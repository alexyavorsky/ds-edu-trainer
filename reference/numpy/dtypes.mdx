## Коротко

- Все элементы массива одного типа (`dtype`). По умолчанию целые — `int64`, дробные — `float64`.
- `a.astype(тип)` возвращает **новый** массив нужного типа. Из float в int дробная часть отбрасывается (к нулю), а не округляется.
- Целые в массиве **переполняются молча**: `int8` после 127 переходит в −128. Пределы типа — `np.iinfo`, для float — `np.finfo`.
- Запись в массив приводит значение к его типу: `9.9` в целом массиве станет `9`, а `NaN` туда не записать.
- Число Python не расширяет тип массива (правила NEP 50 в NumPy 2): `float32 + 3.0` остаётся `float32`.

## Синтаксис

<Syntax code={`a.dtype                  # dtype('int64')
a.astype(np.float32)     # или "float32", float, int, bool, str
np.array(data, dtype=np.int16)
np.iinfo(np.int8)        # min, max для целых
np.finfo(np.float64)     # eps, max, точность для дробных`} />

| Тип | Что хранит | Байт |
| --- | --- | --- |
| `bool` | True / False | 1 |
| `int8`, `int16`, `int32`, `int64` | целые со знаком | 1, 2, 4, 8 |
| `uint8` … `uint64` | целые без знака | 1 … 8 |
| `float32`, `float64` | дробные | 4, 8 |
| `complex128` | комплексные | 16 |
| `<U5` | строки Unicode до 5 символов | 20 |
