Склад маркирует посылки числовыми номерами, а контрольная сумма номера — это сумма его цифр. Напишите рекурсивную функцию `digit_sum(n)`, которая считает её для неотрицательного целого `n` без циклов и без перевода числа в строку.

## Примеры

```python
digit_sum(9875)  # 29, потому что 9 + 8 + 7 + 5
digit_sum(1000)  # 1
digit_sum(0)     # 0
```

## Ограничения

- `0 <= n < 10**100`
- Без `for`, `while` и `str(n)` — только рекурсия и арифметика.
