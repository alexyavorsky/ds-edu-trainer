Маска умеет не только отбирать значения, но и **менять** их. Это главный способ чистить данные: убрать
ошибки датчика, обрезать выбросы, превратить числа в категории.

## Присваивание по маске

`a[маска] = значение` записывает значение во все элементы, где в маске `True`. Остальные не меняются:

Присваивание по маске меняет массив на месте. Если исходные данные нужно сохранить — сначала сделайте копию,
как в уроке о представлениях.

## Выбор из двух вариантов: np.where

`np.where(условие, если_да, если_нет)` строит **новый** массив: там, где условие верно, берётся значение
из второго аргумента, где нет — из третьего. Аргументами могут быть числа и массивы той же длины:

<Quiz id="where-quiz">
Что получится: `np.where(np.array([1, -2, 3]) > 0, 1, 0)`?

- [x] `array([1, 0, 1])`
- [ ] `array([1, 3])`
- [ ] `array([0, 2])`

<Explain>`np.where` с тремя аргументами возвращает массив той же длины: 1 там, где условие верно, 0 — где нет. Отобрать элементы (`[1, 3]`) — это маска в квадратных скобках.</Explain>
</Quiz>

## Ограничить границами: np.clip

`np.clip(a, нижняя, верхняя)` «прижимает» значения к границам: всё, что меньше нижней, становится нижней,
всё, что больше верхней, — верхней. Остальное не меняется:

<Mistake title="np.where с одним условием">
`np.where(условие)` **без** второго и третьего аргументов — это другая функция: она возвращает не значения,
а **номера** элементов, где условие верно. Если нужна замена, всегда пишите все три аргумента.
</Mistake>

## Итоги

- `a[маска] = x` — заменить подходящие элементы на месте.
- `np.where(условие, да, нет)` — новый массив: значение из «да» или «нет» для каждого элемента.
- `np.clip(a, низ, верх)` — прижать значения к границам.
- `np.where` с одним аргументом возвращает номера элементов, а не значения.
