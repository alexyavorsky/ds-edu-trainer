Схема метро задана графом: `lines[s]` — станции, до которых можно доехать от `s` за один перегон. Напишите `route(lines, start, goal)`: функция возвращает список станций от `start` до `goal` с минимальным числом перегонов, включая обе конечные станции, или `None`, если пути нет. Если кратчайших маршрутов несколько, годится любой.

## Пример

```python
lines = {
    "Парк": ["Музей", "Вокзал"],
    "Музей": ["Театр"],
    "Вокзал": ["Рынок"],
    "Рынок": ["Театр", "Порт"],
}
route(lines, "Парк", "Театр")   # ["Парк", "Музей", "Театр"]
route(lines, "Парк", "Парк")    # ["Парк"]
route(lines, "Порт", "Парк")    # None
```
