## Коротко

- `pd.concat([df1, df2])` ставит таблицы **одну под другой**; столбцы сопоставляются по именам.
- Недостающие в какой-то таблице столбцы заполняются `NaN`; `join="inner"` — оставить только общие.
- Индексы сохраняются и могут повторяться — обычно передают `ignore_index=True`.
- `keys=[…]` добавляет внешний уровень индекса — видно, из какой таблицы строка.
- `axis=1` — **рядом**, по совпадающему индексу. Для объединения по значениям столбца-ключа нужен [merge](/reference/pandas/merge).

## Синтаксис

<Syntax code={`pd.concat(objs, axis=0, join="outer", ignore_index=False, keys=None)`} />
