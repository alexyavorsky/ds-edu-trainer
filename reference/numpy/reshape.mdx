## Коротко

- `a.reshape(3, 4)` раскладывает элементы в новую форму; **число элементов** должно совпадать.
- Одна из размерностей может быть `-1` — NumPy вычислит её сам. `a.reshape(-1)` вытягивает массив в одну строку.
- Элементы читаются и раскладываются **по строкам** (порядок C); `order="F"` — по столбцам.
- `reshape` и `ravel` по возможности возвращают **представление**, `flatten` — всегда копию.
- Другой размер (с повтором данных) — функция `np.resize`.

## Синтаксис

<Syntax code={`a.reshape(3, 4)          # или a.reshape((3, 4))
a.reshape(-1, 4)         # число строк вычислится
a.reshape(-1)            # одномерный
a.ravel()                # одномерный, по возможности без копии
a.flatten()              # одномерный, всегда копия
np.resize(a, new_size)   # другой размер, данные повторяются`} />
