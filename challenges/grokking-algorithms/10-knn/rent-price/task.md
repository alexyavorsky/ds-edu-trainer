Квартиры описаны признаками `[площадь, этаж, минут до метро]`, для каждой известна цена аренды. Напишите `predict_rent(train, query, k)`: функция прогнозирует цену для `query` как **среднее** цен `k` ближайших квартир (евклидово расстояние). Это регрессия методом k ближайших соседей.

## Пример

```python
train = [
    ([40, 3, 10], 35_000),
    ([42, 5, 12], 37_000),
    ([80, 10, 5], 90_000),
    ([38, 2, 15], 30_000),
]
predict_rent(train, [41, 4, 11], 2)   # 36000.0
```

## Правила

- При равных расстояниях ближе квартира, которая раньше в `train`.
- Если `k` больше числа квартир, усредняются все.
