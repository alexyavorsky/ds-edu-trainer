Таблицы не всегда приходят из файлов. Небольшую таблицу — справочник, результаты расчёта, пример для
проверки идеи — проще собрать прямо в коде. Заодно станет понятнее, как DataFrame устроен внутри.

## Типы столбцов

В одном столбце лежат значения одного типа. Типы всех столбцов показывает атрибут `dtypes`:

<Demo id="dtypes" title="Типы столбцов меню" />

pandas определил типы сам по значениям: текст — `str`, целые числа — `int64`, дробные — `float64`. Число 64 —
сколько бит памяти занимает одно значение; помнить его не нужно. Слово `object` в последней строке относится
к самому списку типов, а не к таблице.

Тип важен: с числовым столбцом можно считать, с текстовым — нет. Если числа попали в таблицу как текст
(в кавычках), `sum` склеит их как строки, а `mean` упадёт с ошибкой. Как чинить такие столбцы, разберём
в модуле об очистке данных.

<Quiz id="mixed-quiz">
В списке `[1, 2.5, 3]` есть и целые, и дробное число. Какой тип получит столбец `x` в
`pd.DataFrame({"x": [1, 2.5, 3]})`?

- [ ] `int64`
- [x] `float64`
- [ ] `str`

<Explain>Тип у столбца один. Целое можно без потерь записать дробным (1 → 1.0), а дробное целым — нельзя, поэтому pandas выбирает `float64`.</Explain>
</Quiz>

## Series без таблицы

Один столбец тоже можно создать отдельно — `pd.Series` из списка. Параметр `index=` задаёт метки, `name=` —
название:

<Demo id="series" title="Чаевые по дням" />

По метке значение достают квадратными скобками — как из словаря:

<Demo id="by-label" title="Значение по метке и сумма" />

Series — это пары «метка → значение» с общим типом и названием. А DataFrame — несколько Series с **общим
индексом**, поставленные рядом: каждый столбец — Series. Поэтому `menu["price"]` возвращает именно Series.

## Итоги

- `pd.DataFrame({"столбец": [значения], ...})` — таблица из словаря списков; списки одной длины.
- `pd.DataFrame([{...}, {...}])` — таблица из списка словарей: словарь — строка.
- `dtypes` — типы столбцов: `int64`, `float64`, `str`, `bool`.
- `index=` задаёт метки строк; `pd.Series(значения, index=..., name=...)` — отдельный столбец.
- DataFrame — это несколько Series с общим индексом.
