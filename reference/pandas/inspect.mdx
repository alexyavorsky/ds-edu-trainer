## Коротко

- `head(n)` / `tail(n)` — первые / последние строки (по умолчанию 5).
- `shape` — размер, `columns` — имена, `dtypes` — типы.
- `info()` — одним взглядом: типы, **число непустых значений** в каждом столбце (видно пропуски) и память.
- `describe()` — статистика по числовым столбцам; `include="all"` — по всем.
- `value_counts()` — частоты значений столбца, `nunique()` — число различных значений.

## Синтаксис

<Syntax code={`df.head(5), df.tail(5)
df.shape, df.columns, df.dtypes
df.info()
df.describe(include=None, percentiles=None)
df["col"].value_counts(normalize=False, dropna=True)
df.nunique()`} />

## Параметры

<Params
  items={[
    ['n', 'сколько строк показать в head / tail', '5'],
    ['include', 'в describe: None — только числа, "all" — все столбцы, список типов', 'None'],
    ['normalize', 'в value_counts: доли вместо количеств', 'False'],
    ['dropna', 'в value_counts: не считать NaN', 'True'],
  ]}
/>

## Подводные камни

<Pitfall title="value_counts не показывает пропуски">

Строки с `NaN` по умолчанию не считаются, и сумма частот меньше числа строк. Чтобы увидеть пропуски, передайте `dropna=False`.

</Pitfall>

<Pitfall title="describe без текстовых столбцов">

По умолчанию `describe` молча пропускает нечисловые столбцы — в примере выше нет `city` и `drink`. Для них — `include="all"` или `value_counts`.

</Pitfall>
