## Коротко

- `rank()` ставит каждому значению место: наименьшее получает 1. `ascending=False` — наибольшее получает 1.
- Порядок строк не меняется — в отличие от сортировки.
- Для равных значений `method`: `"average"` — средний ранг (3.5), `"min"` — как в спорте (оба третьи, следующий пятый), `"dense"` — без пропусков (следующий четвёртый), `"first"` — по порядку появления.
- `pct=True` — ранг как доля от 0 до 1.
- В группах — `groupby("group")["col"].rank()`.
- Ранги — float, для целых мест добавьте `.astype(int)`.

## Синтаксис

<Syntax code={`s.rank(method="average", ascending=True, pct=False, na_option="keep")
df.groupby("g")["col"].rank(method="min")`} />
