Номера релизов приложения хранятся в отсортированном списке. Функция `find_release(versions, target)` бинарным поиском возвращает индекс релиза или `-1`, если такого нет. В ней две ошибки — найдите и исправьте их.

## Примеры

```python
find_release([101, 105, 110, 120], 110)  # 2
find_release([101, 105, 110, 120], 111)  # -1
find_release([], 5)                      # -1
```
