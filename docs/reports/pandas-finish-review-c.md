## Важно

### В1. Ноутбук: пометка `<After>` ломает список в «Выводах» и неверна для `id="*"`
`src/lib/courses/notebook.ts`, `componentMarkdown`:
`` `*После решения упражнения выше:* ${block.body}` ``.

У 8 проектов (`project-cities`, `project-climate`, `project-channels`, `project-grades`, `project-merge`,
`project-plan`, `project-weather-sales`, `project-report`) «Выводы» — маркированный список. В .ipynb первый
пункт приклеивается к пометке одной строкой — проверено в `dist/courses/pandas/project-cities.ipynb`:
`*После решения упражнения выше:* - Крупных покупок в Казани…`. В Markdown это абзац, а список начинается
только со второго пункта: первый вывод выглядит сломанным. Кроме того, для `<After id="*">` «упражнения выше»
неверно: итог открывается после **всех** упражнений урока.

Как исправить: пометку отдельным абзацем (`…:*\n\n${body}`), а для `id="*"` — текст «После решения всех
упражнений урока». Строку в COURSES_PLAN («В ноутбуке — … с пометкой…») поправить так же.
