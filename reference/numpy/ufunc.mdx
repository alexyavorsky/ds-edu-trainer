## Коротко

- **ufunc** (universal function) — функция, которая применяется к каждому элементу массива; цикл выполняется внутри NumPy.
- Одноместные: `sqrt`, `exp`, `log`, `log10`, `abs`, `sin`… Двуместные: `add`, `multiply`, `maximum`, `minimum`… Все операторы `+`, `*` — тоже ufunc.
- `np.maximum(a, b)` выбирает большее **из двух массивов поэлементно**, а `np.max(a)` ищет максимум **внутри** массива.
- У двуместных ufunc есть методы: `reduce` (свернуть), `accumulate` (нарастающий итог), `outer` (все пары), `at` (на месте по индексам).
- Параметры `out=` и `where=` позволяют писать в готовый массив и считать только там, где условие истинно.
- Функции модуля `math` с массивами не работают — берите аналоги из `np`.

## Синтаксис

<Syntax code={`np.sqrt(a), np.exp(a), np.log(a), np.abs(a)
np.maximum(a, b), np.minimum(a, b)      # поэлементно из двух
np.add.reduce(a)          # = a.sum()
np.add.accumulate(a)      # = a.cumsum()
np.multiply.outer(a, b)   # все пары: форма (len(a), len(b))
np.add.at(a, idx, 1)      # прибавить по индексам с повторами
np.sqrt(a, out=res, where=a >= 0)`} />
