Составьте рейтинг игроков по очкам — от лучшего к худшему. Напишите `quicksort_desc(scores)`: функция возвращает новый список, отсортированный **по убыванию** быстрой сортировкой.

## Примеры

```python
quicksort_desc([30, 75, 10, 75, 50])  # [75, 75, 50, 30, 10]
quicksort_desc([])                    # []
```

## Ограничения

- Без `sorted`, `.sort()` и `reversed(...)` поверх готовой сортировки.
- Исходный список не изменяется.
