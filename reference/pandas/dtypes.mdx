## Коротко

- Основные типы: `int64`, `float64`, `bool`, `str`, `datetime64`, `category`. Посмотреть — `df.dtypes`.
- `astype(тип)` или `astype({"col": тип})` — привести столбцы; падает на первом неподходящем значении.
- `pd.to_numeric(s, errors="coerce")` превращает в число всё, что можно, а остальное — в `NaN`.
- **Nullable-типы** с заглавной буквы — `Int64`, `Float64`, `boolean`, `string` — хранят пропуск как `pd.NA`, не меняя тип: целые остаются целыми.
- `convert_dtypes()` подбирает nullable-типы для всей таблицы.

## Синтаксис

<Syntax code={`df.dtypes
df.astype({"qty": "int64", "price": "float64"})
pd.to_numeric(s, errors="raise", downcast=None)
pd.Series(values, dtype="Int64")      # "Float64", "boolean", "string"
df.convert_dtypes()`} />

## Параметры

<Params
  items={[
    ['dtype', 'в astype: тип или словарь {"столбец": тип}', '—'],
    ['errors', 'в to_numeric: "raise" — ошибка, "coerce" — NaN для неподходящих значений', '"raise"'],
    ['downcast', 'в to_numeric: "integer", "float" — выбрать самый компактный тип', 'None'],
  ]}
/>

| Тип | Что хранит | Пропуск |
| --- | --- | --- |
| `int64` | целые | нельзя — столбец станет `float64` |
| `Int64` | целые | `pd.NA` |
| `float64` | дробные | `NaN` |
| `bool` / `boolean` | логические | нельзя / `pd.NA` |
| `str` | строки (по умолчанию в pandas 3) | `NaN` |
| `category` | повторяющиеся значения из набора | `NaN` |
