Арифметикой можно получить столбец из других столбцов. Но бывают правила, которые формулой не запишешь:
«категории „Кофе“ — полка A, сладостям — полка B», «дороже 1000 ₽ — дорогой товар», «доставка зависит от цены
ступеньками». Для них есть четыре инструмента — от самого простого к самому общему.

## map: значение по словарю

Соответствие «было → стало» удобно записать словарём. Метод `map` заменяет каждое значение столбца тем, что
лежит в словаре по этому ключу:

<Demo id="map" title="Категория → полка на складе" />

`map` пропускает через словарь **все** значения. Если для значения нет ключа, на его месте окажется `NaN` —
так pandas обозначает пропуск, «нет данных»:

<Demo id="map-missing" title="В словаре только кофе и чай" />

Пропускам посвящён первый урок следующего модуля. Пока достаточно знать: `NaN` после `map` значит, что
в словаре не хватило ключа. Проверить столбец на пропуски помогает `notna()` — маска «значение есть».
`столбец.notna().all()` вернёт `True`, только если пропусков нет: в неполном переводе они есть, а в столбце
`shelf` из первого примера — нет.

В словаре `rates` — скидка для каждой категории. Добавьте в таблицу `goods` столбец `discount` — скидку
товара по его категории — и столбец `sale_price`: цену со скидкой, округлённую до целых рублей.

<Hint>`goods["discount"] = goods["category"].map(rates)`.</Hint>
<Hint>Цена со скидкой — `goods["price"] * (1 - goods["discount"])`; всё выражение в скобки и `.round()`.</Hint>
</Exercise>

## replace: заменить только некоторые

Когда менять нужно лишь часть значений, а остальные оставить, подходит `replace`. Он тоже принимает словарь,
но значения, которых в словаре нет, **не трогает**:

<Demo id="replace" title="Посуда и аксессуары — в одну категорию" />

Запомнить разницу просто: `map` — «перевести всё по словарю», `replace` — «исправить указанное».

<Quiz id="map-quiz">
Сколько непустых значений останется:
`print(pd.Series(["да", "нет", "да"]).map({"да": 1}).notna().sum())`?

- [ ] `3`
- [x] `2`
- [ ] `0`

<Explain>Для «нет» ключа в словаре нет — `map` поставит на его место `NaN`. Останется два значения. `replace` с тем же словарём оставил бы «нет» как есть.</Explain>
</Quiz>

<Exercise id="groups" title="Напитки">
Добавьте в `goods` столбец `group`: категории «Кофе» и «Чай» заменены на «Напитки», остальные — без изменений.
Столбец `category` не меняйте. В `n_drinks` сохраните число товаров-напитков.

<Hint>`goods["category"].replace({"Кофе": "Напитки", "Чай": "Напитки"})`.</Hint>
<Hint>Число — сумма маски `goods["group"] == "Напитки"`.</Hint>
</Exercise>

## np.where: одно из двух по условию

Столбец «если условие выполнено — одно значение, иначе — другое» строит функция `where` из библиотеки
NumPy. pandas построен на NumPy, и некоторые её функции удобно вызывать напрямую; подключают её под именем `np`.
У `np.where` три аргумента: маска, значение для `True`, значение для `False`.

обозначает текст длиной до семи символов. Массив можно сразу записать в столбец таблицы:

## apply: своё правило

Если правило сложнее — несколько ступенек, длинное условие, — его можно написать обычной функцией Python:
на вход одно значение, на выход результат. Метод `apply` вызовет функцию для каждого значения столбца:

<Demo id="apply" title="Три уровня цены" />

Функцию передают **без скобок** — `apply(level)`, а не `apply(level())`: мы отдаём саму функцию, а вызывать
её будет pandas.

`apply` умеет всё, но у этого есть цена: функция Python вызывается отдельно для каждой строки, и на больших
таблицах это в десятки и сотни раз медленнее готовых операций. Поэтому сначала стоит проверить, нет ли
операции, которая работает со столбцом целиком:

<Demo id="apply-slow" title="Тот же результат — но формула быстрее и короче" />

Порядок выбора: арифметика и сравнения → `map`, `replace`, `np.where` → и только если ничего не подошло,
`apply`.

<Exercise id="shipping" title="Стоимость доставки">
Доставка товара стоит: бесплатно — при цене от 1000 ₽, 150 ₽ — при цене от 500 до 999 ₽, 250 ₽ — если товар
дешевле 500 ₽. Допишите функцию `shipping(price)`, добавьте в `goods` столбец `shipping` с её результатами
и сохраните в `free` число товаров с бесплатной доставкой.

<Hint>В функции — два `if` с `return` и последний `return 250`, как в примере с уровнями цены.</Hint>
<Hint>`goods["shipping"] = goods["price"].apply(shipping)`; число — сумма маски `goods["shipping"] == 0`.</Hint>
</Exercise>

## Итоги

- `столбец.map(словарь)` — перевести все значения по словарю; нет ключа — `NaN`.
- `столбец.replace(словарь)` — заменить только указанные значения.
- `np.where(маска, a, b)` — `a` там, где `True`, и `b` там, где `False`.
- `столбец.apply(функция)` — своё правило для каждого значения; медленно, поэтому в последнюю очередь.
