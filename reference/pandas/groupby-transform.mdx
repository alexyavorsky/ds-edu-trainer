## Коротко

- `agg` сворачивает группу в одну строку; `transform` возвращает результат **той же длины**, что исходная таблица — значение группы оказывается в каждой её строке.
- Типичные задачи `transform`: доля строки в сумме группы, отклонение от среднего по группе, заполнение пропусков средним по группе.
- `filter(функция)` оставляет или убирает **целые группы** по условию.
- `cumcount`, `cumsum`, `shift`, `rank`, `diff` работают внутри групп и тоже сохраняют длину.
- `apply` — самый общий и самый медленный способ: функция получает каждую группу как DataFrame.

## Синтаксис

<Syntax code={`df.groupby(key)["col"].transform("sum")     # или "mean", своя функция
df.groupby(key).filter(lambda g: условие)

df.groupby(key)["col"].cumsum(), .shift(), .diff(), .rank()
df.groupby(key).apply(func)`} />

<Pitfall title="apply там, где хватит transform или agg">

`apply` вызывает функцию Python для каждой группы. Встроенные агрегации и `transform("sum")` со строковым именем считают все группы сразу, без вызова Python для каждой, — поэтому быстрее.

</Pitfall>
