В проекте про скидки базовый класс `Discount` был «заглушкой»: его метод `amount` возвращал 0, а подклассы
его переопределяли. Но ничто не мешало создать сам `Discount` или подкласс, где `amount` забыли, — касса
просто посчитала бы скидку 0, и ошибку никто бы не заметил. Нужен способ сказать: «этот класс — только
основа для других, а такой-то метод подкласс **обязан** написать».

## `ABC` и `@abstractmethod`

Такой класс называется **абстрактным** (abstract base class, ABC). В Python его объявляют наследником
класса `ABC` из модуля `abc` стандартной библиотеки, а обязательные методы помечают декоратором
`@abstractmethod`; такой метод называют **абстрактным методом** (abstract method). Тело абстрактного метода
обычно пустое — `...`: реализацию дадут подклассы. Декоратор работает только в наследнике `ABC`: в обычном
классе `@abstractmethod` молча ничего не запрещает.

<Mistake title="TypeError при создании экземпляра подкласса">
Ошибка вида `Can't instantiate abstract class … without an implementation for abstract method 'cost'` (так она
звучит в Python 3.12 и новее; в 3.10–3.11 — `… with abstract method cost`) при создании экземпляра значит: в подклассе нет одного из абстрактных методов — его имя есть в
конце сообщения. Частая причина — опечатка в имени метода: `def cots(self, km)` не реализует `cost`.
</Mistake>

## Шаблонный метод

В `card()` вы написали обычный метод абстрактного класса, который вызывает абстрактный. Это частый приём —
**шаблонный метод** (template method): базовый класс задаёт порядок действий целиком, а подклассы
заполняют отдельные шаги. Порядок не повторяется в каждом подклассе, и по договорённости подклассы шаблонный
метод не переопределяют — хотя Python этого не запрещает.

<Exercise id="sales-report" title="Отчёт о продажах">
Объявите подкласс `SalesReport` класса `Report` из демонстрации. `SalesReport({"Латте": 41, "Раф": 17})`
хранит словарь продаж в атрибуте `sales`. Заголовок отчёта — `"Продажи за день"`, строки — `"Латте: 41"`,
`"Раф: 17"` и так далее в порядке словаря. Метод `render` не переопределяйте.

<Hint>Свой `__init__` не обязан вызывать `super().__init__`, если у базового класса его нет.</Hint>
<Hint>`lines()` возвращает список строк — по одной на пару «название, количество» из словаря `self.sales`.</Hint>
</Exercise>

<Quiz id="abc-quiz">
У абстрактного класса `Report` два абстрактных метода: `title` и `lines`. Подкласс реализовал только
`lines`. Когда появится ошибка?

- [ ] при объявлении подкласса
- [x] при создании экземпляра подкласса
- [ ] при вызове `render()`

<Explain>Объявить такой подкласс можно — он сам остаётся абстрактным. А при попытке создать экземпляр Python проверит, что абстрактных методов не осталось, и выбросит `TypeError`.</Explain>
</Quiz>

Абстрактный класс — это договор: «каждый способ доставки умеет `cost`», «каждый отчёт умеет `title` и
`lines`». Код, который пользуется такими объектами, может на этот договор полагаться.
