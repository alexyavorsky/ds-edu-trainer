Районы города нужно раскрасить на карте так, чтобы соседние районы были разного цвета. Цвета — числа `0, 1, 2, …`. Минимальное число цветов искать не будем: это NP-полная задача. Раскрашиваем жадно: районы идут по убыванию числа соседей, и каждому достаётся **наименьший цвет, не занятый его соседями**. Допишите `color_map(neighbors)`. Пропуски помечены `# TODO`.

## Пример

```python
neighbors = {
    "Центр": {"Север", "Юг", "Запад"},
    "Север": {"Центр", "Запад"},
    "Юг": {"Центр"},
    "Запад": {"Центр", "Север"},
}
color_map(neighbors)   # например {"Центр": 0, "Север": 1, "Запад": 2, "Юг": 1}
```

## Правила

- Соседство симметрично. Тесты проверяют, что соседи разного цвета, цвета идут подряд с 0, и цветов не больше чем «максимум соседей + 1».
