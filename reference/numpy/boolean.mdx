## Коротко

- Сравнение массива даёт **маску** — массив `True`/`False` той же формы: `temps > 5`.
- `a[маска]` возвращает элементы, где маска `True`. Результат — одномерная **копия**.
- Условия объединяют через `&` (и), `|` (или), `~` (не), каждое условие — **в скобках**. Слова `and`, `or`, `not` с массивами не работают.
- `a[маска] = значение` меняет только выбранные элементы.
- `маска.sum()` — сколько `True`, `маска.mean()` — их доля; `any()` / `all()` — есть ли хоть один / все ли.

## Синтаксис

<Syntax code={`mask = a > 0
a[mask]                      # или сразу a[a > 0]
a[(a > 0) & (a < 10)]        # и
a[(a < 0) | (a > 10)]        # или
a[~mask]                     # не
a[a < 0] = 0                 # запись по маске
mask.sum(), mask.any(), mask.all()`} />

<Pitfall title="Условия без скобок">

У `&` и `|` приоритет выше, чем у `>` и `<`: `a > 0 & a < 10` читается как `a > (0 & a) < 10`. Скобки вокруг каждого условия обязательны.
