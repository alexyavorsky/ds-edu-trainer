У путешественника есть **один** купон: на любом одном рейсе он платит половину цены (с округлением вниз — `price // 2`). Допишите `cheapest_with_coupon(flights, start, goal)`: функция возвращает минимальную цену перелёта или `None`. Купон можно и не использовать. Пропуски помечены `# TODO`.

## Пример

```python
flights = {
    "A": {"B": 1000, "C": 300},
    "C": {"B": 600},
}
cheapest_with_coupon(flights, "A", "B")   # 500: прямой рейс за 1000 // 2
# без купона было бы 900 через C, с купоном на C → B — 600
```
