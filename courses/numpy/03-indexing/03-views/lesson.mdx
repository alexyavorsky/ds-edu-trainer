У списков Python срез — это **копия**: изменили кусок — исходный список цел. У массивов NumPy иначе, и это
одна из самых частых неожиданностей для новичков.

## Срез смотрит на тот же массив

Срез массива — это **представление** (view): окно, через которое видны те же самые данные. Своих данных у
него нет. Поэтому изменение среза меняет исходный массив:

Зачем так сделано: массивы бывают огромными (миллионы чисел), и копировать данные при каждом срезе было бы
медленно и расточительно. Представление создаётся мгновенно, сколько бы элементов в нём ни было.

<Mistake title="«я поменял только кусок»">
Если вы взяли срез, чтобы поэкспериментировать, и изменили его, — исходный массив изменился тоже. Ошибки нет,
просто данные тихо испортились. Правило: срез, который вы собираетесь менять, а исходник беречь, нужно
скопировать.
</Mistake>

<Quiz id="view-change">
Что напечатает этот код?

```python
a = np.array([1, 2, 3, 4])
b = a[1:3]
b[0] = 99
print(a)
```

- [ ] `[1 2 3 4]`
- [x] `[ 1 99  3  4]`
- [ ] `[99  2  3  4]`

<Explain>`b` — окно на элементы `a` с индексами 1 и 2. `b[0]` — это `a[1]`, поэтому в `a` двойка меняется на 99.</Explain>
</Quiz>

## Когда представление — то, что нужно

Бывает, что изменить часть исходника и нужно. Тогда представление удобно: дали ему короткое имя — и меняете
через него:

<Exercise id="bonus" title="Премия второму кварталу">
В `plan` — план продаж по 12 месяцам. Через представление `q2` (месяцы с индексами 3, 4, 5 — второй квартал)
увеличьте план второго квартала на 10 %, чтобы изменился и сам `plan`.

<Hint>`q2 = plan[3:6]` — окно на три месяца.</Hint>
<Hint>Чтобы изменить данные на месте, присваивайте в срез: `q2[:] = q2 * 1.1`. Простое `q2 = q2 * 1.1` создаст новый массив и `plan` не тронет.</Hint>
</Exercise>

<Mistake title="q2 = q2 * 1.1 не меняет plan">
Присваивание `q2 = …` не меняет данные, а даёт имени `q2` новый массив — результат умножения. Старое окно
забыто, `plan` остался прежним. Менять данные через представление можно только присваиванием **в** него:
`q2[:] = …` или `q2[0] = …`.
</Mistake>

обнулите элементы начиная с индекса 3. `backup` должен остаться прежним.

<Hint>Копию делайте до изменения: `backup = scores.copy()`.</Hint>
<Hint>Обнулить хвост — `scores[3:] = 0`.</Hint>
</Exercise>

## Итоги

- Срез массива — представление: те же данные, изменение видно в исходнике.
- `copy()` — независимая копия; нужна, если срез будете менять, а исходник беречь.
- Менять данные через представление — присваиванием в него (`v[:] = …`); `v = …` просто даёт имени новый массив.
- Подробнее о том, что даёт представление, а что копию, — в справочнике; например, выборка по маске (модуль 4)
  всегда копия.
