Для проекта нужны навыки `needed`. У каждого кандидата свой набор навыков: `candidates[имя]`. Напишите `pick_team(needed, candidates)`: функция жадным алгоритмом собирает небольшую команду, в которой вместе есть все нужные навыки, и возвращает список имён. Если это невозможно, она возвращает `None`.

## Пример

```python
needed = {"python", "sql", "ml", "devops", "design"}
candidates = {
    "Ира": {"python", "ml", "sql"},
    "Кирилл": {"devops", "python"},
    "Лена": {"design", "sql"},
    "Миша": {"ml"},
}
pick_team(needed, candidates)   # например ["Ира", "Кирилл", "Лена"]
```

## Правила

- Жадный алгоритм приближённый: он не всегда находит самую маленькую команду, но в тестах его результата хватает. Проверяются допустимость команды и её размер.
