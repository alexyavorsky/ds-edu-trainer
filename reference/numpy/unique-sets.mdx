## Коротко

- `np.unique(a)` — отсортированные уникальные значения.
- `return_counts=True` добавляет частоты, `return_inverse=True` — номер уникального значения для каждого элемента (удобно для кодирования категорий), `return_index=True` — где значение встретилось впервые.
- `axis=0` ищет уникальные **строки** двумерного массива.
- Короткие функции (NumPy 2): `unique_values`, `unique_counts`, `unique_inverse`, `unique_all`.
- `np.isin(a, b)` — маска «элемент `a` есть в `b`». Множества: `intersect1d`, `union1d`, `setdiff1d`, `setxor1d` — результат отсортирован и без повторов.

## Синтаксис

<Syntax code={`np.unique(a, return_index=False, return_inverse=False,
          return_counts=False, axis=None)
np.unique_counts(a)          # → (values, counts)
np.isin(a, b, invert=False)
np.intersect1d(a, b), np.union1d(a, b)
np.setdiff1d(a, b), np.setxor1d(a, b)`} />

<Pitfall title="NaN в unique">

`np.unique` считает все `NaN` одним значением, хотя `NaN != NaN`. Чтобы каждый `NaN` остался отдельным, передайте `equal_nan=False`.
