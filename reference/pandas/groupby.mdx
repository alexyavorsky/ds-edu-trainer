## Коротко

- `groupby` работает по схеме **разделение → применение → объединение** (split-apply-combine): строки делятся на группы по ключу, к каждой группе применяется функция, результаты собираются в одну таблицу.
- Сам `df.groupby("city")` ничего не считает — это «ленивый» объект; результат появляется после агрегации: `.sum()`, `.mean()`, `.agg(...)`.
- Ключи группировки по умолчанию уходят в **индекс** результата и **сортируются**.
- `size()` — число строк в группе, `count()` — число непустых значений в столбце.
- Строки с `NaN` в ключе по умолчанию выпадают (`dropna=True`).

## Подводные камни

<Pitfall title="mean() по всему DataFrame падает на текстовых столбцах">

Агрегации не отбрасывают молча нечисловые столбцы. Выберите нужные столбцы или передайте `numeric_only=True`. При этом `sum()` на строках не падает, а склеивает их — тоже вряд ли то, что нужно.

<Pitfall title="Строки с пустым ключом исчезают">

<Pitfall title="MultiIndex там, где его не ждали">

Группировка по нескольким ключам даёт MultiIndex. Если дальше нужны обычные столбцы — например, для `merge` или сохранения в CSV, — передайте `as_index=False` или вызовите `.reset_index()`.

</Pitfall>
