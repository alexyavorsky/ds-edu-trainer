## Коротко

- `sample(n=3)` — 3 случайные строки, `sample(frac=0.1)` — 10 % строк.
- `random_state=число` — воспроизводимый результат; без него каждый вызов разный.
- `sample(frac=1)` перемешивает все строки; `ignore_index=True` — заодно новый индекс.
- `replace=True` — с повторами (бутстреп); `weights` — вероятность строки пропорциональна весу.
- Без `replace` нельзя взять больше строк, чем есть в таблице.

## Синтаксис

<Syntax code={`df.sample(n=None, frac=None, replace=False, weights=None,
