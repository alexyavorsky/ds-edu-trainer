Турникет стадиона записывает коды билетов в порядке прохода. Напишите `first_repeat(scans)`: функция возвращает код билета, который **раньше всех** прошёл повторно, или `None`, если повторов нет. «Раньше всех» — по моменту второго прохода.

## Примеры

```python
first_repeat(["A1", "B7", "C3", "B7", "A1"])  # "B7" — его повтор случился раньше, чем у A1
first_repeat(["A1", "B7"])                    # None
```

## Ограничения

- До 10⁶ проходов, время — O(n): проверка «уже был» должна занимать O(1). Тест на 50 000 проходов разрешает прочитать журнал до 3 раз и ждёт не больше 3 секунд.
