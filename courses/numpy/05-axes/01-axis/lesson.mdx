`sum`, `mean`, `max` до сих пор сворачивали всю таблицу в одно число. Но у таблицы обычно спрашивают другое:
сколько продал **каждый** магазин, какой была выручка **каждого** квартала. Для этого у агрегатов есть
параметр `axis` — ось, вдоль которой считать.

## Две оси таблицы

У двумерного массива две оси: **ось 0** — вдоль строк (вниз), **ось 1** — вдоль столбцов (вправо). Номера
осей совпадают с позициями в форме `(3, 4)`: ось 0 длиной 3, ось 1 длиной 4.

`axis` — это ось, **которую сворачивают**: вдоль неё идёт сложение, и она исчезает из результата.

<AxisDiagram />

<Demo id="axis-sums" title="sum(axis=0) и sum(axis=1)" />

- `sales.sum(axis=0)` — складываем вниз, строки исчезают: сумма для **каждого столбца** — квартала. Форма
  `(3, 4)` → `(4,)`.
- `sales.sum(axis=1)` — складываем вправо, столбцы исчезают: сумма для **каждой строки** — магазина. Форма
  `(3, 4)` → `(3,)`.

<Mistake title="путаница с axis">
Интуиция часто подсказывает наоборот: «axis=0 — это строки, значит, итог по строкам». Но итог **по каждой
строке** — это `axis=1`. Надёжный способ не ошибиться — смотреть на форму: число, которое вы указали в `axis`,
пропадает из формы. Нужен результат длиной «сколько строк» — сворачивайте столбцы, `axis=1`.
</Mistake>

## Итоги

- `axis` — ось, которую сворачивают; она исчезает из формы результата.
- В таблице: `axis=0` — итог для каждого столбца, `axis=1` — для каждой строки.
- Параметр `axis` есть у `sum`, `mean`, `min`, `max`, `argmax` и других агрегатов.
