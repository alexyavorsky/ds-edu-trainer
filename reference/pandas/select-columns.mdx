## Коротко

- `df["col"]` — один столбец, результат — **Series**.
- `df[["a", "b"]]` — несколько столбцов (список!), результат — **DataFrame**. `df[["a"]]` — DataFrame из одного столбца.
- `df.col` работает для простых имён, но ломается, если имя совпадает с методом или атрибутом (`size`, `count`, `index`) или содержит пробел. Для присваивания точку не используют.
- `select_dtypes(include="number")` — все числовые столбцы; `filter(like="…")` — по части имени.

## Синтаксис

<Syntax code={`df["col"]                         # Series
df[["a", "b"]]                    # DataFrame
df.select_dtypes(include="number", exclude=None)
df.filter(items=None, like=None, regex=None)`} />
