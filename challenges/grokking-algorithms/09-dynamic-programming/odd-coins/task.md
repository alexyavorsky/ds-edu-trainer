В одной стране монеты бывают необычных номиналов, например `[1, 3, 4]`. Жадный выбор «сначала самую крупную» тут не всегда оптимален. Напишите `min_coins(amount, coins)`: функция возвращает минимальное число монет на сумму `amount`, решая задачу таблицей, или `-1`, если сумму набрать нельзя.

## Примеры

```python
min_coins(6, [1, 3, 4])   # 2: 3 + 3 (жадно было бы 4 + 1 + 1)
min_coins(7, [2, 4])      # -1
min_coins(0, [5])         # 0
```

## Ограничения

- `amount <= 300`, номиналов до 20. Время — O(amount · len(coins)).
- Подходит и таблица, и рекурсия с запоминанием; без запоминания перебор не успеет.
