Очередь печати хранится как односвязный список (глава 2): каждый узел знает только следующий. Функция `reverse(head)` должна рекурсивно развернуть список на месте и вернуть новую голову, не создавая новых узлов. В ней две ошибки — найдите и исправьте их.

## Пример

```python
head = Node(1, Node(2, Node(3)))
new_head = reverse(head)
# new_head: 3 → 2 → 1 → None
```

## Идея алгоритма

Развернуть всё, кроме головы (рекурсивный случай). Затем прицепить голову в конец развёрнутой части. Новая голова — последний узел исходного списка.
