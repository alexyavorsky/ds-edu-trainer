## Коротко

- `shift(1)` сдвигает значения на строку вниз — в строке оказывается предыдущее значение; `shift(-1)` — следующее. Освободившиеся места — `NaN`.
- `diff()` — разность с предыдущим (`s - s.shift()`), `pct_change()` — относительное изменение (`s / s.shift() - 1`).
- `periods=k` — сравнение со значением k строк назад.
- `shift(1, freq="D")` сдвигает **даты в индексе**, а значения оставляет на месте.
- Для нескольких рядов в одной таблице — `groupby(...)["col"].diff()`, иначе разности посчитаются между разными рядами.
