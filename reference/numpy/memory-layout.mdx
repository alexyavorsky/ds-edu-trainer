## Коротко

- Данные массива лежат в памяти одним блоком. Форма и **strides** говорят, как по нему ходить: на сколько байт сдвинуться, чтобы перейти к следующему элементу по каждой оси.
- **C-порядок** (по умолчанию) — строка за строкой; **F-порядок** (Fortran) — столбец за столбцом.
- Транспонирование, срезы с шагом, `broadcast_to` меняют только strides — поэтому они бесплатны и дают представления.
- `flags["C_CONTIGUOUS"]` показывает, лежат ли элементы подряд в порядке C. Некоторые операции (`ravel`, `reshape`, передача в C-библиотеки) для несплошных массивов копируют данные.
- Проход вдоль последней оси C-массива быстрее, чем вдоль первой: элементы идут подряд.

## Синтаксис

## Подводные камни

<Pitfall title="ravel и reshape иногда копируют">

Для несплошного массива (например, транспонированного) вытянуть элементы в строку без копии нельзя, и `ravel` молча копирует. Если важно, чтобы копии не было, используйте `a.reshape(-1, copy=False)` — он упадёт вместо копирования.
