Функция `lcs(a, b)` возвращает саму самую длинную общую подпоследовательность, а не только её длину. Сначала она заполняет таблицу, как в главе, затем проходит по ней от правого нижнего угла и собирает символы. Таблица заполняется верно, но при восстановлении есть две ошибки. Найдите и исправьте их.

## Примеры

```python
lcs("рыбак", "бирка")   # "рк" — или другая общая подпоследовательность длины 2
lcs("abcbdab", "bdcaba")   # одна из подпоследовательностей длины 4, например "bcba"
```

## Правила

- Если вариантов несколько, годится любой. Тесты проверяют, что ответ — общая подпоследовательность максимальной длины.
