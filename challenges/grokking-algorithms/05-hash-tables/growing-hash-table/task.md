Хеш-таблица начинается с 4 корзин и удваивается, как только **коэффициент заполнения** (элементов / корзин) превышает 0.7. Так цепочки остаются короткими, а операции — O(1) в среднем. После вставки коэффициент не должен превышать 0.7. Но в коде две ошибки: таблица растёт не вовремя и после роста теряет ключи. Найдите и исправьте их.

## Пример

```python
table = GrowingHashTable()
for i in range(3):
    table.put(i, i * 10)      # 3 / 4 = 0.75 > 0.7 → 8 корзин
len(table.buckets)            # 8
table.get(2)                  # 20
```
