## Коротко

- `df.plot()` рисует линию для каждого числового столбца; по оси X — индекс.
- Вид графика — через `kind=…` или методы `df.plot.bar()`, `.barh()`, `.hist()`, `.scatter(x, y)`, `.area()`, `.box()`, `.pie()`.
- Рисует библиотека **matplotlib** — её нужно установить отдельно. `.plot` возвращает объект осей (`Axes`): через него настраивают подписи и сохраняют картинку.
- Для графика по категориям удобен длинный или сводный формат: сначала [pivot_table](/reference/pandas/pivot-table) или `groupby`, потом `.plot`.
- В Jupyter график показывается сам; в скрипте — `import matplotlib.pyplot as plt; plt.show()` или сохранение в файл.

## Подводные камни

<Pitfall title="matplotlib не установлен">

pandas не ставит matplotlib сам, а без него `.plot` падает с `ImportError: matplotlib is required for plotting…`. Установите `pip install matplotlib`.

</Pitfall>

<Pitfall title="Нечисловые столбцы">

Текстовые столбцы в график не попадают. Если числовых столбцов нет совсем, `.plot` падает — проверьте типы через `df.dtypes`.
