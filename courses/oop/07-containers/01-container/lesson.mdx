Корзина и меню из прошлых модулей хранят товары внутри, но снаружи с ними неудобно: чтобы узнать число
товаров, пишут `len(cart.items)`, а чтобы найти товар — вызывают метод. Со списком или словарём всё проще:
`len(menu)`, `menu[0]`, `"Латте" in menu`. Такие объекты называют **контейнерами**. Свой класс тоже может
стать контейнером — нужно объявить несколько магических методов. Набор методов, которые ждёт встроенная
операция, называют **протоколом** (protocol): здесь — протоколом контейнера.

## `len` и `bool`

`len(x)` вызывает `x.__len__()` — метод должен вернуть целое число не меньше нуля. А в `if x:` и `bool(x)`
Python спрашивает `x.__bool__()`; если такого метода нет, но есть `__len__`, — объект ложен, когда его длина 0.
Поэтому пустая корзина с `__len__` сама собой становится «ложью»:

`__bool__` объявляют, когда «истинность» объекта означает не «непустой», а что-то другое:

<Exercise id="machine" title="Готова ли кофемашина">
Допишите класс `CoffeeMachine`: `bool(machine)` — `True`, если в ней есть и вода (`water` больше 0 мл), и

<Hint>Нужны оба условия сразу — соедините два сравнения через `and`.</Hint>
<Hint>`__bool__` должен вернуть именно `True` или `False` — результат сравнения подходит.</Hint>
</Exercise>

## Квадратные скобки: `__getitem__`

`x[key]` вызывает `x.__getitem__(key)`. Что считать ключом, решает класс: список принимает номер, словарь —
ключ. Например, расписание смен удобно открывать по дню недели:

Если такого ключа нет, по соглашению выбрасывают `KeyError` (для номеров — `IndexError`), как делает словарь.

## `in`: `__contains__`

`x in container` вызывает `container.__contains__(x)`. Без него Python перебрал бы элементы по одному — но
только если объект умеет перебираться. С `__contains__` вы сами решаете, что значит «есть в контейнере»:

</Exercise>

<Quiz id="bool-quiz">
У класса `Cart` есть `__len__`, но нет `__bool__`. Что напечатает `print(bool(Cart()))` для пустой корзины?

- [x] `False`
- [ ] `True`
- [ ] ошибку `TypeError`

<Explain>Без `__bool__` Python спрашивает `__len__`: длина 0 — значит, объект ложен. Без обоих методов любой объект был бы истинным.</Explain>
