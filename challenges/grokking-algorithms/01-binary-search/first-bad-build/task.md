Сборки проекта пронумерованы от `1` до `n`. В какой-то момент в код попала ошибка, и с этой сборки все последующие тоже сломаны. Функция `is_bad(k)` проверяет сборку `k`, но каждый вызов занимает десять минут. Напишите `first_bad_build(n, is_bad)`: она возвращает номер первой сломанной сборки или `-1`, если все сборки исправны.

## Пример

```python
# сломаны сборки 4, 5, 6, 7
first_bad_build(7, lambda k: k >= 4)   # 4
first_bad_build(7, lambda k: False)    # -1
```

## Ограничения

- `1 <= n <= 10**12`
- Вызовов `is_bad` — O(log n). Бинарному поиску при n = 10¹² хватает около 40 вызовов, тест допускает до 123. Перебор подряд не успеет.
- `is_bad` можно вызывать только для номеров от 1 до n.
