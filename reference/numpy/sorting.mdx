## Коротко

- `np.sort(a)` возвращает **новый** отсортированный массив; метод `a.sort()` сортирует **на месте** и возвращает `None`.
- `descending=True` (с NumPy 2.5) — по убыванию. В старом коде для этого писали `np.sort(a)[::-1]`.
- `np.argsort(a)` — индексы, которые упорядочили бы `a`. С ними сортируют связанные массивы и строки таблицы.
- В многомерном массиве по умолчанию сортируется каждая строка (`axis=-1`); `axis=None` — весь массив как одномерный.
- Несколько ключей — `np.lexsort`: главный ключ передаётся **последним**.

## Синтаксис

<Syntax code={`np.sort(a, axis=-1, kind=None, descending=False)
a.sort(axis=-1)                   # на месте
np.argsort(a, axis=-1, descending=False)

np.lexsort((второстепенный, главный))`} />
