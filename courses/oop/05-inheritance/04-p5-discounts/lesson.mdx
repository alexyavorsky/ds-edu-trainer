У «Кофейной лавки» три вида акций: процент от суммы, фиксированная сумма и «каждый n-й напиток в подарок».
Касса должна уметь применить любую из них — и выбрать для покупателя самую выгодную. Если писать это
цепочкой `if`, каждая новая акция будет требовать правки кассы. Вместо этого сделаем иерархию классов:
у всех скидок один метод `amount(cart)` — сколько рублей скидка даёт для корзины, — а касса просто вызывает его.

## Что у нас уже есть

Товар и корзина из прошлых модулей: `subtotal` — сумма корзины без скидок.

## Шаг 1. Базовая скидка

<Exercise id="base" title="Класс Discount">
Допишите класс `Discount`: `Discount("без скидки")` хранит название акции в атрибуте `title`, `str(discount)`
возвращает это название, а метод `amount(cart)` возвращает 0 — базовая «скидка» ничего не скидывает.
Подклассы переопределят `amount`.

<Hint>`__str__` возвращает `self.title`; `amount` — `return 0`.</Hint>
</Exercise>

## Шаг 2. Процент и фиксированная сумма

Подклассы наследуют от `Discount` всё, что есть в шаге 1, и переопределяют только `amount`. Название акции
каждый подкласс собирает сам и передаёт в `__init__` базового класса.

<Exercise id="percent" title="Процент от суммы">
Объявите подкласс `PercentDiscount`: `PercentDiscount(10)` — скидка 10 %, процент хранится в атрибуте
`percent`, название — `"скидка 10 %"`. `amount(cart)` — процент от `cart.subtotal`, округлённый до целых.

<Hint>`super().__init__(f"скидка {percent} %")`, затем `self.percent = percent`.</Hint>
</Exercise>

<Exercise id="fixed" title="Фиксированная сумма">
Объявите подкласс `FixedDiscount`: `FixedDiscount(150)` — минус 150 ₽, сумма в атрибуте `value`, название —
`"минус 150 ₽"`. Скидка не может быть больше суммы корзины: для корзины на 100 ₽ `amount` — 100.

<Hint>Меньшее из двух чисел — `min(self.value, cart.subtotal)`.</Hint>
</Exercise>

## Шаг 3. Каждый n-й в подарок

<Exercise id="buy-n" title="Каждый n-й бесплатно">
Объявите подкласс `BuyNGetOne`: `BuyNGetOne("Латте", 3)` — каждый третий латте в подарок, название —
`"каждый 3-й Латте в подарок"`, атрибуты `name` и `n`. `amount(cart)`: сколько товаров с таким названием
в корзине, столько раз по `n` целиком — столько бесплатных; скидка — их число, умноженное на цену этого
товара. Нет товара в корзине — 0.

<Hint>Товары с нужным названием — `[p for p in cart.items if p.name == self.name]`; бесплатных — `len(...) // self.n`.</Hint>
<Hint>Цену возьмите у любого из найденных товаров, например у первого, — но только если список не пуст.</Hint>
</Exercise>

## Шаг 4. Касса

<Exercise id="checkout" title="К оплате и лучшая акция">
Напишите две функции. `to_pay(cart, discount)` — сумма к оплате: `subtotal` корзины минус скидка.
`best_discount(cart, discounts)` — та скидка из списка, которая для этой корзины даёт больше всего рублей.
Ни одна функция не должна проверять класс скидки.

<Hint>Обе функции вызывают только `discount.amount(cart)` — это и есть полиморфизм.</Hint>
</Exercise>

## Шаг 5. Корзина Анны

<Exercise id="anna" title="Что выгоднее Анне">
В корзине Анны три латте, два круассана и чай. Для трёх акций из списка `offers` сохраните в `prices` словарь
«название акции → сумма к оплате», а в `best` — название самой выгодной акции.

<Hint>Название акции — `str(discount)`; сумма — `to_pay(anna, discount)`.</Hint>
</Exercise>

Посмотрите на функции кассы: в них нет ни одного `isinstance`. Новая акция — скажем, «скидка на выпечку» —
это новый подкласс с методом `amount`, а `to_pay` и `best_discount` не меняются. Но базовый `Discount` пока
можно создать и «забыть» переопределить в подклассе `amount` — касса молча посчитает скидку 0. Как запретить
