Треки описаны признаками `[темп, энергичность, акустичность]`. Для обучающей выборки жанры известны. Напишите `classify(train, query, k)`: функция определяет жанр трека `query` голосованием `k` ближайших соседей (евклидово расстояние).

## Пример

```python
train = [
    ([120, 0.9, 0.1], "электроника"),
    ([125, 0.8, 0.2], "электроника"),
    ([70, 0.3, 0.9], "фолк"),
    ([80, 0.4, 0.8], "фолк"),
    ([118, 0.7, 0.3], "поп"),
]
classify(train, [122, 0.85, 0.15], 3)   # "электроника"
```

## Правила

- При равных расстояниях ближе считается трек, который раньше в `train`.
- Если голоса разделились поровну, побеждает жанр, у которого есть **самый близкий** сосед среди лидеров.
- `1 <= k <= len(train)`.
