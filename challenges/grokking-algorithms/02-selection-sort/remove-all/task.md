Лента заказов — односвязный список кодов. Функция `remove_all(head, code)` удаляет **все** узлы с кодом `code` (отменённые заказы) и возвращает новую голову. В функции две ошибки — найдите и исправьте их.

## Примеры

```python
# 7 → 0 → 3 → 0 → 0 → 5
remove_all(head, 0)   # 7 → 3 → 5
# 0 → 0 → 1
remove_all(head, 0)   # 1
```
