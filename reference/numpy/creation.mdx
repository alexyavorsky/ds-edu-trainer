## Коротко

- Из данных: `np.array(список)`; `np.asarray(x)` не копирует, если `x` уже массив.
- Заполненные: `zeros`, `ones`, `full(shape, значение)`, `empty` (не заполняет — там мусор).
- Форма передаётся **кортежем**: `np.zeros((2, 3))`.
- Диапазоны: `arange(start, stop, step)` — как `range`, `stop` не входит; `linspace(start, stop, num)` — ровно `num` точек, конец входит.
- `*_like(a)` создаёт массив той же формы и типа, что `a`.

## Подводные камни

<Pitfall title="arange с дробным шагом">

Из-за погрешности float последняя точка может попасть в диапазон, хотя `stop` не должен входить. Для дробных сеток используйте `linspace` — там число точек задано явно.

<Pitfall title="Форма без скобок">

`np.zeros(2, 3)` читается как «2 элемента типа 3». Форму двумерного массива передавайте кортежем: `np.zeros((2, 3))`.

<Pitfall title="empty не значит «нули»">

`np.empty` только выделяет память и не заполняет её: в массиве может оказаться что угодно, в том числе нули — на это нельзя полагаться. Используйте его, только если сразу перезапишете все элементы.

</Pitfall>
