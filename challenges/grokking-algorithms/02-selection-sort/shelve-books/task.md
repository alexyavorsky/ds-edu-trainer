Книги на полке нужно расставить по возрастанию номеров, переставляя их прямо на полке — без второй полки (нового списка). Сортировка выбором на месте: на шаге `i` ищем самую маленькую книгу среди стоящих на местах `i…n-1` и меняем её местами с книгой на месте `i`. Допишите `shelve(books)`: функция сортирует список на месте и возвращает число обменов. Пропуски помечены `# TODO`.

## Пример

```python
books = [42, 19, 3, 7]
shelve(books)   # 3
books           # [3, 7, 19, 42]
```

## Правила

- Если минимальная книга уже стоит на месте `i`, обмена нет.
- При равных номерах берётся первая по порядку книга.

## Ограничения

- Без `sorted` и `.sort()`.
