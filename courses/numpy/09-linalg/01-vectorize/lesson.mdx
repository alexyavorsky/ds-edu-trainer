Весь курс мы заменяли циклы операциями над массивами: `prices * 0.9` вместо цикла по ценам, маска вместо
`if` в цикле. Это называют **векторизацией** (vectorization): операция записывается для всего массива, а цикл
по элементам выполняет NumPy — внутри, в десятки и сотни раз быстрее цикла на Python. В этом уроке — последние недостающие
кусочки: математические функции и приёмы, которыми переписывают любой цикл.

## Математика поэлементно

Функции модуля `math` из обычного Python работают с одним числом. У NumPy есть такие же, но для массивов —
применяются к каждому элементу:

- `np.sqrt` — квадратный корень;
- `np.abs` — модуль числа (без знака);
- `np.log10` — десятичный логарифм: в какую степень нужно возвести 10, чтобы получить число (`log10(1000) = 3`);
- `np.log` — натуральный логарифм, `np.exp` — обратная ему экспонента.

## Поэлементный максимум: np.maximum

`np.maximum(a, b)` сравнивает два массива **поэлементно** и берёт большее в каждой позиции. Вместо массива может
быть число — тогда оно работает как нижняя граница. `np.minimum` — то же с меньшим:

<Demo id="maximum" title="np.maximum и np.minimum" />

<Mistake title="np.max вместо np.maximum">
`np.max(a, 0)` выглядит как «максимум из `a` и нуля», но второй аргумент `np.max` — это `axis`. Результат —
одно число, наибольшее в массиве, и ошибки нет. Поэлементный максимум — только `np.maximum`.
</Mistake>

<Quiz id="max-quiz">
Что выведет `print(np.max(np.array([-2, 5, -1]), 0))`?

- [ ] `[0 5 0]`
- [x] `5`
- [ ] ошибку

<Explain>Второй аргумент `np.max` — ось: `np.max(a, 0)` — это `a.max(axis=0)`, самый большой элемент. Замену отрицательных нулём делает `np.maximum(a, 0)`.</Explain>
</Quiz>

## Итоги

- Векторизация — операция для всего массива сразу, цикл по элементам выполняет NumPy.
- `np.sqrt`, `np.abs`, `np.log10`, `np.log`, `np.exp` применяются к каждому элементу.
- `np.maximum(a, b)` и `np.minimum(a, b)` — поэлементно; с числом — граница снизу или сверху.
- `np.max(a, 0)` — не поэлементный максимум, а `axis=0`.
- Цикл с `if` переписывается маской, `np.where`, `np.maximum`, `np.minimum`, `np.clip`.
