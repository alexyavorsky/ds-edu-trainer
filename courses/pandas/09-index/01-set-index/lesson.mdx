С индексом мы встречаемся с первого урока, но до сих пор он был в основном номерами строк. Иногда метки
оказывались осмысленными — города после группировки, названия показателей в `describe`, — и тогда по ним
было удобно искать. Пора взять это в свои руки: назначать индекс самим.

Столбец `product_id` переехал влево: теперь это подписи строк, а его название стоит над индексом. Искать

## Срез по меткам

Индексом может быть любой столбец. Возьмём название товара:

<Demo id="by-name" title="Цена по названию" />

Если индекс **отсортирован**, по нему работают срезы меток — в том числе по неполным значениям. Срез
от `"Т"` до `"Ф"` вернёт все названия, которые по алфавиту лежат между этими буквами:

<Demo id="sorted-slice" title="Товары от Т до Ф" />

«Френч-пресс» и «Фильтры» не попали: по алфавиту они идут **после** строки `"Ф"` — как в словаре слово
«фильтр» стоит после буквы «ф». Поэтому для «всех товаров на К» правая граница — следующая буква, `"Л"`.

На неотсортированном индексе такой срез вызовет ошибку — pandas не сможет определить, где начинается и где
кончается диапазон. Сначала `sort_index()`.

</Exercise>

## Когда метки повторяются

Метки индекса не обязаны быть уникальными. Сделаем индексом номер заказа — а в заказе бывает несколько строк:

<Demo id="dup-index" title="Индекс с повторами" />

`loc[10001]` вернул **таблицу** из двух строк — всех с этой меткой. Удобно: «покажи заказ 10001» — одна
короткая запись. Но есть подвох: результат меняет тип в зависимости от данных.

<Demo id="dup-one" title="Две строки — таблица, одна строка — Series" />

Если метка встречается один раз, `loc` возвращает строку как Series, если несколько — таблицу. Код, написанный
в расчёте на одно, сломается на другом. Поэтому индекс с повторами хорош для просмотра, а для расчётов
надёжнее уникальный ключ — или обычные столбцы и `groupby`.

<Exercise id="order" title="Один заказ">
Сохраните в `order_10140` строки заказа с номером 10140, в `n_lines` — их число, в `order_sum` — сумму заказа
(цена × количество по всем его строкам). Затем верните номер заказа в столбцы: сохраните в `flat` таблицу
`orders` с обычным индексом.

<Hint>`orders.loc[10140]` — все строки с этой меткой.</Hint>
<Hint>`orders.reset_index()` — без `drop=True`, иначе номера заказов пропадут.</Hint>
</Exercise>

## Итоги

- `set_index("столбец")` делает столбец индексом; `reset_index()` возвращает его в столбцы.
- `таблица.loc[метка]` — строка по метке; `таблица.loc[метка, "столбец"]` — ячейка.
- `index_col="столбец"` в `read_csv` назначает индекс при загрузке.
- Срезы меток работают на отсортированном индексе; конец среза входит.
- Индекс может содержать повторы — тогда `loc` возвращает несколько строк.
