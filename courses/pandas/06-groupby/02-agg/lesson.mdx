Один показатель редко рассказывает всё. О городе хочется знать и выручку, и число заказов, и средний чек.
Можно написать три группировки подряд — а можно одну.

## Несколько итогов одного столбца

Метод `agg` (aggregate, «свести») после группировки принимает список названий функций — строками:

<Demo id="list" title="Сумма, среднее и число значений выручки по городам" />

Получилась таблица: строки — группы, столбцы — показатели. С ней работают как с любой таблицей:

<Demo id="list-use" title="Ячейка и столбец результата" />

Названия функций — те же, что у методов: `"sum"`, `"mean"`, `"median"`, `"min"`, `"max"`, `"count"`,
`"nunique"`, `"std"`, `"size"`.

<Exercise id="prices" title="Цены по категориям">
Сохраните в `price_stats` наименьшую, наибольшую и среднюю цену (`price`) по каждой категории — столбцы
`min`, `max`, `mean`. В `widest` сохраните название категории с наибольшей разностью между наибольшей
и наименьшей ценой.

<Hint>`orders.groupby("category")["price"].agg(["min", "max", "mean"])`.</Hint>
<Hint>Разность столбцов — Series: `price_stats["max"] - price_stats["min"]`; метка наибольшего — `idxmax()`.</Hint>
</Exercise>

## Разные столбцы — свои названия

Чаще показатели считаются по **разным** столбцам: сумма выручки, число разных заказов, средняя цена. Для этого
есть **именованная агрегация**: в `agg` перечисляют новые столбцы в виде
`название=("исходный столбец", "функция")`.

<Demo id="named" title="Три показателя по трём столбцам" />

Столбец после `groupby` здесь не выбирают — он указан внутри каждой пары. Названия новых столбцов вы
придумываете сами; пишутся они без кавычек, как имена параметров.

Результат — обычная таблица, в которую можно добавить вычисляемый столбец:

<Demo id="named-calc" title="Средний чек по городам" />

<Quiz id="shape-quiz">
Что выведет `print(orders.groupby("channel")["revenue"].agg(["sum", "mean"]).shape)`?

- [ ] `(2, 3)`
- [x] `(3, 2)`
- [ ] `(2448, 2)`

<Explain>Строки результата — группы: каналов три. Столбцы — показатели: их два, `sum` и `mean`. `shape` — сначала строки, потом столбцы: `(3, 2)`.</Explain>
</Quiz>

## Группировка по двум столбцам

Если передать в `groupby` список столбцов, группой станет каждое **сочетание** их значений:

<Demo id="two-keys" title="Выручка по парам «город, канал»" />

Слева теперь два столбца подписей — у индекса **два уровня**: город и канал. Название города напечатано один
раз на всю свою группу строк. Такой индекс называют `MultiIndex`.

Значение достают по паре меток в круглых скобках. Если указать только первую метку, вернётся вся её группа:

<Demo id="two-keys-loc" title="Одна пара и весь город" />

Пять городов и три канала дают 15 групп, а сумма по ним — всё та же выручка года. Названия уровней
хранит атрибут `index.names`:

<Demo id="two-keys-len" title="Групп 15, итог прежний, уровни — city и channel" />

Порядок столбцов в списке задаёт порядок уровней: `["city", "channel"]` — сначала города, внутри них каналы.

<Exercise id="pairs" title="Город и категория">

## Итоги

- `.agg(["sum", "mean"])` — несколько итогов одного столбца; результат — таблица.
- `.agg(название=("столбец", "функция"), ...)` — показатели по разным столбцам со своими названиями.
- `groupby(["a", "b"])` — группы по сочетаниям; у результата индекс из двух уровней.
- Значение по двум уровням — `результат.loc[("метка a", "метка b")]`.
