Таблицу с продажами по месяцам можно записать двумя способами. В **широком** формате каждый месяц — отдельный
столбец. В **длинном** — месяц записан значением в столбце, и на каждую пару «город, месяц» приходится своя
строка.

<MeltPivotDiagram />

Данные одни и те же, форма разная. Широкая таблица компактна, её удобно читать. Длинная удобна для расчётов:
по столбцу `month` можно группировать и фильтровать — а по названиям столбцов нельзя. Поэтому данные
из отчётов и электронных таблиц, которые обычно приходят широкими, перед анализом часто «расплавляют».

## melt: из широкой в длинную

<Demo id="wide" title="Широкая таблица: месяцы в столбцах" />

Метод `melt` («расплавить») превращает столбцы в строки:

<Demo id="melt" title="Длинная таблица: строка на каждую пару «город, месяц»" />

- `id_vars` — столбцы, которые остаются как есть: они **определяют** наблюдение (здесь город);
- все остальные столбцы «плавятся»: их названия уходят в один новый столбец, значения — в другой;
- `var_name` и `value_name` — названия этих двух новых столбцов.

Было 2 строки × 2 столбца с числами — стало 4 строки: по одной на каждую ячейку.

## pivot и pivot_table

Названия похожи, и параметры те же — `index`, `columns`, `values`. Разница одна, но важная: `pivot` только
**переставляет** значения и ничего не считает. Поэтому каждой паре «строка, столбец» должно соответствовать
ровно одно значение. В полной ведомости у каждого студента по каждому предмету две оценки — за два семестра:

<Demo id="grades" title="Ведомость в длинном формате" />

<Demo id="pivot-dup" title="Два значения на одну ячейку" />

<Mistake title="Index contains duplicate entries, cannot reshape">
`pivot` не знает, какое из двух значений положить в ячейку, и отказывается работать. Либо сначала оставьте
по одному значению на ячейку (например, отфильтруйте один семестр), либо возьмите `pivot_table` — она
свернёт несколько значений функцией `aggfunc`.
</Mistake>

Правило простое: **переставить** — `pivot`, **посчитать** — `pivot_table`.

<Quiz id="pivot-quiz">
```python
t = pd.DataFrame({"who": ["a", "a", "b", "b"], "what": ["x", "y", "x", "y"], "n": [1, 2, 3, 4]})
print(t.pivot(index="who", columns="what", values="n").shape)
```

Что выведет этот код?

- [ ] `(4, 3)`
- [x] `(2, 2)`
- [ ] `(2, 3)`

<Explain>В строках — разные значения `who` (a и b), в столбцах — разные значения `what` (x и y). Таблица 2 × 2; столбец `who` ушёл в индекс и в число столбцов не входит.</Explain>
</Quiz>

## Итоги

- Широкий формат — значения признака в названиях столбцов; длинный — в отдельном столбце.
- `melt(id_vars=..., var_name=..., value_name=...)` — из широкого в длинный.
- `pivot(index=..., columns=..., values=...)` — из длинного в широкий; требует одно значение на ячейку.
- `pivot_table` делает то же, но сворачивает несколько значений функцией `aggfunc`.
- Для расчётов удобнее длинная таблица, для показа — широкая.
