«Сколько выручки принёс **каждый** город?», «какой средний чек **по каждому** каналу?», «сколько дождливых
дней **в каждом** месяце?» Слова «каждый» и «по каждому» — признак самой частой операции в анализе данных:
группировки.

Запись читается слева направо, по шагам:

1. `sales.groupby("city")` — **разделить** строки на группы: в одну группу попадают строки с одинаковым
   значением `city`.
2. `["cups"]` — взять в каждой группе столбец, который будем считать.
3. `.sum()` — **посчитать** итог в каждой группе и **объединить** итоги в один результат.

Результат — Series. Его метки — значения столбца, по которому группировали, отсортированные по порядку;
значения — итоги групп:

<Mistake title="среднее по строкам — не средний чек">
`orders.groupby("channel")["revenue"].mean()` — средняя выручка **строки**, а строка — это одна позиция заказа.
Средний чек — выручка, делённая на число заказов. Прежде чем брать `mean`, спросите себя, что значит одна
строка.
</Mistake>

## size и count

Сколько строк в каждой группе? Для этого есть два похожих метода, и разница между ними важна:

- `size()` — число **строк** в группе; столбец выбирать не нужно;
- `count()` — число **непустых значений** выбранного столбца.

<Demo id="size-count" title="Дней в году и дней с известной температурой" />

В Казани 365 строк, но `temp_max` известна только в 363: два пропуска. Если пропусков нет, числа совпадают —
и поэтому ошибку легко не заметить.

## Итоги

- `таблица.groupby("ключ")["столбец"].sum()` — разделить по ключу, взять столбец, посчитать итог в каждой
  группе.
- Результат — Series: метки — значения ключа, значения — итоги.
- Итог может быть любым: `sum`, `mean`, `max`, `count`, `nunique`…
- `size()` — строк в группе, `count()` — непустых значений столбца.
- Сумма по группам должна сходиться с общей суммой — проверяйте.
