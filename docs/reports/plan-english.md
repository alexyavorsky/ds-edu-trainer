# Отчёт: планирование направления «Английский» (0.2) и формат упражнений не на Python (0.3)

Ветка `plan-english`. Платформу не менял; изменения для П2 — в разделе «Нужно от платформы» плана.

## Сделано

- `docs/ENGLISH_PLAN.md`:
  - С4 — 88 статей в 18 разделах (A1 18 · A2 22 · B1 32 · B2 13 · C1 3), у каждой slug, заголовок, уровень,
    содержание, контрасты и связи; индекс по уровням; формат статьи (frontmatter с `cefr`, `contrasts`,
    `patterns`; виды article / contrast / overview; обязательные разделы; компоненты `Examples`, `Formula`,
    `Fix`, `Level`); проверки валидатора; объём, готовность, первая треть (разделы 1–4 и 9 + 3 статьи).
  - К2 — 14 модулей, 79 уроков (65 обучающих, 10 повторений, 3 контрольные, входная проверка), у уроков —
    ссылки на статьи С4 (все существуют: сверено скриптом); педагогика, повторение в трёх слоях, формат урока;
    первая треть — уровень A1–A2 (модули 0–4, 27 уроков).
  - 0.3 — `exercises.toml` рядом с `lesson.mdx` + `<Practice id>`; виды gap, choice, order, transform,
    find-error, match (translate — вторая очередь); поля; нормализация (типографика, пробелы, регистр,
    пунктуация loose/strict, сокращения equal/strict с порождением кратких форм из полных для 's/'d,
    несколько пропусков — сравнение целого предложения); объяснения после ответа; прогресс совместимо с
    `edu:course:v1` + ключи `edu:drill:v1`, `edu:test:v1`; режим без JS; проверки валидатора; слепое решение
    (`--blind-export` / `--blind-check`).
  - «Нужно от платформы» — 17 пунктов.
- `docs/glossary/english.md` — названия времён (английские, с обоснованием), ~55 терминов с нежелательными
  вариантами, обозначения формул, британский вариант как основной, оформление примеров и перевода, список слов
  для проверки валидатором.
