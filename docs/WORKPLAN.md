# Журнал масштабного обновления

Справочники ООП, алгоритмов, Git и грамматики английского; задачи NumPy, pandas и ООП; курсы ООП и английского;
ускорение CI и расширения платформы. Оркестратор (главный чат) планирует, запускает агентов, принимает
результаты и сливает потоки; контент пишут агенты в своих ветках и worktree.

**Если чат оборвался:** новый чат читает этот файл сверху вниз — таблицу потоков, «Следующие шаги» и
журнал — и продолжает с первого незавершённого шага. Агенты описаны в `.claude/agents/` (stream-writer —
medium, stream-reviewer — medium, grammar-reviewer — high). Подробные отчёты потоков — `docs/reports/`.

## Правила (кратко, из задания)

- Не больше 3–4 потоков одновременно; справочник направления — раньше курса и задач того же направления.
- Поток = ветка от main + PR (gh доступен). Слияние — когда CI зелёный, ревью пройдено, найденное исправлено,
  отчёт написан. Сливаю по одному, после каждого проверяю CI на main; упал — сначала чиню main.
- Общие файлы (навигация, коллекции, раннер, воркер, CI, схемы) меняет только оркестратор или поток
  платформы. Контентный поток описывает нужное изменение в отчёте («Нужно от платформы»).
- Новый раздел при слиянии помечается «бета» (одно поле метаданных); снимает пометку пользователь.
- Ревью — отдельным агентом, по ходу (после первой трети) и в конце; после исправлений — повторное ревью
  изменённых мест. Для ООП и английского — общий глоссарий `docs/glossary/<направление>.md`.

## Решения без меня

1. **Контекст pandas-course.** PR #3 уже слит в main (2026-09-30). Пункт 0.1 делается новой веткой
   `pandas-finish` от main, а не в pandas-course. Варианты: вернуть ветку pandas-course — нет смысла, она слита.
2. **Уровень усилий агентов** задан определениями в `.claude/agents/` (поле `effort`): исполнители потоков и
   CI — medium, рецензенты — medium, рецензент английской грамматики — high. Определения в репозитории — чтобы
   новый чат продолжил с теми же агентами.
3. **Репозиторий публичный** — минуты GitHub Actions бесплатны без лимита 2000; расчёт расхода для приватного
   репозитория всё равно будет в отчёте П1 (на случай смены видимости).

4. **Агенты запускаются как general-purpose** с брифом «прочитай `.claude/agents/<роль>.md`»: определения из
   `.claude/agents/` не подхватываются в уже открытом сеансе. Поле `effort` в определениях сработает в новом
   чате; в этом — уровень задаётся словами в брифе. Вариант «ждать перезапуска» противоречит работе без остановок.
5. **Планирование 0.2 делят три агента** (ООП; английский + формат 0.3; алгоритмы + Git + задачи NumPy/pandas):
   каждый пишет свой `*_PLAN.md` и раздел «Нужно от платформы» — из них собирается объём П2.

6. **Решения по открытым вопросам планов** записаны в каждом `*_PLAN.md` («Решения по открытым вопросам»).
   Главные: группы направлений «Python и алгоритмы», «Данные», «Git», «Английский» — внутри вкладок
   «Задачи · Курсы · Справочник», а не отдельными вкладками; курс ООП — 35 уроков (свой «Python-минимум»,
   итоговый проект двумя уроками); CPython-проверка на 3.14, если закреплённые NumPy/pandas ставятся;
   git 2.54.0 с выводом на английском; раздела про GitHub нет; вид упражнений translate и «Проверьте себя»
   в статьях грамматики — не в этой волне.
7. **Р1 (ревью NumPy) и П1 (CI) стартуют раньше слияния 0.1**: Р1 не зависит от платформы, П1 начинает с
   замеров. П1 подтягивает main после слияния 0.1 (оба трогают validate_browsers.ts). Так занято 3 из 4 мест.

8. **Лимит API (2026-10-01 ночью)** оборвал 0.1, П1 и Р1 — все три продолжены с места обрыва через SendMessage.
