## Коротко

- Пропуск в числах и строках — `NaN`; в nullable-типах (`Int64`, `boolean`, `string`) — `pd.NA`. `None` при создании превращается в одно из них.
- `isna()` / `notna()` — маски; `isna().sum()` — сколько пропусков в каждом столбце.
- `fillna(значение)` — заполнить; словарь — своё значение для каждого столбца. `ffill()` / `bfill()` — предыдущим / следующим значением.
- `dropna()` удаляет строки с пропусками; `subset` — смотреть только на эти столбцы, `thresh` — сколько непустых значений нужно, чтобы оставить строку.
- `interpolate()` — восстановить значения между известными (линейно, по времени и т. д.).
