Мелодии записаны строками нот, например `"CDEFG"`. Общий мотив — самая длинная общая **подпоследовательность**: ноты идут в том же порядке, но не обязательно подряд. Допишите `common_motif_length(a, b)`: функция заполняет таблицу и возвращает длину общего мотива. Пропуски помечены `# TODO`.

## Примеры

```python
common_motif_length("CDEFGAB", "CEGBD")   # 4: C E G B
common_motif_length("AAAA", "AA")         # 2
common_motif_length("CDE", "FGA")         # 0
```
