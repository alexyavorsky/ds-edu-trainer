До сих пор все атрибуты записывались в `__init__` через `self` — у каждого экземпляра свои. Но бывают данные,
общие для всех экземпляров класса: валюта цен, предельная скидка, счётчик созданных заказов. Их хранят
в самом классе.

## Атрибут класса

Переменная, объявленная прямо в теле класса (не внутри метода), — **атрибут класса** (class attribute).
Он один на весь класс, и его видно и через класс, и через любой экземпляр. Постоянные значения — константы
класса — называют заглавными буквами:

## Где Python ищет атрибут

Атрибуты экземпляра хранятся в словаре `__dict__` самого экземпляра, атрибуты класса — в `__dict__` класса.
Когда вы пишете `latte.CURRENCY`, Python сначала ищет имя у экземпляра, а не найдя — у его класса:

<Demo id="lookup" title="Словари экземпляра и класса" />

Поэтому метод может читать константу как `self.CURRENCY`: у экземпляра её нет, и Python найдёт её в классе.

<Exercise id="max-discount" title="Предельная скидка">
Допишите класс `Product`. Добавьте атрибут класса `MAX_DISCOUNT = 30` — больше 30 % скидки кофейня не даёт.
Метод `discounted(percent)` возвращает цену со скидкой, округлённую до целых, но если `percent` больше
`MAX_DISCOUNT`, применяется `MAX_DISCOUNT`: `Product("Латте", 200).discounted(50)` — 140.

<Hint>Константа объявляется в теле класса, рядом с методами: `MAX_DISCOUNT = 30`.</Hint>
<Hint>Скидка с учётом предела — `min(percent, self.MAX_DISCOUNT)`.</Hint>
</Exercise>

## Запись атрибута через экземпляр

Читать атрибут класса через экземпляр можно, а вот **запись** через экземпляр работает иначе:
`latte.CURRENCY = "$"` создаёт атрибут *у экземпляра*, и он закрывает собой атрибут класса — только для этого
экземпляра. Изменить общее значение можно только через класс:

<Demo id="shadow" title="Запись через экземпляр и через класс" />

<Quiz id="lookup-quiz">
Что напечатает этот код?

```python
class Cup:
    size = "M"

a = Cup()
b = Cup()
a.size = "L"
Cup.size = "S"
print(a.size, b.size)
```

- [ ] `L L`
- [x] `L S`
- [ ] `S S`

<Explain>`a.size = "L"` создал атрибут у экземпляра `a`, и он находится первым. У `b` своего `size` нет, поэтому `b.size` — это атрибут класса, а его изменили на `"S"`.</Explain>
</Quiz>

Из-за этого правила частая ошибка — счётчик в атрибуте класса, который увеличивают через `self`:

<Demo id="counter-bug" title="self.count += 1 не меняет счётчик класса" />

<Mistake title="self.count += 1 вместо Order.count += 1">
`self.count += 1` читает `count` из класса, прибавляет 1 и **записывает результат в экземпляр**. Атрибут
класса остаётся прежним, а у каждого заказа появляется свой `count`, равный 1. Общее значение меняют через
имя класса: `Order.count += 1`.
</Mistake>

<Exercise id="numbering" title="Номера заказов">
Объявите класс `Order`. Атрибут класса `created` — сколько заказов создано, вначале 0. Каждый новый заказ
увеличивает `created` на 1 и получает атрибут экземпляра `number` — свой порядковый номер: первый заказ —
номер 1, второй — 2 и так далее.

<Hint>В `__init__`: `Order.created += 1`, затем `self.number = Order.created`.</Hint>
</Exercise>

## Общий список — общая беда

Атрибут класса со списком тоже один на всех. Если экземпляры добавляют в него элементы, добавляют они в
**один и тот же** список:

<Demo id="shared-list" title="Две корзины с одним списком" />

<Mistake title="список в атрибуте класса общий для всех экземпляров">
`items = []` в теле класса создаётся один раз — когда объявляется класс. Все корзины видят этот единственный
список, и товар, положенный в одну, оказывается во всех. Список, который у каждого экземпляра свой, создают
в `__init__`: `self.items = []`.
</Mistake>

<Exercise id="fix-cart" title="Починить корзину">
В заготовке — класс `Cart` с ошибкой из демонстрации выше. Исправьте его так, чтобы у каждой корзины был свой
список `items`, а метод `add(name)` добавлял товар только в свою корзину.

<Hint>Уберите `items = []` из тела класса и создайте список в `__init__`.</Hint>
</Exercise>

Правило простое: атрибут класса — для того, что действительно общее и **не меняется** через экземпляры
(константы, настройки). Всё, что у каждого объекта своё, — в `__init__` через `self`.
