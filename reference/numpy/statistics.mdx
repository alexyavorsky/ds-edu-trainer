## Коротко

- `mean` — среднее, `median` — медиана (устойчива к выбросам).
- `std` и `var` по умолчанию делят на `n` (`ddof=0`). Выборочная оценка — `ddof=1`; так по умолчанию считает pandas.
- `percentile(a, q)` — перцентили в процентах (0–100), `quantile(a, q)` — то же в долях (0–1). Способ интерполяции задаёт `method`.
- `average(a, weights=w)` — взвешенное среднее.
- `corrcoef(x, y)` возвращает **матрицу** 2 × 2; сам коэффициент — элемент `[0, 1]`. Ковариация — `cov`.
- Все функции принимают `axis`; с пропусками — `nanmean`, `nanmedian`, `nanpercentile`…

## Синтаксис

<Syntax code={`np.mean(a, axis=None), np.median(a, axis=None)
np.std(a, axis=None, ddof=0), np.var(a, ddof=0)
np.percentile(a, q, axis=None, method="linear")   # q в 0–100
np.quantile(a, q, method="linear")                # q в 0–1
np.average(a, weights=None)
np.corrcoef(x, y)[0, 1]`} />
