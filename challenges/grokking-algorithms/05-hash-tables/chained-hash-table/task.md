Соберите хеш-таблицу своими руками. Массив из `size` корзин, ключ попадает в корзину `hash(key) % size`, коллизии разрешаются цепочками: в каждой корзине лежит список пар. Допишите методы `put` и `get`. Пользоваться встроенным `dict` внутри нельзя. Пропуски помечены `# TODO`.

## Пример

```python
table = ChainedHashTable(size=4)
table.put("яблоко", 120)
table.put("молоко", 90)
table.put("яблоко", 110)   # обновление, а не второй ключ
table.get("яблоко")        # 110
table.get("хлеб", 0)       # 0
len(table)                 # 2
```
