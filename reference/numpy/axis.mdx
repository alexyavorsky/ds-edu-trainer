## Коротко

- `axis` — номер оси, **вдоль которой** идёт вычисление. Эта ось исчезает из формы результата.
- В двумерном массиве `axis=0` идёт вниз по строкам → одно значение **на каждый столбец**; `axis=1` идёт вдоль строки → одно значение **на каждую строку**.
- `axis=None` (по умолчанию) — по всему массиву; `axis=-1` — последняя ось; можно передать кортеж осей.
- `keepdims=True` оставляет свёрнутую ось длиной 1 — результат удобно [транслировать](/reference/numpy/broadcasting) обратно на исходный массив.
- Накопительные `cumsum`, `cumprod` форму не меняют, а без `axis` вытягивают массив в одну строку.

## Синтаксис

<Syntax code={`a.sum(axis=0)                # по столбцам: (3, 4) → (4,)
a.sum(axis=1)                # по строкам:  (3, 4) → (3,)
a.mean(axis=1, keepdims=True)  # (3, 4) → (3, 1)
a.argmax(axis=1)             # индекс максимума в каждой строке
a.cumsum(axis=1)             # нарастающий итог, форма та же
a.sum(axis=(0, 2))           # сразу по нескольким осям`} />

## Подводные камни

<Pitfall title="«axis=0 — это по строкам?»">

Путаница из-за слов: `axis=0` **сворачивает** строки, поэтому ответ получается для каждого столбца. Проверка без запоминания: посмотрите на форму — из `(3, 4)` при `axis=0` исчезает 3, остаётся `(4,)`. В pandas смысл тот же: `df.sum(axis=0)` — сумма каждого столбца.

</Pitfall>

<Pitfall title="Оси, которой нет">

Оси нумеруются с нуля: у двумерного массива только 0 и 1 (или −1 и −2).
