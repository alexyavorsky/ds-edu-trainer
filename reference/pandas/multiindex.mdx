## Коротко

- MultiIndex — метка строки из нескольких частей (уровней). Появляется после `set_index([a, b])`, `groupby([a, b])`, `pivot_table`, `stack`.
- `df.loc["Омск"]` — все строки внешнего уровня; полная метка — кортеж `df.loc[("Омск", "фев")]`.
- `xs("янв", level="month")` — срез по любому уровню.
- `pd.IndexSlice` — срезы по нескольким уровням сразу; индекс должен быть отсортирован (`sort_index()`).
- `swaplevel`, `droplevel`, `get_level_values` — работа с уровнями; `reset_index()` — обратно в плоскую таблицу.

## Синтаксис

<Syntax code={`df.set_index(["a", "b"])
df.loc["x"], df.loc[("x", "y")], df.loc[("x", "y"), "col"]
df.xs("y", level="b")
idx = pd.IndexSlice; df.sort_index().loc[idx[:, ["y1", "y2"]], :]
df.swaplevel(), df.droplevel("b"), df.index.get_level_values("a")`} />

## Подводные камни

<Pitfall title="Срезы по неотсортированному индексу">

Срез по меткам уровня (`loc["Омск":"Тула"]`, `IndexSlice`) требует отсортированного индекса, иначе `UnsortedIndexError`. Выбор одной метки работает и без сортировки. Вызывайте `sort_index()` перед срезами.
