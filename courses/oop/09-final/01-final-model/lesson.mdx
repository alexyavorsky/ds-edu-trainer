В итоговом проекте вы соберёте кассу «Кофейной лавки» целиком — из классов, которые писали по отдельности
весь курс. Проект в двух уроках. В этом — **модель**: товары, каталог и корзина. В следующем — **правила**:
скидки, оплата, чек и отчёт за день.

Почти всё здесь вы уже делали; новое — в том, чтобы решить, какой инструмент взять для каждой части:

| Часть кассы | Что это | Инструмент |
| --- | --- | --- |
| ошибки | своя иерархия | подклассы `Exception` |
| товар | неизменяемые данные | `@dataclass(frozen=True)` |
| каталог | контейнер товаров | `__len__`, `__contains__`, `__getitem__`, `__iter__` |
| корзина | содержит каталог и строки | композиция, свойство, магические методы |

## Шаг 1. Ошибки кассы

<Exercise id="errors" title="ShopError и UnknownProductError">
Объявите базовое исключение кассы `ShopError` (подкласс `Exception`) и его подкласс `UnknownProductError` —
«товара нет в каталоге».

<Hint>Два класса; тело — `pass`.</Hint>
</Exercise>

## Шаг 2. Товар

<Exercise id="product" title="Product">
Объявите неизменяемый dataclass `Product` с полями `name` (строка), `price` (целое) и `category` (строка, например
`"кофе"`). Цена не больше нуля — `ValueError` при создании. `str(product)` — `"Латте — 220 ₽"`.

<Hint>`@dataclass(frozen=True)`, проверка — в `__post_init__`, текст — в `__str__`.</Hint>
</Exercise>

## Шаг 3. Каталог

<Exercise id="catalog" title="Catalog">
Объявите класс `Catalog`: `Catalog([товар, товар, …])` хранит товары во внутреннем словаре «название → товар».

- `len(catalog)` — число товаров;
- `"Латте" in catalog` — есть ли товар с таким названием;
- `catalog["Латте"]` — товар; если его нет — `UnknownProductError("нет в каталоге: Латте")`;
- `for product in catalog` — товары по алфавиту названий.

<Hint>В `__init__`: `self._products = {p.name: p for p in products}`.</Hint>
<Hint>В `__getitem__` сначала проверьте `name not in self._products` и выбросите своё исключение — иначе словарь выбросит `KeyError`.</Hint>
</Exercise>

## Шаг 5. Корзина

Строка корзины — товар и количество. Это маленький dataclass, он уже готов:

<Demo id="line" title="Строка корзины" />

<Exercise id="cart" title="Cart">
Объявите класс `Cart`: `Cart(catalog)` — пустая корзина, которая **содержит** каталог и берёт товары из него.

- `add(name, qty=1)` — найти товар в каталоге (неизвестный — `UnknownProductError` уходит дальше) и добавить
  строку; если строка с этим товаром уже есть — увеличить её количество, а не добавлять вторую;
- `len(cart)` — число строк, `for line in cart` — строки по порядку добавления;
- свойство `subtotal` — сумма `cost` всех строк.

<Hint>Строки — список `self._lines`; для существующего товара найдите его строку циклом и прибавьте `qty`.</Hint>
<Hint>`Line` изменяемый — `line.qty += qty` работает.</Hint>
</Exercise>

## Шаг 6. Первые заказы

<Exercise id="orders" title="Три корзины">
По списку `requests` — что попросил каждый покупатель — соберите корзины. Сохраните в `subtotals` суммы корзин
по порядку, а в `unknown` — названия, которых нет в каталоге (такие позиции пропускайте, остальное в корзину
кладите).

<Hint>Для каждого покупателя — новая `Cart(catalog)`; для каждой позиции — `try: cart.add(name, qty)`, `except UnknownProductError: unknown.append(name)`.</Hint>
</Exercise>
