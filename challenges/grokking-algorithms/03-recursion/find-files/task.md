Папка задана словарём: ключ — имя, значение — размер файла (`int`) или вложенная папка (`dict`). Допишите функцию `find_files(folder, ext)`: она возвращает полные пути всех файлов с расширением `ext` в порядке обхода. Пропуски помечены `# TODO`.

## Пример

```python
project = {
    "main.py": 120,
    "README.md": 40,
    "utils": {"io.py": 300, "data.csv": 900, "deep": {"cfg.py": 10}},
}
find_files(project, ".py")
# ["main.py", "utils/io.py", "utils/deep/cfg.py"]
```

## Правила

- Пути строятся через `/`, у файлов верхнего уровня префикса нет.
- Порядок — как в словарях: сначала всё содержимое подпапки, потом следующий элемент.
- Подходят только файлы. Папка с именем `old.py` в ответ не попадает, но искать внутри неё нужно.
