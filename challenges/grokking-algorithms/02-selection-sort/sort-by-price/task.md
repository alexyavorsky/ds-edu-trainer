Товары на витрине заданы парами `(название, цена)`. Напишите `sort_by_price(items)`: функция возвращает **новый** список, отсортированный по возрастанию цены, методом сортировки выбором. Товары с одинаковой ценой сохраняют исходный порядок.

## Пример

```python
sort_by_price([("чай", 300), ("мёд", 450), ("сахар", 90), ("кофе", 300)])
# [("сахар", 90), ("чай", 300), ("кофе", 300), ("мёд", 450)]
```

## Ограничения

- Без `sorted`, `.sort()` и `min(...)` с ключом — выбор минимума напишите сами.
- Исходный список не изменяется.
