Функция `cheapest(offers)` должна вернуть индекс самого дешёвого предложения доставки. При равных ценах возвращается первый индекс, для пустого списка — `-1`. В функции две ошибки — найдите и исправьте их.

## Примеры

```python
cheapest([350, 290, 410, 290])  # 1 — первая из двух цен 290
cheapest([500, 400, 300])       # 2
cheapest([])                    # -1
```
