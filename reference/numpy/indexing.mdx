## Коротко

- Индексы начинаются с 0; отрицательные считаются с конца: `a[-1]` — последний элемент.
- Срез `a[start:stop:step]`: `stop` не входит, любую часть можно опустить. `a[::-1]` — массив задом наперёд.
- В срез можно присвоить число (запишется во все элементы) или массив той же длины.
- Срез — **представление** (view): это окно в тот же массив, а не копия. Изменение среза меняет исходный массив.
- Индекс за границей — `IndexError`, а срез за границей просто становится короче.

## Синтаксис

<Syntax code={`a[i]              # один элемент
a[-1]             # последний

a[2:5] = 0        # присваивание в срез
a[2:5].copy()     # независимая копия среза`} />
