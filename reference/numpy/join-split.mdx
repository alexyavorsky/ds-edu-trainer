## Коротко

- `np.concatenate(список, axis)` склеивает по **существующей** оси. Размеры по остальным осям должны совпадать.
- `np.stack(список, axis)` добавляет **новую** ось: из двух `(2, 2)` получается `(2, 2, 2)`. Формы должны совпадать полностью.
- Короткие варианты: `vstack` — одно под другим (векторы становятся строками), `hstack` — рядом, `column_stack` — векторы как столбцы.
- `np.split(a, n)` — на `n` равных частей, `np.split(a, [i, j])` — по индексам разреза. `np.array_split` допускает неравные части.
- Функции принимают **список** массивов, а не несколько аргументов.

## Синтаксис

<Syntax code={`np.concatenate([a, b], axis=0)
np.stack([a, b], axis=0)
np.vstack([a, b]), np.hstack([a, b]), np.column_stack([a, b])
np.split(a, 3, axis=0)            # 3 равные части
np.split(a, [2, 5])               # a[:2], a[2:5], a[5:]
np.array_split(a, 3)              # части могут отличаться на 1`} />
