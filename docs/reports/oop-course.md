# Отчёт: курс «ООП в Python» (К1)

Ветка `oop-course` (от main 4530bfd). Preview: https://ds-edu-trainer-git-oop-course-edu-485b.vercel.app/courses/oop

## Программа — 9 модулей, 35 уроков

По OOP_PLAN.md (К1) с решениями оркестратора: свой урок «Python-минимум», итоговый проект в двух уроках.
25 уроков (с «Python-минимумом») + 10 уроков-проектов (8 мини-проектов и итоговый проект в двух уроках),
137 упражнений, ≈ 12 ч по оценке уроков.

| Модуль | Уроки | Мини-проект |
| --- | --- | --- |
| 1 Первые классы | Python-минимум · Всё в Python — объект · Первый класс · `__init__` и self · Методы | Ценник |
| 2 Состояние объектов | Атрибуты класса и экземпляра · Объекты в списках и ссылки | Корзина |
| 3 Инкапсуляция и свойства | `_` и `__` · Свойства · Сеттер и проверка значений | Карта лояльности |
| 4 Представление и сравнение | `__repr__`/`__str__` · `__eq__` и `__hash__` · Сортировка | Прайс-лист |
| 5 Наследование и полиморфизм | Наследование · super() · Полиморфизм и утиная типизация | Скидки |
| 6 Абстракции и проектирование | Абстрактные классы · classmethod/staticmethod · Композиция | Оплата |
| 7 Контейнеры и операторы | `__len__`/`__getitem__`/`__contains__` · `__iter__` и yield · Операторы | Склад |
| 8 dataclasses и исключения | dataclasses · Настройки dataclass · Свои исключения | Заказ с проверками |
| 9 Итоговый проект «Касса кофейни» | — | Каталог и корзина · Скидки, оплата и чек (+ «Что дальше») |

Сквозной сюжет — касса «Кофейной лавки»: от класса `Product` до программы из девяти классов. Вход — базовый
Python (самопроверка в первом уроке), NumPy и pandas не нужны. Выход и «куда расти» — последний урок.

Отличия от плана: справочника ООП (С1) нет — `reference: []` во всех уроках, ссылок на статьи нет; курс
не зависит от него. Порядок уроков и понятий — по таблицам плана; в мини-проекте модуля 2 — 5 упражнений.

## Платформа (в этой ветке, без них курс не проходит проверку)

| Из OOP_PLAN | Что сделано |
| --- | --- |
| П5 курс без пакета | `course.toml`: `package`/`reference` необязательны, `python = "3.10"`; уроки не грузят NumPy; `output.json.generated` — «Pyodide … · Python 3.14.2»; ноутбук проверяет версию Python |
| П4 версия Python | CI-задание «Курсы» — на Python 3.14 (как Pyodide): тексты встроенных ошибок, которые показывает курс, в 3.10–3.13 другие |
| П6 понятия ООП | `concepts = "python"`: понятия — `class`, `class(Base)`, магические методы, декораторы, `super()`, `isinstance`, `raise`/`raise from`, `yield`, `is`, `NotImplemented`, импорты `модуль.имя`; атрибуты и параметры своих классов понятиями не считаются |
| П11 адреса в выводе | валидатор — ошибка на `at 0x…` в сохранённом выводе |
| П12 заготовка-класс | метод из `...` в заготовке — цель «Класс.метод»: «класс X не объявлен» / «метод X.m пока состоит из ... — допишите его» вместо проваленных тестов (кроме абстрактных методов) |

Не сделано: П8 (ссылка «Задачи по теме» в `module.toml`), П9 (схемы `ClassDiagram`/`MroDiagram`), П10 (группы
направлений и пометка «бета»). Курсы NumPy и pandas после правок проходят проверку без изменений.

Синхронизация с Supabase: новых ключей localStorage курс не добавляет — прогресс и код упражнений в тех же
`edu:course:v1` и `edu:code:v1:<урок>/<упражнение>`, которые уже синхронизируются (`KEY_PATTERN`); id упражнений
подходят под шаблон.
