## Коротко

- Словарь `{"столбец": [значения]}` — самый частый способ; списки должны быть одной длины.
- Список словарей — по записи на строку; отсутствующие ключи становятся `NaN`.
- Из массива NumPy — с явными `columns` и `index`.
- Словарь из Series **выравнивается по индексу**: строки сопоставляются по меткам, а не по порядку.
- `shape` — (строки, столбцы), `columns` — имена столбцов, `index` — метки строк, `dtypes` — типы столбцов.
