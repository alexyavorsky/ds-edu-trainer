Подарочную карту на `total` рублей нужно потратить полностью, купив ровно два разных товара. Напишите `pair_for_card(prices, total)`: функция возвращает индексы `(i, j)` при `i < j` таких, что `prices[i] + prices[j] == total`, или `None`. Если подходящих пар несколько, годится любая.

## Примеры

```python
pair_for_card([700, 1500, 300, 1200], 1500)  # (2, 3): 300 + 1200
pair_for_card([500, 500], 1000)              # (0, 1): два разных товара с одной ценой
pair_for_card([500], 1000)                   # None: один товар нельзя купить дважды
```

## Ограничения

- До 10⁶ товаров, время — O(n): перебор всех пар не подойдёт. Тест на 300 000 товаров разрешает прочитать список до 3 раз.
