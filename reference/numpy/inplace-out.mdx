## Коротко

- `a += b`, `a *= 2` и другие составные операторы меняют массив **на месте**: новый массив не создаётся.
- `a = a + b` создаёт новый массив и переназначает имя; другие ссылки на старый массив его не видят.
- У любой ufunc есть `out=` — куда записать результат. `np.sqrt(a, out=a)` — корень на месте.
- `where=` вместе с `out=` меняет только элементы, где условие истинно.
- Тип массива при операции на месте не меняется: `int += float` — ошибка.

<Pitfall title="Целый массив и дробный результат">

<Pitfall title="Побочные эффекты через представления">
