Кафе на карте — точки с координатами. Функция `nearest(points, query)` возвращает индекс ближайшей к `query` точки по евклидову расстоянию. При равных расстояниях — меньший индекс, для пустого списка — `-1`. В функции две ошибки — найдите и исправьте их.

## Примеры

```python
nearest([[0, 0], [5, 5], [1, 2]], [2, 2])   # 2
nearest([[1, 0], [-1, 0]], [0, 0])          # 0 — ничья, берём меньший индекс
```
