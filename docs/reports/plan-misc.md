# Отчёт: планирование С2, С3, З1, З2 (волна 0.2, ветка `plan-misc`)

Сделано: три плана — `docs/ALGORITHMS_PLAN.md` (С2), `docs/GIT_PLAN.md` (С3), `docs/TASKS_PLAN.md` (З1 и З2).
Контент и платформа не менялись.

## Объёмы
- С2 «Алгоритмы на Python»: 34 статьи (Б 6 · С 22 · П 4 · итоговые 2), ≈ 220 примеров; связь с главами 1–9 «Грокаем».
- С3 «Git»: 30 статей (основы 17 · проблемы 12 · шпаргалка), ≈ 150 примеров-скриптов.
- З1 NumPy: 27 задач в 4 главах; З2 pandas: 27 задач в 4 главах.

## Проверено по ходу
- Детерминизм git (git 2.54, macOS): обёртка `git()` с растущими GIT_AUTHOR_DATE/GIT_COMMITTER_DATE, фиксированный
  автор, `core.abbrev=7`, `LC_ALL=C`, свой HOME — два прогона дают одинаковые хеши и вывод; различаются только
  абсолютные пути временной папки (`To /var/…/server.git`) — их должен заменять валидатор.
- Валидатор справочника уже допускает свои разделы после «Коротко» — формат статей С2 и «Проблем» С3 в него
  укладывается без правок структуры.

## Нужно от платформы (сводно; подробно — в разделах планов)
1. Тема справочника без пакета: `package`/`version` необязательны, свой `prelude` темы, `docs` необязательно,
   браузер не грузит NumPy для такой темы (`packages.ts`).
2. Поле `practice` у статей (id задач) и блок «Задачи» в статье; обратные `refs` → «Задачи по теме».
3. Git: `runtime = "shell"` у темы, `scripts/validate_git.py`, `reference/git/prelude.sh`, показ «команда → вывод»
   без «Запустить», поиск по `.sh`, задание CI со сборкой git фиксированной версии из исходников и кэшем.
4. Задачи тем: `data.py` в копируемом файле, поле `lessons`, строка «Нужно: numpy …» в docstring, эталоны без
   Future/DeprecationWarning, CI с NumPy/pandas (3.12–3.14; пропуск на версиях без колёс), браузеры — Chromium.
5. Общее: `direction` (python · data · git · english) у book/topic/course, `beta = true`, правка ARCHITECTURE.md
   про главы тем.

## Открытые вопросы
- Название темы С2; вывод git на английском (`LC_ALL=C`) и версия git для фиксации.
- `data.py` против генераторов в `tests.py`; тип `complexity` для вопросов не про O(·).
