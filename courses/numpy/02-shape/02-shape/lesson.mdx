Данные часто похожи на таблицу: продажи трёх магазинов по четырём кварталам, оценки учеников по предметам,

и столбцы. Создаётся он из списка списков — каждый внутренний список становится строкой:

## Форма

Главное свойство массива — **форма** (shape): сколько элементов по каждому направлению. У таблицы выше
3 строки и 4 столбца, форма — `(3, 4)`: сначала строки, потом столбцы. `shape` — атрибут, это не метод, и
скобки после него не пишут:

<Demo id="shape" title="shape, ndim, size" />

- `ndim` — число измерений (осей): у простого ряда чисел 1, у таблицы 2.
- `size` — сколько всего элементов: 3 × 4 = 12.
- `len` у таблицы — число строк.

У одномерного массива форма из одного числа: `(5,)`. Запятая здесь — не опечатка, так Python записывает
кортеж (tuple) из одного элемента.

<Quiz id="shape-of">
Какая форма у `np.array([[1, 2, 3], [4, 5, 6]])`?

- [ ] `(3, 2)`
- [x] `(2, 3)`
- [ ] `(6,)`

<Explain>Внешний список содержит два внутренних — это две строки, в каждой по три числа — три столбца. Форма — сначала строки, потом столбцы: `(2, 3)`.</Explain>
</Quiz>

## Строки должны быть одной длины

Таблица прямоугольная: во всех строках одинаковое число элементов. Если длины разные, NumPy откажется делать
двумерный массив:

<Demo id="ragged" title="Строки разной длины" />

<Mistake title="строки разной длины">
`inhomogeneous shape` — «неоднородная форма»: в одной из строк не хватает элемента или есть лишний. Проверьте
данные: обычно одно значение потерялось при копировании.
</Mistake>

## Пустая таблица нужного размера

`np.zeros`, `np.ones` и `np.full` умеют делать и таблицы: вместо числа передают форму — кортеж
`(строки, столбцы)`. Двойные скобки нужны: внутренние — это и есть кортеж формы.

- Двумерный массив — таблица; создаётся из списка списков одинаковой длины.
