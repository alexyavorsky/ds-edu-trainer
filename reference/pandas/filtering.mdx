## Коротко

- Условие над столбцом даёт булеву маску: `df["amount"] > 1000`. `df[маска]` оставляет строки, где `True`.
- Условия объединяют через `&` (и), `|` (или), `~` (не), каждое — **в скобках**. `and` / `or` не работают.
- `isin([...])` — значение из списка, `between(a, b)` — в диапазоне (границы включены).
- `query("amount > 1000 and city == 'Омск'")` — то же строкой; переменные Python — через `@`.
- Фильтр плюс выбор столбцов — `df.loc[маска, ["a", "b"]]`.

## Синтаксис

<Syntax code={`df[df["col"] > 0]
