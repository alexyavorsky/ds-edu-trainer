Даны результаты забега в секундах, возможно с повторами. Напишите `kth_fastest(times, k)`: функция возвращает `k`-й по величине результат (k = 1 — самый быстрый), **не сортируя весь список**. Используйте идею быстрой сортировки: после разбиения по опорному элементу рекурсия нужна только в одну часть.

## Примеры

```python
kth_fastest([61, 58, 70, 58, 64], 1)  # 58
kth_fastest([61, 58, 70, 58, 64], 2)  # 58 — повторы считаются
kth_fastest([61, 58, 70, 58, 64], 3)  # 61
```

## Ограничения

- `1 <= k <= len(times)`
- Без `sorted`, `.sort()` и модуля `heapq`. Среднее время — O(n).
- Результаты могут прийти уже упорядоченными — это худший случай из главы для опорного элемента «первый в списке»: глубина рекурсии станет n. Выбирайте опорный элемент случайно (`random.choice`).
