## Коротко

- `df.loc[строки, столбцы]` — по **меткам** индекса и именам столбцов. Срез меток **включает** конец.
- `df.iloc[строки, столбцы]` — по **позициям** 0, 1, 2… Срез позиций, как в Python, конец **не включает**.
- Вместо строк в `loc` можно передать булеву маску: `df.loc[df["qty"] < 15, "price"]`.
- Изменять значения — тоже через `loc` / `iloc` в **одних** скобках: `df.loc[mask, "col"] = значение`.
- `at` / `iat` — одна ячейка по метке / позиции, быстрее `loc` / `iloc`.

## Синтаксис

<Syntax code={`df.loc["метка"]                  # строка
df.loc["метка", "col"]           # ячейка
df.loc["a":"c", ["x", "y"]]      # срез меток (c входит) и список столбцов
df.loc[mask, "col"] = value      # запись по условию
df.iloc[0], df.iloc[1:3, :2]     # позиции (3 и 2 не входят)
df.at["метка", "col"], df.iat[0, 1]`} />

| | `loc` | `iloc` |
| --- | --- | --- |
| что принимает | метки, списки меток, маски | целые позиции, списки позиций, маски |
| срез | конец включается | конец не включается |
| несуществующая метка при записи | новая строка | ошибка |

## Подводные камни

<Pitfall title="Срезы loc и iloc по-разному обращаются с концом">

`stock.loc["чай":"какао"]` включает «какао», а `stock.iloc[1:3]` не включает позицию 3. Для меток «следующий после конца» не всегда определён, поэтому конец включают.

</Pitfall>

<Pitfall title="Запись в loc с новой меткой добавляет строку">

Опечатка в метке при записи не даёт ошибку — появляется новая строка.
