## Коротко

- `sort_values("col")` — по столбцу; список столбцов — по нескольким, `ascending` — список направлений.
- Пропуски по умолчанию идут в конец (`na_position="last"`).
- `key=` — функция, применяемая к столбцу перед сравнением: например, без учёта регистра.
- `sort_index()` — по индексу; помогает вернуть исходный порядок строк.
- `nlargest(n, "col")` / `nsmallest` — n строк с наибольшими / наименьшими значениями, быстрее полной сортировки.
- Сортировка возвращает новую таблицу; индекс остаётся прежним, пока не передать `ignore_index=True`.

## Синтаксис

<Syntax code={`df.sort_values(by, ascending=True, na_position="last", key=None, ignore_index=False)
df.sort_index(ascending=True)
df.nlargest(n, columns), df.nsmallest(n, columns)`} />

## Подводные камни

<Pitfall title="Результат не сохранили">

`sort_values` не меняет таблицу. Присвойте результат: `staff = staff.sort_values("salary")`.

<Pitfall title="Заглавные и строчные буквы">

Строки сравниваются по кодам символов: все заглавные идут раньше строчных, поэтому «аня» оказывается после «Дины». Для сортировки без учёта регистра передайте `key`.

</Pitfall>
