Цены товаров отсортированы по возрастанию и могут повторяться. Допишите `first_at_least(prices, budget)`: функция возвращает индекс первой цены, которая **не меньше** `budget`. Если такой цены нет, она возвращает `len(prices)`. Пропуски помечены `# TODO`.

## Примеры

```python
prices = [100, 250, 250, 250, 400]
first_at_least(prices, 250)  # 1 — первая из одинаковых
first_at_least(prices, 260)  # 4
first_at_least(prices, 50)   # 0
first_at_least(prices, 500)  # 5 — подходящих нет
```

## Ограничения

- Без модуля `bisect` — бинарный поиск уже написан в заготовке, допишите его.
- Время — O(log n), даже если все цены одинаковые: на 100 000 одинаковых цен тест допускает до 60 прочитанных элементов (хватает ~17).
