Галерея хранит в памяти не больше `capacity` превью фотографий. Когда место заканчивается, выбрасывается превью, к которому **дольше всех не обращались** (LRU — least recently used). Реализуйте класс `PreviewCache`: `get(photo_id)` возвращает превью или `None`, `put(photo_id, preview)` добавляет или обновляет превью. Оба метода считаются «обращением».

## Пример

```python
cache = PreviewCache(2)
cache.put("a", "превью A")
cache.put("b", "превью B")
cache.get("a")               # "превью A" — теперь «a» использовалась недавно
cache.put("c", "превью C")   # места нет: вытесняется «b»
cache.get("b")               # None
```

## Ограничения

- `capacity >= 1`. `get` и `put` работают за O(1) в среднем.
