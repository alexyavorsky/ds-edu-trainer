Маршрут автобуса — список остановок. Он называется симметричным, если одинаково читается от начала и от конца. Функция `is_symmetric(route)` проверяет это рекурсивно, но в ней две ошибки. Найдите и исправьте их.

## Примеры

```python
is_symmetric(["Депо", "Рынок", "Депо"])            # True
is_symmetric(["Парк", "Мост", "Мост", "Парк"])     # True
is_symmetric(["Парк", "Мост"])                     # False
is_symmetric([])                                   # True — пустой маршрут симметричен
```

## Идея алгоритма

Если первая и последняя остановки различаются, маршрут не симметричен. Если совпадают — проверяем тем же способом маршрут без них.
