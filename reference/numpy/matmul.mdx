## Коротко

- `a @ b` — матричное произведение: `(n, k) @ (k, m) → (n, m)`. Внутренние размеры должны совпадать.
- `a * b` — **поэлементное** умножение, это другое.
- Вектор на вектор через `@` — скалярное произведение (число); матрица на вектор — вектор.
- Для массивов 3D и больше `@` умножает матрицы **пачкой** по последним двум осям, а первые оси транслирует. `np.dot` для них ведёт себя иначе — в новом коде используйте `@`.
- `np.outer(x, y)` — все попарные произведения, `np.inner` / `np.dot` для векторов — скалярное произведение.

## Синтаксис

<Syntax code={`a @ b                 # = np.matmul(a, b)
np.dot(x, y)          # для векторов и матриц совпадает с @
np.inner(x, y)        # скалярное произведение векторов
np.outer(x, y)        # (n,) и (m,) → (n, m)`} />

| Формы | `a @ b` |
| --- | --- |
| `(n, k) @ (k, m)` | `(n, m)` |
| `(n, k) @ (k,)` | `(n,)` |
| `(k,) @ (k,)` | число |
| `(b, n, k) @ (k, m)` | `(b, n, m)` — пачка матриц |
