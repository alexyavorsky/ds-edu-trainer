## Коротко

- Строковые методы вызываются через `.str`: `s.str.lower()`, `s.str.contains("x")`. Они работают с каждым значением и пропускают `NaN`.
- В pandas 3 строки по умолчанию хранятся в типе `str` (раньше — `object`).
- `contains`, `replace`, `split`, `extract` по умолчанию понимают **регулярные выражения**. Для поиска обычного текста — `regex=False`.
- `split(expand=True)` раскладывает части по столбцам; `extract(r"(...)")` достаёт группы шаблона.
- `s.str[:4]` — срез каждой строки, `s.str.len()` — длины.
