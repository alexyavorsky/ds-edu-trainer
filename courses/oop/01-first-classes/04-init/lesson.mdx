В прошлом уроке атрибуты записывались снаружи, по одному, и их было легко забыть. Правильное место для
них — внутри класса, в специальном методе `__init__`.

## Метод `__init__`

Функция, объявленная внутри класса, называется **методом**. У метода с именем `__init__` особая роль:
Python вызывает его сам, сразу после создания экземпляра. В `__init__` экземпляр заполняют атрибутами:

<Demo id="init" title="Product с __init__" />

Разберём по шагам, что делает `Product("Латте", 220)`:

1. Python создаёт новый пустой экземпляр `Product`.
2. Вызывает `__init__`, передавая **этот экземпляр первым аргументом**, а `"Латте"` и `220` — следом.
   Первый параметр метода по соглашению называют `self` — «сам экземпляр».
3. Строки `self.name = name` записывают атрибуты в этот экземпляр — так же, как `cup.name = …` снаружи.
4. Готовый экземпляр возвращается и попадает в переменную.

Порядок легко увидеть, если напечатать что-нибудь внутри `__init__`:

<Demo id="steps" title="Когда вызывается __init__" />

Метод `__init__` называют **инициализатором** (initializer): он не создаёт объект — объект к этому моменту
уже есть, — а заполняет его. Имена с двумя подчёркиваниями с обеих сторон Python зарезервировал для таких
особых методов; их будет много, и у них есть общее название — **магические методы** (special methods;
их ещё называют dunder — от double underscore). Подробно о них — в модуле 4.

Теперь забыть атрибут не получится: аргументы `__init__` обязательны, и без них экземпляр не создастся:

## Забытый `self.`

<Demo id="no-self" title="Атрибут без self." />

<Mistake title="забыли self. — атрибут не сохранился">
Строка `name = name` внутри `__init__` создаёт обычную переменную метода, и она исчезает, когда метод
закончился. Атрибутом экземпляра значение становится только через `self.`: `self.name = name`. Ошибка
проявится позже — `AttributeError` при чтении атрибута.
</Mistake>

<Quiz id="init-quiz">
Сколько раз выполнится `__init__` в этом коде?

```python
a = Cup()
b = Cup()
c = a
```

- [ ] `3`
- [x] `2`
- [ ] `1`

<Explain>`__init__` вызывается при каждом создании экземпляра, то есть при каждом вызове `Cup()`. Строка `c = a` нового экземпляра не создаёт: переменная `c` получает тот же объект, что и `a`.</Explain>
</Quiz>

## Значения по умолчанию

Параметры `__init__` — обычные параметры функции, и у них могут быть значения по умолчанию. Тогда аргумент
можно не передавать:
