На складе «Кофейной лавки» — зёрна, молоко, сиропы и стаканы. Утром приходит поставка, днём бариста
расходует запасы, вечером управляющий смотрит, чего осталось мало. Сделаем класс `Stock`, с которым
всё это пишется так же коротко, как со словарём: `len(stock)`, `"Сироп" in stock`, `stock["Молоко"]`,
`for name in stock`, а поставка добавляется оператором `+`.

## Шаг 1. Склад-контейнер

<Exercise id="stock" title="Класс Stock">
Допишите класс `Stock`. `Stock({"Зёрна": 8, "Молоко": 12})` хранит **копию** словаря «позиция → количество»
во внутреннем атрибуте `_items`.

- `len(stock)` — число позиций, у которых количество больше нуля;
- `stock["Молоко"]` — количество позиции; если позиции нет — 0 (склад не ругается, а говорит «ноль»);
- `"Молоко" in stock` — `True`, если позиция есть и её количество больше нуля;
- `for name in stock` — названия позиций с количеством больше нуля, по алфавиту.

<Hint>`self._items = dict(items)` — копия словаря; количество — `self._items.get(name, 0)`.</Hint>
<Hint>`__iter__`: `for name in sorted(self._items):` и `yield name`, если количество больше нуля.</Hint>
</Exercise>

## Шаг 2. Поставка и расход

<Exercise id="supply" title="Сложение и списание">
Добавьте в класс (скопируйте его из шага 1 целиком):

- `__add__`: `stock + supply` — **новый** склад, где количества одинаковых позиций сложены; оба слагаемых не
  меняются; сложение с чужим типом — `NotImplemented`;
- метод `take(name, amount)` — списать `amount` единиц позиции; если на складе меньше —
  `ValueError("на складе мало: <название>")`, и ничего не меняется.

<Hint>В `__add__`: начните с `dict(self._items)` и прибавьте к нему количества из `other._items` через `get(name, 0)`.</Hint>
</Exercise>

## Шаг 3. Утро

<Exercise id="morning" title="Поставка пришла">
На складе с вечера — `leftover`, утром пришла поставка `delivery`. Сохраните в `stock` склад после поставки,
в `n_positions` — сколько на нём позиций, а в `milk` — сколько молока.

<Hint>`stock = leftover + delivery` — то, ради чего писали `__add__`.</Hint>
</Exercise>

## Шаг 4. День

<Exercise id="day" title="Расход за день">
В `usage` — что бариста взяли со склада за день, по порядку. Спишите всё по очереди методом `take`;
списания, на которые не хватило запасов, пропускайте, а их названия сохраните в `short` — в порядке
попыток.

<Hint>Цикл по парам `(name, amount)` и `try: stock.take(name, amount)`, `except ValueError: short.append(name)`.</Hint>
</Exercise>

## Шаг 5. Вечерний отчёт

<Exercise id="report" title="Что заказать">
Сохраните в `low` названия позиций, которых осталось меньше 5, — в порядке обхода склада циклом, а в
`out_of_syrup` — `True`, если сиропа на складе не осталось.

<Hint>`[name for name in stock if stock[name] < 5]` — цикл по складу и квадратные скобки.</Hint>
<Hint>«Сиропа не осталось» — `"Сироп" not in stock`.</Hint>
</Exercise>
