Нужно прочитать книгу из глав по `chapters[i]` страниц за `days` дней. Каждый день вы читаете не больше `s` страниц и только одну главу: если глава закончилась раньше, новую в тот же день не начинаете. Допишите `days_needed` и `min_daily_pages`: вторая функция возвращает минимальное `s`, при котором вы успеваете. Пропуски помечены `# TODO`.

## Пример

```python
min_daily_pages([30, 11, 23, 4, 20], 6)  # 23
# при s = 23: 2 + 1 + 1 + 1 + 1 = 6 дней; при s = 22 уже 7 дней
days_needed([30, 11, 23, 4, 20], 23)     # 6
```

## Ограничения

- `len(chapters) <= days` — решение всегда существует.
- До 10⁵ глав, в главе до 10⁹ страниц. Перебирать скорость по одной — слишком долго: тест на 10⁵ глав допускает до 100 проходов по списку глав (бинарному поиску хватает ~31).
