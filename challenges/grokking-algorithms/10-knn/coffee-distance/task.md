Каждый сорт кофе описан вектором признаков, например `[кислотность, горечь, плотность]`. Напишите `distance(a, b)`: функция возвращает расстояние между двумя векторами по формуле из главы — корень из суммы квадратов разностей. Если у векторов разная длина, она выбрасывает `ValueError`.

## Примеры

```python
distance([3, 4], [0, 0])          # 5.0
distance([7, 2, 5], [7, 2, 5])    # 0.0
distance([1, 2], [1, 2, 3])       # ValueError
```

## Ограничения

- Формулу напишите сами: без `math.dist` и `math.hypot`.
