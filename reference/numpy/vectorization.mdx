## Коротко

- **Векторизация** — запись вычисления через операции над целыми массивами. Цикл выполняет NumPy на C, а не интерпретатор Python — обычно в 10–100 раз быстрее.
- Типовые замены: `if/else` → `np.where`, цепочка `if/elif` → `np.select`, накопление суммы → `cumsum`, двойной цикл «каждый с каждым» → [транслирование](/reference/numpy/broadcasting), подсчёт по группам → `bincount`.
- `np.vectorize` только оборачивает функцию Python, чтобы её можно было вызвать от массива. Внутри тот же цикл по элементам, **ускорения нет**.
- Векторизованный код иногда создаёт большие промежуточные массивы — следите за памятью.

## Синтаксис

<Syntax code={`# цикл                                   # векторно
[f(x) if c else g(x) for x in a]         np.where(cond, f(a), g(a))
if / elif / else                         np.select([c1, c2], [v1, v2], default)
s += x в цикле                           np.cumsum(a), a.sum()
for i: for j: d[i, j] = …               a[:, None] - a[None, :]
np.vectorize(f)(a)                       # удобно, но не быстрее цикла`} />

## Подводные камни

<Pitfall title="np.vectorize не ускоряет">

Название обманчиво: это удобная обёртка для вызова обычной функции на массиве, а не компиляция. Если функцию нельзя переписать через операции NumPy, `np.vectorize` хотя бы делает код короче — но не быстрее.
