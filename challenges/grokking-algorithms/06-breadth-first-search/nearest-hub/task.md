Города соединены двусторонними дорогами. В некоторых городах есть склады. Допишите `distance_to_hub(towns, roads, hubs)`: функция возвращает словарь «город → минимальное число дорог до ближайшего склада». Для города со складом это `0`, для города, откуда склад недостижим, — `-1`. Пропуски помечены `# TODO`.

## Пример

```python
towns = ["A", "B", "C", "D", "E"]
roads = [("A", "B"), ("B", "C"), ("C", "D")]
distance_to_hub(towns, roads, {"A", "D"})
# {"A": 0, "B": 1, "C": 1, "D": 0, "E": -1}
```

## Ограничения

- До 10⁵ городов и дорог, время — O(V + E): один поиск в ширину, а не по поиску на каждый город. Тест на 20 000 городов ждёт не больше 5 секунд.
