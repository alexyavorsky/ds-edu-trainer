## Коротко

- `rolling(n)` — окно из `n` последних строк; дальше агрегация: `.mean()`, `.sum()`, `.max()`, `.agg([...])`. Первые `n − 1` значений — `NaN`.
- `min_periods` — сколько значений достаточно для расчёта; `center=True` — окно вокруг точки, а не до неё.
- `rolling("7D")` при датах в индексе — окно **по времени**: учитываются строки за последние 7 дней, даже если дней с данными меньше.
- `expanding()` — окно от начала до текущей строки: максимум или среднее «на сегодняшний день».
- `ewm(span=…)` — экспоненциальное сглаживание: недавние значения весят больше.

## Подводные камни

<Pitfall title="Окна через границы групп">

Если в одной таблице несколько рядов, простое `rolling` смешает их. Группируйте перед окном — результат получит MultiIndex (группа, исходная метка).

</Pitfall>

<Pitfall title="Окно по строкам при пропусках в датах">

`rolling(3)` берёт 3 строки, даже если между ними неделя. Для «последних 3 дней» нужен `rolling("3D")` и даты в индексе, как в примере выше.

</Pitfall>
