Маски и операторы `&`, `|`, `~` позволяют записать любое условие. Но некоторые условия встречаются так часто,
что для них есть короткие записи.

## between: число в диапазоне

«Цена от 320 до 390» — это два сравнения через `&`. Метод `between` («между») записывает их одним вызовом:

<Demo id="between" title="Цены от 320 до 390" />

Обе границы **входят**: товары ровно за 320 и ровно за 390 попали в выборку. Если границы нужно исключить, это
задаёт параметр `inclusive`: `"both"` — входят обе (так по умолчанию), `"neither"` — ни одна, `"left"` или
`"right"` — только левая или только правая.

## query: условие строкой

Метод `query` («запрос») принимает условие как текст. Внутри текста названия столбцов пишут без кавычек и без
`orders[...]`, а условия соединяют привычными `and`, `or`, `not`:

<Demo id="query" title="Условие в виде строки" />

Сравните с `orders[(orders["price"] > 3000) & (orders["city"] == "Новосибирск")]` — результат тот же, а читать
легче. Текстовые значения внутри условия берут в кавычки другого вида: снаружи двойные — внутри одинарные.

Переменные Python в условии отмечают знаком `@`; список проверяют словом `in`:

<Demo id="query-var" title="Переменные в запросе" />

Если забыть кавычки вокруг текста, `query` примет слово за название столбца или переменной:

<Demo id="query-error" title="Казань без кавычек" />

<Mistake title="name 'Казань' is not defined">
В `query` слово без кавычек — это название столбца. Текстовое значение пишут в кавычках:
`"city == 'Казань'"`. А название столбца с пробелом внутри берут в обратные кавычки: `` `unit price` > 5 ``.
</Mistake>

<Hint>Переменная Python внутри запроса — со знаком `@`: `price > @min_price`.</Hint>

Что выбрать — маски или `query`? Результат одинаковый. `query` короче и читается легче, когда условий
несколько. Маски нужны, когда условие собирается по частям, переиспользуется или по нему считают (`sum`,
`mean`). В этом курсе встречаются оба способа.

## Итоги

- `столбец.isin([...])` — значение входит в список; с `~` — не входит.
- `столбец.between(a, b)` — от `a` до `b`, обе границы входят; `inclusive=` это меняет.
- `таблица.loc[маска, столбцы]` — строки по условию и нужные столбцы одной записью.
- `таблица.query("условие")` — условие строкой: столбцы без кавычек, `and`/`or`/`not`, переменные через `@`.
