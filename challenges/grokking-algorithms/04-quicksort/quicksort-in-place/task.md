Версия из книги создаёт новые списки `less` и `greater`. Эта версия сортирует **на месте**: `partition` переставляет элементы отрезка `[low, high]` так, что слева от опорного (последнего) элемента оказываются меньшие, а справа — остальные, и возвращает итоговую позицию опорного. В коде две ошибки — найдите и исправьте их.

## Пример

```python
data = [5, 2, 9, 1, 5, 6]
quicksort_in_place(data)
data   # [1, 2, 5, 5, 6, 9]
```
