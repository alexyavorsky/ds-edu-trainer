Цены авиабилетов заданы взвешенным графом: `flights[a][b]` — цена прямого рейса из `a` в `b`. Напишите `cheapest(flights, start, goal)`: функция возвращает минимальную суммарную цену перелёта из `start` в `goal`, возможно с пересадками, или `math.inf`, если долететь нельзя.

## Пример

```python
flights = {
    "Москва": {"Стамбул": 9000, "Дубай": 15000},
    "Стамбул": {"Дубай": 4000, "Бангкок": 21000},
    "Дубай": {"Бангкок": 11000},
}
cheapest(flights, "Москва", "Бангкок")   # 24000: Москва → Стамбул → Дубай → Бангкок
cheapest(flights, "Бангкок", "Москва")   # inf
```

## Ограничения

- Цены неотрицательные. `cheapest(flights, x, x) == 0`.
