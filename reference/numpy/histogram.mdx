## Коротко

- `np.histogram(a, bins)` возвращает пару: **счётчики** и **границы** интервалов (границ на одну больше).
- `bins` — число интервалов одинаковой ширины или список границ.
- Интервалы полуоткрытые `[a, b)`, кроме последнего — он включает правую границу.
- `np.bincount(a)` считает вхождения целых 0, 1, 2… — быстрее `unique` для небольших неотрицательных целых. С `weights` — суммы по группам.
- `np.digitize(a, bins)` — номер интервала для каждого значения.

## Синтаксис

<Syntax code={`counts, edges = np.histogram(a, bins=10, range=None, density=False)
np.bincount(x, weights=None, minlength=0)   # x — неотрицательные целые
np.digitize(a, bins, right=False)`} />

## Параметры

<Params
  items={[
    ['bins', 'число интервалов, список границ или правило вроде "auto"', '10'],
    ['range', '(min, max) — диапазон для равных интервалов; значения вне него не считаются', 'None'],
    ['density', 'True — плотность вместо счётчиков: площадь гистограммы равна 1', 'False'],
    ['weights', 'в bincount: вместо +1 прибавлять вес элемента', 'None'],
    ['minlength', 'минимальная длина результата bincount', '0'],
    ['right', 'в digitize: включать правую границу интервала вместо левой', 'False'],
  ]}
/>
