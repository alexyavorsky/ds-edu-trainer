## Элемент: [строка, столбец]

У двумерного массива элемент задаётся **двумя** индексами через запятую: сначала строка, потом столбец.

## Строка и столбец

Если указать только первый индекс, получится **строка** целиком — все показатели одного дня. Чтобы взять
**столбец**, на месте строк ставят двоеточие `:` — «все строки»:

<Demo id="row-col" title="Строка и столбец" />

Двоеточие — это срез без границ. Столбец — снова одномерный массив, с ним работает всё, что мы уже знаем:
`mean`, `max`, срезы.

<Mistake title="строка вместо столбца">
`weather[1]` — это **вторая строка** (2 января), а не второй столбец. Первый индекс всегда выбирает строки.
Столбец — `weather[:, 1]`.
</Mistake>

## Блок: срезы по двум осям

Срез можно задать и для строк, и для столбцов сразу: `weather[0:7, 1:3]` — первые 7 строк и столбцы 1 и 2.
Получается маленькая таблица:

<Quiz id="block-shape">
Какая форма у `weather[:, 1:3]`?

- [ ] `(2,)`
- [ ] `(365,)`
- [x] `(365, 2)`

<Explain>`:` берёт все 365 строк, `1:3` — два столбца (1 и 2; конец 3 не входит). Получается таблица 365 × 2.</Explain>
</Quiz>

## Итоги

- Элемент таблицы — `a[строка, столбец]`, оба индекса с нуля.
- `a[i]` — строка, `a[:, j]` — столбец (одномерные массивы).
- `a[r1:r2, c1:c2]` — прямоугольный блок; срезы по каждой оси работают как обычно.
