## Коротко

- `np.diff(a)` — `a[1:] - a[:-1]`: разности соседних элементов. Результат **на 1 короче**.
- `prepend=` / `append=` добавляют значение перед вычислением, чтобы сохранить длину.
- `n=2` — разность разностей (вторая разность).
- В многомерном массиве по умолчанию берётся **последняя** ось; другая — через `axis`.
- `diff` и `cumsum` взаимно обратны. `np.gradient` возвращает массив той же длины: центральные разности внутри и односторонние на краях.

## Синтаксис

<Syntax code={`np.diff(a, n=1, axis=-1, prepend=None, append=None)

## Подводные камни

<Pitfall title="Беззнаковые целые">

Для `uint8`, `uint16` и других беззнаковых типов отрицательная разность «переворачивается» в большое положительное число. Перед `diff` переведите массив в знаковый тип: `level.astype(np.int16)`.
