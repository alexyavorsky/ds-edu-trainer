## Коротко

- `np.flip(a, axis)` — обратный порядок вдоль оси; без `axis` — по всем осям. `flipud` / `fliplr` — короткие имена для осей 0 и 1.
- `np.flip` для одномерного массива — то же, что `a[::-1]`; оба дают представление.
- `np.roll(a, k)` — **циклический** сдвиг: элементы, ушедшие за край, появляются с другой стороны. Положительный `k` — вправо.
- `roll` без `axis` работает с вытянутым массивом, а затем возвращает исходную форму.
- `np.rot90(a, k)` поворачивает на `k × 90°` против часовой стрелки.
