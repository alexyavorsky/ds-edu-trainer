## Коротко

- **Индекс** — метки строк. По нему работают `loc`, выравнивание, `join`, временные ряды.
- `set_index("col")` делает столбец индексом (по умолчанию убирая его из данных); список столбцов — MultiIndex.
- `reset_index()` возвращает индекс в обычный столбец и ставит индекс 0, 1, 2…; `drop=True` — старый индекс просто выбросить.
- После фильтрации и сортировки индекс остаётся старым, с пропусками — `reset_index(drop=True)` приводит его в порядок.
- Индекс не обязан быть уникальным, но с повторами `loc` возвращает несколько строк.

## Синтаксис

<Syntax code={`df.set_index(keys, drop=True)
df.reset_index(drop=False)
