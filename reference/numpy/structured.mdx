## Коротко

- Тип элемента задаётся списком полей: `np.dtype([("name", "U10"), ("age", "i4")])`. Каждый элемент — запись.
- `a["age"]` — массив одного поля (представление); `a[1]` — одна запись.
- Работают маски, сортировка по полю (`order="age"`), запись в поле.
- Полезно для чтения двоичных форматов и обмена с C-кодом. Для анализа табличных данных почти всегда удобнее [pandas DataFrame](/reference/pandas/dataframe).

## Синтаксис

<Syntax code={`dt = np.dtype([("name", "U10"), ("age", "i4"), ("score", "f8")])
a = np.array([("Аня", 21, 4.5), ...], dtype=dt)   # элементы — кортежи
a["age"]                  # поле
a[0]                      # запись
np.sort(a, order="age")`} />

| Код типа | Значение |
| --- | --- |
| `"U10"` | строка до 10 символов |
| `"i4"`, `"i8"` | целое 4 / 8 байт |
| `"f8"` | float64 |
| `"?"` | bool |
