Две строки логов нужно сравнить: какой самый длинный фрагмент встречается в обеих **подряд** (самая длинная общая подстрока)? Функция `common_fragment_length(a, b)` решает это таблицей, но перепутала подстроку с подпоследовательностью. В ней две ошибки — найдите и исправьте их.

## Примеры

```python
common_fragment_length("error: disk full", "warning: disk quota")   # 7: ": disk " (с пробелами)
common_fragment_length("abcx", "xabc")                              # 3: "abc"
```
