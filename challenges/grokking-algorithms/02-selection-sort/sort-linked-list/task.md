Отсортируйте односвязный список по возрастанию сортировкой выбором, **переставляя узлы**, а не значения. Напишите `sort_nodes(head)`: функция возвращает новую голову. Новые узлы не создаются, поле `value` не меняется, узлы с равными значениями сохраняют исходный порядок.

## Пример

```python
head = Node(4, Node(1, Node(3, Node(1))))
head = sort_nodes(head)   # 1 → 1 → 3 → 4 (сначала та единица, что шла раньше)
```

## Ограничения

- Время — O(n²), дополнительная память — O(1): никаких списков узлов и `sorted`.
