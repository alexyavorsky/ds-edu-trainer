## Коротко

- `pivot_table(values, index, columns, aggfunc)` — значения из `index` становятся строками, из `columns` — столбцами, в ячейках — итог `aggfunc`.
- По умолчанию `aggfunc="mean"` — для сумм укажите `"sum"` явно.
- `fill_value=0` заполняет пустые сочетания, `margins=True` добавляет итоговые строку и столбец.
- `index` и `columns` могут быть списками — получится MultiIndex.
- `pd.crosstab(a, b)` — таблица частот: сколько строк в каждом сочетании; `normalize` — доли.

## Синтаксис

<Syntax code={`df.pivot_table(values=None, index=None, columns=None, aggfunc="mean",
               fill_value=None, margins=False, margins_name="All", observed=True)
pd.crosstab(index, columns, values=None, aggfunc=None, normalize=False, margins=False)`} />

## Параметры

<Params
  items={[
    ['values', 'столбец (или список) с числами для итогов', 'все числовые'],
    ['index / columns', 'что станет строками / столбцами: столбец или список', 'None'],
    ['aggfunc', 'функция или список: "sum", "mean", "count", своя функция', '"mean"'],
    ['fill_value', 'чем заполнить отсутствующие сочетания', 'None'],
    ['margins', 'добавить итоги по строкам и столбцам', 'False'],
    ['normalize', 'в crosstab: True / "all", "index", "columns" — доли вместо количеств', 'False'],
  ]}
/>
