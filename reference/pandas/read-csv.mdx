## Коротко

- `pd.read_csv("файл.csv")` читает таблицу; первая строка — заголовок, разделитель — запятая.
- Типы столбцов определяются автоматически. Даты по умолчанию остаются строками — их разбирают через `parse_dates`.
- Пустые поля и строки вроде `NA`, `null` становятся `NaN`; свои обозначения пропусков — `na_values`.
- CSV из русского Excel: `sep=";"`, `decimal=","`, иногда `encoding="cp1251"`.
- `df.to_csv("файл.csv", index=False)` — запись; без `index=False` индекс попадёт в файл лишним столбцом.

## Синтаксис

<Syntax code={`pd.read_csv(path, sep=",", header="infer", names=None, index_col=None,

            nrows=None, skiprows=None, decimal=".", thousands=None,
            encoding="utf-8")
df.to_csv(path, index=False, sep=",", encoding="utf-8")`} />

    ['decimal / thousands', 'десятичный разделитель и разделитель тысяч', '"." / None'],
    ['encoding', 'кодировка файла', '"utf-8"'],
  ]}
