## Коротко

- `to_dict()` по умолчанию — `{столбец: {метка: значение}}`. Другие формы задаёт `orient`: `"list"`, `"records"`, `"index"`.
- `to_dict("records")` — список словарей по строкам; это самый частый формат для JSON и API.
- `to_numpy()` — массив NumPy. У разнотипных столбцов общий тип `object` — медленный и неудобный.
- `tolist()` — список значений Series в обычных типах Python.
- Вместо `.values` используйте `to_numpy()`: у него понятное поведение и параметры `dtype`, `na_value`.

<Pitfall title="Пропуски в nullable-типах">

В столбце `Int64` пропуск — это `pd.NA`. В массиве NumPy у целых пропусков нет, поэтому `to_numpy` возвращает float с `NaN`. Если нужны целые, укажите `dtype` и значение для пропусков.
