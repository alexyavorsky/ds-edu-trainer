## Коротко

- `a == b`, `a < b` и другие сравнения работают **поэлементно** и возвращают массив `True`/`False`, а не одно значение.
- Поэтому `if a == b:` падает: Python не знает, как превратить массив в одно `True` или `False`.
- Равенство целиком — `np.array_equal(a, b)`: одинаковые форма и все элементы.
- Дробные числа сравнивают **с допуском**: `np.allclose` (целиком) и `np.isclose` (поэлементно).
- `NaN` не равен ничему, даже себе; для сравнения с учётом `NaN` есть `equal_nan=True`.

## Синтаксис

<Syntax code={`a == b                         # поэлементно → массив bool
(a == b).all()                 # все ли совпали (формы должны совпадать)
np.array_equal(a, b, equal_nan=False)
np.allclose(a, b, rtol=1e-05, atol=1e-08, equal_nan=False)
np.isclose(a, b, rtol=1e-05, atol=1e-08)   # поэлементно`} />

## Параметры

<Params
  items={[
    ['rtol', 'относительный допуск: разрешённая разница — rtol × |b|', '1e-05'],
    ['atol', 'абсолютный допуск; важен для значений около нуля', '1e-08'],
    ['equal_nan', 'считать NaN равным NaN', 'False'],
  ]}
/>

Условие близости: `|a − b| <= atol + rtol × |b|`.
