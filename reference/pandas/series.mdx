## Коротко

- `pd.Series(данные, index=…, name=…)` — значения плюс индекс. Без `index` метки — 0, 1, 2…
- Из словаря ключи становятся индексом. Из одного значения с `index` — это значение повторяется.
- `s["метка"]` — по метке, `s.iloc[i]` — по позиции, `s[s > 0]` — по условию.
- `s.index` — метки, `s.to_numpy()` — значения как массив NumPy, `s.name` — имя (станет именем столбца в DataFrame).
- Пропуск в целых числах превращает весь Series в `float64`, потому что `NaN` — это float.
