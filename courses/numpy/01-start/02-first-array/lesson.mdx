Представьте прайс-лист маленькой кофейни: четыре позиции по 120, 80, 45 и 300 рублей. Вы решили сделать скидку
10 % на всё. В обычном Python цены — это список, и новую цену приходится считать для каждого элемента отдельно:
циклом или генератором списка.

<Demo id="list-loop" title="Скидка на список цен" />

Работает, но с числами так приходится делать постоянно: каждая формула превращается в цикл. **NumPy**
(Numerical Python) — библиотека, которая хранит числа в **массивах** (array) и умеет считать по всем элементам
сразу. На ней построены pandas, scikit-learn, SciPy и почти весь анализ данных на Python.

## Первый массив

NumPy подключают под коротким именем `np` — так пишут почти во всех программах и в документации:

<Demo id="first" title="Массив из списка" />

`np.array` берёт список и делает из него массив. Последняя строка ячейки — просто `prices`, и Jupyter (как и
этот урок) показывает её значение: `array([...])`. По такой записи сразу видно, что перед нами массив, а не
список. `print` показывает тот же массив иначе:

<Demo id="print" title="print показывает массив без запятых" />

Элементы через пробелы, без запятых — это не ошибка, так массив выглядит при печати. Тип массива называется
`ndarray` (n-dimensional array, «n-мерный массив»): массивы бывают и двумерными, как таблица, — до них дойдём во
втором модуле.

## Действие со всем массивом сразу

Главное, ради чего нужен NumPy: арифметика с массивом применяется к **каждому элементу**. Цикл при этом писать
не нужно — он спрятан внутри NumPy и работает на скорости языка C.

## Список ведёт себя иначе

У обычного списка те же знаки означают совсем другое: `*` повторяет список, а `+` склеивает два списка.

А умножить список на дробное число Python не может вовсе:

<Demo id="list-float" title="Список на 0.9 не умножается" />

<Mistake title="список вместо массива">
Если забыть `np.array` и считать со списком, ошибки может и не быть: `prices_list * 2` молча вернёт список
двойной длины. Когда результат выглядит странно, проверьте, что у вас в руках: `type(x)` покажет
`numpy.ndarray` для массива и `list` для списка.
</Mistake>

## Итоги

- NumPy подключают так: `import numpy as np`.
- `np.array(список)` создаёт массив. Значение ячейки выглядит как `array([...])`, а `print` показывает элементы
  без запятых.
- Арифметика с числом (`+ - * / **`) применяется к каждому элементу и даёт новый массив — без циклов.
- У списков те же знаки значат другое: `*` повторяет список, `+` склеивает.
