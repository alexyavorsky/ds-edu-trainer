Посмотрите на классы из прошлых модулей: `Product`, `Money`, `Customer`. В каждом — одинаковый `__init__`,
который переписывает параметры в атрибуты, `__repr__`, который их перечисляет, и `__eq__`, который их
сравнивает. Это много однообразного кода, в котором легко ошибиться: добавили атрибут — и забыли его в
`__eq__`. Для таких **классов данных** (data class) в стандартной библиотеке есть модуль `dataclasses`.

## `@dataclass`

Декоратор `@dataclass` читает список **полей** (field) класса и сам пишет `__init__`, `__repr__` и `__eq__`.
Поле объявляется в теле класса строкой `имя: тип` — это **аннотация типа** (type annotation): подсказка,
какого типа значение ожидается.

<Demo id="dataclass" title="Product на dataclass" />

Три строки полей заменили собой три метода. `__repr__` перечисляет поля с именами, `__eq__` сравнивает все
поля по порядку.

<Note title="Аннотации не проверяются">
Python не проверяет аннотации при выполнении: `Product("Латте", "220")` создастся, и в `price` окажется строка.
Аннотации читают люди, редакторы кода и отдельные программы-проверщики, а `@dataclass` — только чтобы узнать
список полей. До этого урока курс обходился без аннотаций; дальше поля dataclass пишутся только с ними.
</Note>

## Значения по умолчанию

Значение по умолчанию задают прямо в поле: `volume: int = 250`. Поля со значением по умолчанию идут **после**
полей без него — как параметры функции:

## Списки в полях: `default_factory`

Помните изменяемое значение по умолчанию из модуля 2? dataclass не даёт на него наступить — поле
`items: list = []` вызывает ошибку сразу при объявлении класса:

<Demo id="mutable" title="Список по умолчанию запрещён" />

Нужно сказать, **как создавать** значение для каждого нового экземпляра: `field(default_factory=list)` —
вызвать `list()` и получить новый пустой список. `field` импортируют из того же модуля:

<Demo id="factory" title="Свой список у каждой корзины" />

<Mistake title="список по умолчанию в dataclass">
Ошибка `mutable default <class 'list'> for field items is not allowed: use default_factory` — защита от общего
списка на все экземпляры. Пишите `items: list = field(default_factory=list)`; для словаря —
`field(default_factory=dict)`.
</Mistake>
