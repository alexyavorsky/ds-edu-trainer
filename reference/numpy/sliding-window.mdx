## Коротко

- `sliding_window_view(a, k)` возвращает все окна длины `k` как строки нового массива: из `n` элементов получается `(n − k + 1, k)`.
- Это **представление** через strides: данные не копируются, окна пересекаются.
- Дальше — любая агрегация по последней оси: `.mean(axis=1)` — скользящее среднее, `.max(axis=1)` — скользящий максимум.
- Для многомерных данных передайте форму окна: `(2, 2)` — квадратики 2 × 2.
- Результат только для чтения. Чтобы окна были той же длины, что данные, сначала дополните массив через [np.pad](/reference/numpy/pad).

## Синтаксис

<Syntax code={`from numpy.lib.stride_tricks import sliding_window_view

sliding_window_view(a, window_shape, axis=None)
sliding_window_view(a, 3).mean(axis=-1)      # скользящее среднее
sliding_window_view(a, 3)[::2]               # окна с шагом 2`} />

<Pitfall title="Большие окна — много вычислений">

Данные не копируются, но `.mean(axis=1)` для окна длины `k` делает `k` сложений на каждую позицию. Для длинных окон скользящую сумму быстрее посчитать через `cumsum`.

<Pitfall title="as_strided">

В старом коде окна делали через `np.lib.stride_tricks.as_strided`. Эта функция не проверяет границы: ошибка в strides читает чужую память. Используйте `sliding_window_view`.

</Pitfall>
