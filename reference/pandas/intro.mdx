## Коротко

- **Series** — одномерный массив значений с **индексом** (метками строк).
- **DataFrame** — таблица: набор столбцов-Series с общим индексом. У каждого столбца свой тип.
- Операции применяются к целому столбцу сразу, как в NumPy: `df["a"] * 2`.
- Принято импортировать так: `import pandas as pd`. Во всех примерах справочника `pd` и `np` уже импортированы.
- Примеры в стиле Jupyter: под кодом — вывод `print` и значение последней строки. В `.py`-файле оберните последнюю строку в `print()`.

## Главное о pandas 3

Справочник написан для pandas 3.0. Если код из интернета ведёт себя иначе, скорее всего, дело в одном из этих изменений:

- строки по умолчанию хранятся в типе `str`, а не `object` — [строки](/reference/pandas/strings);
- любая выборка ведёт себя как копия (Copy-on-Write), цепочечное присваивание не работает — [Copy-on-Write](/reference/pandas/copy-on-write);
- даты из строк получают разрешение в микросекундах, а не наносекундах — [даты](/reference/pandas/datetime);
- удалены `applymap`, `fillna(method=…)`, частоты `M`, `Q`, `Y` и другие устаревшие API — отмечены в статьях.
