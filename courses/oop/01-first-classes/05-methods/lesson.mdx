`__init__` — первый метод, который вы написали. Но у класса бывают и обычные методы: они описывают, что
экземпляр **умеет делать**. Так в класс попадает поведение — как `upper` у строки и `append` у списка.

## Свой метод

Метод объявляется внутри класса, как функция, и первым параметром получает `self`. Через `self` метод
читает атрибуты своего экземпляра:

<Demo id="method" title="Метод label" />

Вызов `latte.label()` Python превращает в `Product.label(latte)`: экземпляр слева от точки становится
аргументом `self`. Поэтому один и тот же метод у разных экземпляров даёт разный результат — каждый раз
`self` — другой объект.

## Метод меняет состояние

Метод может не только вернуть результат, но и **изменить атрибуты** экземпляра. Набор значений атрибутов
называют **состоянием** объекта: после вызова метода состояние уже другое.

<Demo id="state" title="Продажи круассанов" />

<Exercise id="machine" title="Кофемашина">
Допишите класс `CoffeeMachine`. У новой машины счётчик чашек `cups` равен 0. Метод `brew(count=1)` варит
`count` чашек — увеличивает счётчик и ничего не возвращает. Метод `needs_cleaning()` возвращает `True`, если
с момента создания машина сварила 50 чашек или больше, иначе `False`.

<Hint>В `brew`: `self.cups = self.cups + count`.</Hint>
<Hint>`needs_cleaning` сравнивает `self.cups` с 50 и возвращает результат сравнения; ровно 50 чашек — уже пора чистить.</Hint>
</Exercise>

## Метод с параметрами

Кроме `self`, у метода могут быть обычные параметры — и со значениями по умолчанию тоже. При вызове `self`
не передаётся: его подставит Python.

<Exercise id="bill" title="Счёт с чаевыми">
Допишите класс `Bill`: `Bill(500)` хранит сумму счёта в атрибуте `amount`. Метод `with_tip(percent=10)`
возвращает сумму с чаевыми, округлённую до целых, и **не меняет** `amount`: `Bill(500).with_tip()` — 550,
`Bill(480).with_tip(5)` — 504.

<Hint>Как функция `with_tip` из первого урока, только сумма берётся из `self.amount`.</Hint>
</Exercise>

## Две частые ошибки

Первая — забыть `self` в параметрах метода. Python всё равно передаст экземпляр первым аргументом, и ему
некуда будет попасть:

<Demo id="no-self" title="Метод без self" />

<Mistake title="takes 0 positional arguments but 1 was given">
Метод объявлен без параметров, а вызван «с одним аргументом», хотя в скобках пусто. Этот аргумент —
экземпляр, который Python передаёт сам. Добавьте `self` первым параметром.
</Mistake>

Вторая — забыть скобки. `latte.label` без скобок — это сам метод, а не результат его вызова:

<Demo id="no-parens" title="Метод без скобок" />

<Demo id="no-parens-error" title="Метод плюс строка" />

<Mistake title="метод без скобок">
Если в выводе или в ошибке видно `method` там, где ждали строку или число, — где-то пропущены скобки: `latte.label`
вместо `latte.label()`. Без скобок метод не вызывается.
</Mistake>

<Quiz id="parens-quiz">
Что напечатает `print(type(latte.label()).__name__)`?

- [x] `str`
- [ ] `method`
- [ ] `Product`

<Explain>Со скобками метод вызывается, и `type` получает его результат — строку. Без скобок было бы `method`.</Explain>
</Quiz>
