Команда хочет новое название из тех же букв, что и старое. Допишите `is_anagram(a, b)`: функция проверяет, составлены ли строки из одинакового набора букв. Регистр и пробелы не учитываются. Подсчёт ведите словарём, без сортировки. Пропуски помечены `# TODO`.

## Примеры

```python
is_anagram("Листопад", "Спад толи")  # True
is_anagram("кот", "ток")             # True
is_anagram("кот", "кто-то")          # False
```

## Ограничения

- Время — O(len(a) + len(b)).
