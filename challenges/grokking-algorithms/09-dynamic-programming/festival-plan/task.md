На фестивале идут выступления `(название, часы, рейтинг)`. У вас `hours` свободных часов. Выступления не пересекаются по времени, но смотреть каждое можно только целиком. Напишите `plan_festival(shows, hours)`: функция возвращает список **индексов** выступлений с максимальным суммарным рейтингом, которые помещаются в `hours`.

## Пример

```python
shows = [("рок", 3, 50), ("джаз", 2, 30), ("фолк", 2, 35), ("техно", 4, 60)]
plan_festival(shows, 5)   # [0, 2] (рок + фолк = 85) — порядок индексов не важен
```

## Правила

- Если оптимальных вариантов несколько, годится любой.

## Ограничения

- До 100 выступлений, `hours <= 1000`. Время — O(n · hours): подходит таблица или рекурсия с запоминанием.
