Версия алгоритма Дейкстры с очередью с приоритетом (`heapq`): вместо перебора всех узлов самый дешёвый берётся из кучи за O(log n). Функция `shortest_costs(graph, start)` возвращает словарь минимальных стоимостей до всех достижимых узлов. В ней две ошибки — найдите и исправьте их.

## Пример

```python
graph = {"a": {"b": 7, "c": 2}, "c": {"b": 3}, "b": {"d": 1}}
shortest_costs(graph, "a")   # {"a": 0, "c": 2, "b": 5, "d": 6}
```
