Ведомость — классическая таблица «строки × столбцы»: строка — студент, столбец — предмет. На ней сходится
весь модуль: оси, `argmax`, статистика, сортировка. Файл `data/scores.csv`: первый столбец — код студента,
дальше — баллы по пяти предметам.

<Demo id="peek" title="Начало файла" />

## Шаг 1. Загрузка

Баллы загрузим числами, а коды студентов — отдельно, как текст: у `loadtxt` для этого есть `dtype=str`.

<Exercise id="load" title="Баллы и коды">
Сохраните в `scores` таблицу баллов (столбцы 1–5), а в `ids` — коды студентов (столбец 0) как строки.

<Hint>Баллы: `usecols=(1, 2, 3, 4, 5)`.</Hint>
<Hint>Коды: `usecols=0` и `dtype=str`.</Hint>
</Exercise>

## Шаг 2. Предметы

<Exercise id="subjects-avg" title="Самый трудный предмет">
Сохраните в `subject_avg` средний балл по каждому предмету, а в `hardest` — название предмета с самым низким
средним (названия — в списке `subjects`).

<Hint>Среднее по столбцу — `axis=0`.</Hint>
<Hint>`subjects[subject_avg.argmin()]`.</Hint>
</Exercise>

## Шаг 3. Студенты

<Exercise id="students" title="Лучший студент">
Сохраните в `student_avg` средний балл каждого студента, а в `best_id` — код студента с самым высоким средним.

<Hint>Среднее по строке — `axis=1`.</Hint>
<Hint>Код лучшего — `ids[student_avg.argmax()]`.</Hint>
</Exercise>

<Exercise id="best-per-subject" title="Лучший по каждому предмету">
Сохраните в `best_by_subject` коды студентов, лучших по каждому предмету, — пять кодов по порядку предметов.
Если лучших несколько (одинаковый максимум), `argmax` берёт первого из них — так и оставьте.

<Hint>`scores.argmax(axis=0)` — для каждого столбца индекс строки с максимумом.</Hint>
<Hint>Подставьте эти индексы в `ids[...]`.</Hint>
</Exercise>

## Шаг 4. Кто сдал всё и кто в зоне риска

`all` и `any` тоже понимают `axis`: `(scores >= 60).all(axis=1)` — для каждой строки, все ли её баллы не ниже 60.

<Exercise id="passed" title="Сдали все предметы">
Сохраните в `all_passed` число студентов, у которых **все** баллы не ниже 60.

<Hint>Маска «балл не ниже 60» — `scores >= 60`; «все в строке» — `.all(axis=1)`.</Hint>
<Hint>Число подходящих студентов — сумма получившейся маски.</Hint>
</Exercise>

<Exercise id="risk" title="Зона риска">
Сохраните в `at_risk` коды студентов, у которых хотя бы по одному предмету меньше 50 баллов.

<Hint>«Хотя бы один в строке» — `.any(axis=1)`.</Hint>
<Hint>Коды по маске — `ids[маска]`.</Hint>
</Exercise>

## Шаг 5. Рейтинг

<Exercise id="top5" title="Пятёрка лучших">
Сохраните в `top5` коды пяти студентов с самым высоким средним баллом — от лучшего.

<Hint>`np.argsort(student_avg)` — от худшего к лучшему; `[::-1]` — наоборот; `[:5]` — первые пять.</Hint>
</Exercise>
