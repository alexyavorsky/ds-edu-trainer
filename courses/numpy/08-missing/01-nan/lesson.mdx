Датчик на метеостанции иногда не передаёт показание, в анкете не ответили на вопрос, в таблице пустая клетка.
Такие места называют **пропусками** (missing values). До сих пор наши данные были полными — в этом модуле
научимся работать с неполными.

## Значение «не число»

В массиве нельзя оставить пустую клетку: у каждого элемента есть значение. Для пропуска NumPy использует
особое дробное число **NaN** — Not a Number, «не число». Записывается оно как `np.nan`:

<Demo id="what" title="Массив с пропуском" />

Три наблюдения:

- NaN — дробное число, поэтому массив с ним получает тип `float64`, даже если остальные числа целые.
- Любая арифметика с NaN даёт NaN: неизвестное плюс единица — тоже неизвестное.
- Поэтому `sum` и `mean` по массиву с пропуском возвращают `nan`. NumPy не выбрасывает пропуски молча —
  он показывает, что результат не определён.

## Найти пропуски: np.isnan

Самое странное свойство NaN: он **не равен даже самому себе**. «Неизвестное равно неизвестному?» — ответ «нет»:

<Demo id="nan-eq" title="NaN не равен ничему" />

<Mistake title="сравнение с np.nan">
`a == np.nan` всегда даёт маску из одних `False` — даже там, где пропуск есть. Ошибки нет, поэтому её легко не
заметить: фильтр ничего не находит, замена ничего не меняет. Пропуски ищут только функцией `np.isnan`.
</Mistake>

`np.isnan(a)` возвращает маску: `True` там, где пропуск. С ней работает всё, что вы знаете о масках: `sum`
считает пропуски, `~` переворачивает маску, а `a[~маска]` оставляет только известные значения:

## Заполнить пропуски

Иногда пропуски нужно не пропустить, а **заполнить** — например, чтобы построить график без дыр. Простой способ —
подставить среднее по известным значениям. Здесь пригодится `np.where` из модуля об условиях: где пропуск —
среднее, где нет — само значение.

<Exercise id="fill" title="Заполнить средним">
Сохраните в `filled` копию `readings`, где пропуски заменены средней температурой по известным дням. Сам
`readings` не меняйте.

<Hint>Средняя без пропусков — `np.nanmean(readings)`.</Hint>
<Hint>`np.where(np.isnan(readings), среднее, readings)`.</Hint>
</Exercise>

Заполнение средним сохраняет среднюю, но делает данные «глаже», чем они были. Это решение аналитика, а не
правило: иногда лучше взять соседний день или значение другой станции — так мы сделаем в мини-проекте модуля.

## NaN и целые числа

NaN — дробное число, поэтому в массив целых его записать нельзя:

<Mistake title="cannot convert float NaN to integer">
Эта ошибка значит, что NaN попытались записать в массив целых чисел — например, отметить пропуск в массиве
количеств. Сначала переведите массив в дробный — `counts.astype(float)`, — а потом записывайте `np.nan`.
</Mistake>

## Итоги

- Пропуск в NumPy — дробное значение `np.nan`; массив с ним дробный.
- Арифметика и обычные агрегаты с NaN дают NaN.
- `np.nan == np.nan` — `False`; пропуски ищут маской `np.isnan(a)`.
- `np.nanmean`, `np.nansum`, `np.nanmax`, `np.nanmin` считают без пропусков и принимают `axis=`.
- Заполнить пропуски — `np.where(np.isnan(a), чем_заполнить, a)`.
