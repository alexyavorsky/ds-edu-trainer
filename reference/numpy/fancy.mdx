## Коротко

- `a[[0, 2, 4]]` — элементы с этими индексами. Порядок любой, повторы и отрицательные индексы разрешены.
- Результат — **копия** (в отличие от среза), форма результата равна форме массива индексов.
- В двумерном массиве `a[[i1, i2], [j1, j2]]` берёт **пары** `(i1, j1)`, `(i2, j2)`, а не подматрицу. Подматрица — `a[np.ix_(строки, столбцы)]`.
- Типичный источник индексов — `argsort`, `argmax`, `nonzero`.
- `a[idx] += 1` при повторах в `idx` прибавит один раз; для накопления — `np.add.at`.

## Синтаксис

<Syntax code={`a[[0, 2, 4]]                   # список или массив индексов
a[idx] = 0                     # запись по индексам
m[[0, 2]]                      # строки 0 и 2
m[[0, 2], [1, 3]]              # элементы (0, 1) и (2, 3)
m[np.ix_([0, 2], [1, 3])]      # подматрица 2 × 2
np.add.at(a, idx, 1)           # прибавить с учётом повторов`} />

## Подводные камни

<Pitfall title="Результат — копия, а не представление">

Изменения выбранного массива не попадают в исходный. Чтобы изменить исходный, записывайте прямо в него: `a[idx] = ...`.

<Pitfall title="Повторяющиеся индексы при +=">

`a[idx] += 1` выполняется как `a[idx] = a[idx] + 1`: при повторах одно и то же значение записывается несколько раз, и прибавка засчитывается однажды.
