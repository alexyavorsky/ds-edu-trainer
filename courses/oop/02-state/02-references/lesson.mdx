Экземпляр живёт отдельно от переменных. Переменная — это имя, которое **ссылается** на объект, и имён у
одного объекта может быть несколько. Пока объекты не меняются, разницы не видно. Но экземпляры своих классов
обычно меняются — и тут важно понимать, сколько объектов на самом деле.

## Две переменные — один объект

Присваивание `b = a` не копирует объект: оно даёт тому же объекту второе имя. Изменение через одно имя видно
через другое:

<Demo id="alias" title="Второе имя для того же товара" />

Проверить, один ли это объект, можно оператором `is`. Он отвечает на вопрос о **тождественности**
(identity) — «тот же самый объект?», — а `==` — о **равенстве** (equality). Для своих классов `==` по умолчанию
тоже сравнивает тождественность, но это можно изменить — в модуле 4 мы научим товары сравниваться по названию
и цене.

<Demo id="is" title="is: тот же объект или нет" />

Самое частое место для `is` — проверка на `None`: `if x is None:`. Значение `None` в программе одно, поэтому
его сравнивают по тождественности.

## Объекты в списках и словарях

Список хранит не копии объектов, а ссылки на них. Если взять товар из списка и изменить, изменится тот же
объект, на который ссылается переменная снаружи:

<Demo id="in-list" title="Товар в меню и в переменной" />

Так же работает передача в функцию: функция получает **сам объект** и может его изменить.

<Exercise id="raise-prices" title="Подорожание">
Напишите функцию `raise_prices(products, amount)`: она увеличивает цену каждого товара из списка `products`
на `amount` рублей. Функция меняет сами товары и ничего не возвращает.

<Hint>Цикл по списку и `p.price = p.price + amount` для каждого товара.</Hint>
</Exercise>

<Exercise id="find" title="Найти товар">
Напишите функцию `find(products, name)`: она возвращает **сам товар** из списка с таким названием, а если
его нет — `None`.

<Hint>В цикле: если `p.name == name` — `return p`; после цикла — `return None`.</Hint>
</Exercise>

<Quiz id="copy-quiz">
`menu` — список из двух товаров, второй — чай за 120 ₽. Что напечатает код?

```python
tea = menu[1]
tea.price = 100
print(menu[1].price)
```

- [x] `100`
- [ ] `120` — старую цену
- [ ] ошибку: товар нельзя менять, пока он в списке

<Explain>`tea = menu[1]` не копирует товар, а даёт объекту из списка второе имя: в `menu[1]` и в `tea` один и тот же объект. Изменение через `tea` видно и через список.</Explain>
</Quiz>

## Нужна копия — создайте новый объект

Чтобы получить независимый объект, его создают заново — вызовом класса с теми же значениями. Тогда у копии
своя судьба:

<Exercise id="copy" title="Сезонный напиток">
В `latte` — товар «Латте» за 220 ₽. Создайте **отдельный** товар `pumpkin` с теми же атрибутами, затем
поменяйте ему название на `"Тыквенный латте"` и цену на 290. Исходный `latte` меняться не должен.

<Hint>`pumpkin = Product(latte.name, latte.price)` — новый объект; потом меняйте его атрибуты.</Hint>
</Exercise>

## Изменяемое значение по умолчанию

Та же история со ссылками прячется в значениях по умолчанию. Список, словарь и экземпляры ваших классов —
**изменяемые** (mutable) объекты: их можно поменять, не создавая новый объект. Числа, строки и кортежи —
**неизменяемые** (immutable). Значение по умолчанию вычисляется **один раз**,
когда объявляется функция, а не при каждом вызове. Если это список, все вызовы без аргумента получат один и
тот же список:

<Demo id="default-bug" title="Два заказа с одним списком" />

<Mistake title="изменяемое значение по умолчанию: items=[]">
`def __init__(self, customer, items=[])` — ловушка: пустой список создан один раз, и все заказы без явного
`items` делят его. Правильно — значение по умолчанию `None`, а список создаётся внутри метода:
`if items is None: items = []`.
</Mistake>

<Exercise id="fix-default" title="Починить доставку">
В заготовке — класс `Delivery` (доставка заказа) с ошибкой из демонстрации: заметки курьеру `notes` у всех
доставок без явного списка общие. Исправьте класс: у каждой доставки свой список `notes`. Если список передан
при создании, доставка хранит **его копию** `list(notes)` — чтобы её заметки не меняли чужой список.

<Hint>Значение по умолчанию — `None`; в `__init__` проверьте его через `is None`.</Hint>
</Exercise>

Запомните главное: присваивание и передача в функцию не копируют объекты. Копия появляется, только когда вы
создаёте новый объект сами.
