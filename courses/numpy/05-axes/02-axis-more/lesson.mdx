`axis` работает не только с суммой и средним. В этом уроке — три приёма, которые постоянно нужны на практике:
где максимум в каждой строке, накопленный итог и «когда впервые».

Данные — выручка трёх магазинов по месяцам, в тысячах рублей: строка — магазин, столбец — месяц.

## argmax по оси

`argmax(axis=1)` возвращает для **каждой строки** индекс её максимума — то есть номер лучшего месяца каждого
магазина:

<Demo id="argmax-axis" title="Лучший месяц каждого магазина" />

Индексы месяцев считаются с нуля: 11 — это декабрь. Чтобы получить привычный номер месяца, прибавьте 1.

## Накопленная сумма: cumsum

`cumsum()` (cumulative sum) строит массив, где каждый элемент — сумма всех элементов до него включительно.
Это «итог с начала года» на каждый месяц; последний элемент равен сумме всего массива:

<Demo id="cumsum" title="Выручка с начала года" />

С `axis=1` накопление идёт вдоль каждой строки — отдельно для каждого магазина:

<Quiz id="cumsum-quiz">
Что получится: `np.array([3, 1, 4, 1]).cumsum()`?

- [ ] `9`
- [x] `array([3, 4, 8, 9])`
- [ ] `array([3, 1, 4, 1])`

<Explain>Каждый элемент — сумма всех до него: 3, 3 + 1 = 4, 4 + 4 = 8, 8 + 1 = 9. Одно число 9 дал бы `sum`.</Explain>
</Quiz>

## Когда впервые: argmax у маски

У маски `argmax` возвращает индекс **первого** `True`: максимум маски — это `True` (единица), а при равных
максимумах `argmax` берёт первый. Вместе с `cumsum` это отвечает на вопрос «в каком месяце магазин впервые
набрал 300 тысяч с начала года»:

<Demo id="first-true" title="Первый месяц, когда набрали 300" />

<Mistake title="если True нет совсем">
Если в маске нет ни одного `True`, `argmax` вернёт 0 — как будто условие выполнилось сразу. Прежде чем верить
ответу, проверьте `маска.any()`.
</Mistake>

## Итоги

- `argmax(axis=1)` / `argmin(axis=1)` — индекс максимума / минимума в каждой строке; `axis=0` — в каждом столбце.
- `cumsum()` — накопленная сумма; с `axis` — вдоль каждой строки или столбца.
- `маска.argmax()` — индекс первого `True`; если `True` нет, вернёт 0 — проверяйте `any()`.
