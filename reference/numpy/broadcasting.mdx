## Коротко

- Операция `a + b` (и любая другая поэлементная) работает, даже если формы `a` и `b` разные, но **совместимые**.
- Формы сравниваются **справа налево**; недостающие слева оси считаются равными 1.
- По каждой оси размеры должны совпадать, или один из них должен быть равен 1 — такая ось «растягивается».
- Растягивание виртуальное: данные не копируются, поэтому это быстро и экономно.
- Главная ловушка — форма `(n,)` против `(n, 1)`: вектор всегда прикладывается как **строка**.

## Правила

1. Выровнять формы по правому краю и дописать слева единицы до одинаковой длины: `(4,)` рядом с `(3, 4)` становится `(1, 4)`.
2. Сравнить размеры по каждой оси: равны — хорошо; один равен 1 — он растягивается до другого; иначе `ValueError`.
3. Форма результата — максимум по каждой оси.

<BroadcastDiagram />

| Форма A | Форма B | Результат | Почему |
| --- | --- | --- | --- |
| `(3, 4)` | `()` — число | `(3, 4)` | число растягивается на всё |
| `(3, 4)` | `(4,)` | `(3, 4)` | B → `(1, 4)`, строка повторяется 3 раза |
| `(3, 4)` | `(3, 1)` | `(3, 4)` | столбец повторяется 4 раза |
| `(3, 1)` | `(4,)` | `(3, 4)` | растягиваются оба: «таблица» всех пар |
| `(2, 3, 4)` | `(3, 4)` | `(2, 3, 4)` | B → `(1, 3, 4)`, повторяется по первой оси |
| `(8, 1, 6, 1)` | `(7, 1, 5)` | `(8, 7, 6, 5)` | единицы с обеих сторон |
| `(3, 4)` | `(3,)` | ошибка | справа 4 и 3 — не равны и не 1 |

## Подводные камни

<Pitfall title="Квадратная матрица и вектор — ошибки нет, результат неверный">

Для формы `(3, 4)` вектор `(3,)` вызывает ошибку, а для квадратной `(3, 3)` — нет: вектор молча прикладывается к каждой **строке**, то есть вычитается по столбцам. Для операций «по строкам» делайте среднее столбцом: `keepdims=True` или `[:, np.newaxis]`.

</Pitfall>

<Pitfall title="Огромный промежуточный массив">

`x[:, np.newaxis] - y` для векторов длиной 100 000 создаёт матрицу 10¹⁰ элементов (80 ГБ для `float64`). Транслирование не копирует входные данные, но результат занимает полный объём. Для больших данных обрабатывайте частями.

</Pitfall>

<Pitfall title="broadcast_to возвращает представление только для чтения">

Растянутые элементы — это одна и та же ячейка памяти, поэтому записывать в них нельзя. Нужна изменяемая копия — `np.broadcast_to(...).copy()`.

<Example id="readonly" title="Запись в растянутый массив" />

</Pitfall>

<Pitfall title="При += растягивается только правая часть">

В `a += b` результат пишется в `a`, поэтому форма результата должна совпадать с формой `a`. Если растянуть нужно `a`, пишите `a = a + b`.
