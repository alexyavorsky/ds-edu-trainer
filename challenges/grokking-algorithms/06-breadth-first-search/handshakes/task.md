Соцсеть задана графом: `graph[x]` — список тех, кого знает `x` (знакомство может быть односторонним). Напишите `handshakes(graph, start, goal)`: функция возвращает минимальное число шагов по знакомствам от `start` до `goal`. Если `start == goal`, ответ `0`. Если добраться нельзя — `-1`.

## Пример

```python
graph = {
    "Аня": ["Борис", "Вера"],
    "Борис": ["Гоша"],
    "Вера": ["Гоша", "Дина"],
    "Дина": ["Егор"],
}
handshakes(graph, "Аня", "Гоша")   # 2
handshakes(graph, "Аня", "Егор")   # 3
handshakes(graph, "Гоша", "Аня")   # -1
```
