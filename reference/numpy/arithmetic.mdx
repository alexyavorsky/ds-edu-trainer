## Коротко

- `+ - * / // % **` работают **поэлементно**; у двух массивов формы должны совпадать или быть совместимы по правилам [транслирования](/reference/numpy/broadcasting).
- Операция с числом применяется к каждому элементу: `price * 1.2`.
- `/` всегда даёт float; `//` и `%` округляют вниз, как в Python (важно для отрицательных).
- Результат — **новый** массив; изменить существующий на месте — `a += b` (см. [операции на месте](/reference/numpy/inplace-out)).
- Деление на ноль не бросает исключение: для float получается `inf` или `nan`, для целых — `0`, плюс `RuntimeWarning`.

## Синтаксис

<Syntax code={`a + b, a - b, a * b, a / b      # поэлементно
a // b, a % b, a ** b
a * 2, 10 - a                   # с числом
np.add(a, b), np.multiply(a, b) # то же в виде функций (ufunc)`} />

| Оператор | Функция | Что делает |
| --- | --- | --- |
| `+`, `-` | `np.add`, `np.subtract` | сложение, вычитание |
| `*`, `/` | `np.multiply`, `np.divide` | умножение, деление (результат float) |
| `//`, `%` | `np.floor_divide`, `np.mod` | целая часть вниз, остаток |
| `**` | `np.power` | степень |
| `-a` | `np.negative` | смена знака |

<Pitfall title="Деление на ноль — предупреждение, а не ошибка">

Вычисление продолжается, а в результате появляются `inf` и `nan`, которые портят суммы и средние. Проверяйте делитель заранее или используйте `np.divide(..., where=...)` — см. [where](/reference/numpy/where).
