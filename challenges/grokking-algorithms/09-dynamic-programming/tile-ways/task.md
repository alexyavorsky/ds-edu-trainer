Садовая дорожка длиной `n` выкладывается плитками длины 1 и 2. Порядок плиток важен: `1+2` и `2+1` — разные дорожки. Напишите `tile_ways(n)`: функция возвращает число различных дорожек, заполняя таблицу подзадач.

## Примеры

```python
tile_ways(1)   # 1
tile_ways(3)   # 3: 1+1+1, 1+2, 2+1
tile_ways(0)   # 1: пустая дорожка
```

## Ограничения

- `0 <= n <= 40`. Подходит таблица или рекурсия с запоминанием; полный перебор не успеет.
