## Коротко

- Ключи называются по-разному — `left_on="customer", right_on="client_id"`. По индексу — `left_index=True` / `right_index=True`.
- Одноимённые столбцы, которые не являются ключом, получают суффиксы `_x` и `_y`; свои — `suffixes=("_a", "_b")`.
- `indicator=True` добавляет столбец `_merge`: `both`, `left_only`, `right_only` — удобно искать строки без пары.
- `validate="one_to_one"`, `"one_to_many"`, `"many_to_one"` проверяет уникальность ключей и падает, если она нарушена.
- `df.join(other)` — короткая форма `merge` по индексу `other`.

## Синтаксис

<Syntax code={`left.merge(right, left_on="a", right_on="b", how="left")
left.merge(right, left_on="a", right_index=True)
left.merge(right, on="k", suffixes=("_x", "_y"), indicator=False, validate=None)
left.join(right, on=None, how="left")`} />

<Pitfall title="Два столбца-ключа в результате">

С `left_on` / `right_on` оба ключа остаются в результате (`customer` и `client_id`). Лишний удалите через `drop(columns=…)`.

</Pitfall>
