Курьер выезжает со склада (точка с индексом `0`), объезжает все адреса и возвращается на склад. Точный кратчайший маршрут — NP-полная задача о коммивояжёре, поэтому используем жадную эвристику **«ближайший сосед»**: каждый раз едем в ближайшую ещё не посещённую точку. Напишите `plan_route(points)`: функция возвращает порядок обхода — список индексов, начинающийся с `0` (возврат на склад подразумевается).

## Пример

```python
points = [(0, 0), (10, 0), (1, 1), (9, 1)]
plan_route(points)   # [0, 2, 3, 1]
```

## Правила

- Расстояние — евклидово: `math.dist(a, b)`.
- При равенстве расстояний годится любая из ближайших точек. Тесты проверяют, что каждый шаг ведёт в ближайшую непосещённую точку и что маршрут не сильно длиннее оптимального.
- До 1000 точек, время — O(n²).
