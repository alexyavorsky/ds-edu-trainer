Данные часто приходят по частям: продажи за январь и за февраль в разных файлах, каждая метеостанция в своём.
Чтобы считать по ним вместе, части нужно **склеить** в один массив. Бывает и наоборот: месяц нужно
**разрезать** на недели.

## Новая ось: np.stack

Три метеостанции записали по 28 дней — три одномерных массива формы `(28,)`. Хочется таблицу 3 × 28: строка —
станция. `concatenate` тут не поможет: он продолжит массив до 84 чисел. Нужна **новая ось** — её добавляет
`np.stack`:

<Demo id="stack" title="concatenate и stack" />

`np.stack` кладёт массивы одинаковой формы друг на друга: из нескольких `(n,)` получается `(k, n)`, где `k` —
сколько массивов. С `axis=1` новой осью станут столбцы: `(n, k)`.

<Quiz id="stack-quiz">
`x` и `y` — массивы формы `(5,)`. Какая форма у `np.stack([x, y])`?

- [ ] `(10,)`
- [x] `(2, 5)`
- [ ] `(5, 2)`

<Explain>`stack` добавляет новую ось впереди: два массива по 5 чисел становятся двумя строками таблицы — `(2, 5)`. `(10,)` дал бы `concatenate`, а `(5, 2)` — `stack` с `axis=1`.</Explain>
</Quiz>

другом, `np.hstack` (horizontal — горизонтально) — рядом. Для таблиц это `concatenate` с `axis=0` и `axis=1`,

## Разрезать: np.split

`np.split(a, n)` режет массив на `n` равных частей и возвращает **список** массивов. Части можно сразу
разложить по переменным. Вместо числа частей можно передать список мест разреза — номера, с которых начинается
следующая часть:

<Demo id="split" title="Равные части и места разреза" />

Список массивов Python печатает как `[array([...]), array([...])]` — `array` здесь просто подпись: каждый
элемент списка — массив NumPy.

Если массив не делится на равные части, `split` не угадывает, куда деть остаток, а сообщает об ошибке:

(`np.split(a, [7, 14])`) или нужны отдельными переменными.

## Итоги

- `np.concatenate([a, b], axis=…)` продолжает массив по существующей оси.
- `np.stack([a, b])` добавляет новую ось: из `k` массивов `(n,)` — таблица `(k, n)`.
- `np.vstack` — друг под другом, `np.hstack` — рядом; размеры по другой оси должны совпадать.
- Столбец к таблице — `np.hstack([table, col[:, np.newaxis]])`.
- `np.split(a, n)` — `n` равных частей, `np.split(a, [i, j])` — разрез по местам; результат — список.
