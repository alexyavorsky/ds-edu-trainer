Учебный план: `prereqs[course]` — список курсов, которые нужно пройти **до** `course`. Напишите `study_order(prereqs)`: функция возвращает список всех курсов (и ключей, и упомянутых в требованиях) в порядке, при котором каждый пререквизит идёт раньше курса. Если это невозможно из-за циклической зависимости, функция возвращает `None`. Подходит любой допустимый порядок.

## Пример

```python
study_order({
    "Алгоритмы": ["Python", "Дискретка"],
    "Python": [],
    "ML": ["Алгоритмы", "Статистика"],
})
# например ["Python", "Дискретка", "Статистика", "Алгоритмы", "ML"]

study_order({"A": ["B"], "B": ["A"]})   # None
```

## Ограничения

- До 10⁵ курсов и требований, время — O(V + E).
- В тестах есть цепочка из 20 000 зависимых курсов: рекурсивный обход упрётся в лимит глубины рекурсии Python. Используйте очередь, как в главе.
