## Коротко

- `pd.to_datetime(s)` превращает строки в тип `datetime64`. Свой формат — `format="%d.%m.%Y"`, дата вида 01.03 — `dayfirst=True`, нераспознанные значения в `NaT` — `errors="coerce"`.
- Через `.dt` доступны части даты: `.dt.year`, `.dt.month`, `.dt.day_name()`, `.dt.hour`, `.dt.date`.
- Разность дат — промежуток (`Timedelta`): `.dt.days`, `.dt.total_seconds()`.
- `.dt.floor("D")` округляет вниз до дня, часа и т. д.; `.dt.strftime(...)` форматирует в строку.
- «Плюс месяц» с учётом календаря — `pd.DateOffset(months=1)`.
- В pandas 3 даты из строк хранятся с точностью до **микросекунд** (раньше — наносекунд).

## Синтаксис

<Syntax code={`pd.to_datetime(s, format=None, dayfirst=False, errors="raise")
s.dt.year, s.dt.month, s.dt.day, s.dt.hour, s.dt.date
s.dt.day_name(), s.dt.floor("h"), s.dt.strftime("%d.%m.%Y")
(end - start).dt.days, (end - start).dt.total_seconds()
s + pd.DateOffset(months=1), s + pd.Timedelta(days=3)`} />
