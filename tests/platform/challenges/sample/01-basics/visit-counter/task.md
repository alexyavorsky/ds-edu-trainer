Напишите класс `VisitCounter`: `increment()` добавляет одного посетителя, `reset()` обнуляет счётчик, свойство `value` возвращает текущее число. Функция `sample_visits()` из блока данных возвращает список событий `"in"` / `"reset"` — на нём удобно проверить класс.

## Примеры

```python
c = VisitCounter()
c.increment()
c.value  # 1
```
