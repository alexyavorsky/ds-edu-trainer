## Коротко

- `iterrows()` на каждой строке создаёт новый Series — это медленно.
- Series хранит один тип, поэтому в строке целые превращаются в float, если рядом есть дробные.
- `itertuples()` возвращает именованные кортежи: в несколько раз быстрее, типы сохраняются, поля — `row.qty`.
- Для нескольких столбцов подходит `zip(df["a"], df["b"])`.
- Лучший вариант — вообще без цикла: операции над столбцами, `np.where`, `groupby`, `merge`.
- Изменения `row` внутри цикла **не попадают** в таблицу.

## Синтаксис

<Syntax code={`for idx, row in df.iterrows(): ...        # медленно, типы теряются
for row in df.itertuples(index=False): row.col
for a, b in zip(df["a"], df["b"]): ...
df.to_dict("records")                      # список словарей`} />

| Задача в цикле | Замена |
| --- | --- |
| новый столбец из других | `df["c"] = df["a"] * df["b"]` |
| значение по условию | `np.where(cond, x, y)`, `np.select` |
| сумма / среднее по группам | `groupby(...).agg(...)` |
| подставить данные из другой таблицы | `merge` |
| накопленная сумма | `cumsum()` |
