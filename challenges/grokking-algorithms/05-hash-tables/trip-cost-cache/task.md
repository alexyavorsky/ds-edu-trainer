Маршрут — список городов, в том числе повторяющихся. Цену билета в город возвращает `fetch_price(city)`, но каждый вызов — медленный запрос к серверу. Функция `trip_cost(route, fetch_price)` считает полную стоимость маршрута и должна запрашивать цену каждого города **не больше одного раза**, храня ответы в кэше. В функции две ошибки — найдите и исправьте их.

## Пример

```python
prices = {"Казань": 3000, "Сочи": 5000}
trip_cost(["Казань", "Сочи", "Казань"], prices.__getitem__)  # 11000, два запроса
```
