## Коротко

- **Excel**: `read_excel(path, sheet_name=…)` / `to_excel(path, index=False)`. `sheet_name=None` читает все листы в словарь. Нужен пакет `openpyxl`.
- Несколько листов в один файл — через `pd.ExcelWriter`.
- **JSON**: `to_json(orient="records")` — список объектов; `lines=True` — по объекту на строку (JSON Lines). Для кириллицы — `force_ascii=False`.
- **Parquet**: `to_parquet` / `read_parquet` — быстрый двоичный формат, который **сохраняет типы** (даты, категории, целые с пропусками). Нужен `pyarrow`.
- CSV и JSON — текст: типы при чтении угадываются заново.
