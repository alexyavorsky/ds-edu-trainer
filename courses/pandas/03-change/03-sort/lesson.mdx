Отсортированную таблицу проще читать: сразу видно самое дорогое и самое дешёвое, первое и последнее.
Сортировка отвечает на вопросы со словами «самый», «топ» и «по порядку».

<Mistake title="отсортировали, а порядок прежний">

«Три самых дорогих товара» — это сортировка по убыванию и `head(3)`. Для такого частого случая есть
короткая запись — `nlargest` («n наибольших»):

<Demo id="nlargest" title="Три самых дорогих" />

И парный метод `nsmallest`:

<Demo id="nsmallest" title="Три самых дешёвых" />

<Quiz id="sort-quiz">
```python
t = pd.DataFrame({"x": [3, 1, 2]})
t.sort_values("x")
print(t["x"].tolist())
```

Что выведет этот код?

- [ ] `[1, 2, 3]`
- [x] `[3, 1, 2]`
- [ ] `[3, 2, 1]`

<Explain>`sort_values` вернул отсортированную таблицу, но её не сохранили. В `t` порядок прежний.</Explain>
</Quiz>

<Note title="Равные значения">
В таблице три строки с выручкой 9030 и три — с выручкой 8700, а в пятёрку из вторых помещаются только две.
`nlargest` при равных значениях берёт те строки, что стоят в таблице раньше. У `sort_values` порядок равных
строк не определён — он может оказаться любым. Если порядок важен, добавьте второй ключ сортировки —
например, дату.
</Note>

## Итоги

- `sort_values("столбец")` — по возрастанию; `ascending=False` — по убыванию; результат нужно сохранить.
- Список столбцов — сортировка по нескольким ключам; `ascending` может быть списком.
- После сортировки метки строк остаются прежними; первая строка — `iloc[0]`.
- `nlargest(n, "столбец")`, `nsmallest(n, "столбец")` — первые N.
- `sort_index()` сортирует по меткам индекса.
