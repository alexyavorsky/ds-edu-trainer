## Коротко

- `np.linalg.solve(A, b)` решает систему `A @ x = b`. Это точнее и быстрее, чем `inv(A) @ b`.
- `inv` — обратная матрица, `det` — определитель, `matrix_rank` — ранг.
- `eigh` — собственные значения и векторы **симметричной** матрицы (вещественные, по возрастанию); `eig` — для любой квадратной.
- `norm` — норма вектора или матрицы; с `axis` — для каждой строки или столбца.
- `lstsq(X, y)` — приближённое решение переопределённой системы (линейная регрессия).
- Вырожденная матрица даёт `LinAlgError`. Результаты — числа с плавающей точкой: сравнивайте через `np.allclose`.

## Синтаксис

<Syntax code={`np.linalg.solve(A, b)

values, vectors = np.linalg.eig(A)      # любая квадратная A
np.linalg.norm(x, ord=None, axis=None)
coef, residuals, rank, sv = np.linalg.lstsq(X, y)`} />
