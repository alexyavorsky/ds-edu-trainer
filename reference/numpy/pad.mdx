## Коротко

- `np.pad(a, pad_width, mode)` возвращает новый массив с добавленными краями.
- `pad_width`: число — столько же с каждой стороны каждой оси; `(до, после)` — для всех осей; `((до, после), …)` — для каждой оси отдельно.
- По умолчанию `mode="constant"`: края заполняются нулями или `constant_values`.
- `edge` повторяет крайний элемент, `reflect` отражает без повтора края, `wrap` продолжает по кругу.
- Типичное применение — сохранить длину после свёрток и скользящих окон.

## Синтаксис

<Syntax code={`np.pad(a, pad_width, mode="constant", constant_values=0)
