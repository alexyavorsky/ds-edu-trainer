## Коротко

- `s.where(условие, другое)` **оставляет** значения, где условие `True`, остальные заменяет (по умолчанию на `NaN`).
- `s.mask(условие, другое)` — наоборот: **заменяет**, где условие `True`.
- Замена может быть числом, Series или таблицей той же формы — значения берутся по меткам.
- `clip(lower, upper)` ограничивает значения диапазоном; границы могут быть Series — свои для каждой строки.
- Не путайте с `np.where(условие, a, b)`: там выбирается одно из двух значений, а у `where` в pandas «другое» используется только там, где условие ложно.

## Синтаксис

<Syntax code={`s.where(cond, other=nan)     # оставить, где cond
s.mask(cond, other=nan)      # заменить, где cond
s.clip(lower=None, upper=None)
np.where(cond, a, b)         # NumPy: массив из a или b`} />

## Подводные камни

<Pitfall title="where оставляет, а не заменяет">

Логика обратная привычной: `where(temps > 50, 50)` заменит на 50 всё, что **не больше** 50. Для «заменить, если больше» — `mask`.

</Pitfall>

<Pitfall title="np.where возвращает массив">

Результат `np.where` — массив NumPy без индекса. Чтобы получить Series, оберните: `pd.Series(np.where(...), index=s.index)`.

</Pitfall>
