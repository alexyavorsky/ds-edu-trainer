## Коротко

- Модуль `np.strings` (NumPy 2.0+) — строковые функции, применяемые к каждому элементу: `strip`, `upper`, `lower`, `capitalize`, `str_len`, `find`, `replace`, `startswith`, `slice`…
- Обычный строковый массив имеет тип `<Un` — строки **фиксированной** длины `n`. Более длинное значение при записи молча обрезается.
- `StringDType` (NumPy 2.0+) хранит строки любой длины.
- Старый модуль `np.char` работает, но новый код пишут на `np.strings`.
- Для таблиц со строковыми столбцами удобнее [pandas `.str`](/reference/pandas/strings).
