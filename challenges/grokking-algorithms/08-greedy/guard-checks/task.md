Каждая смена сотрудника — отрезок времени `[start, end]`, включая границы. Охранник хочет обойти посты как можно меньше раз, но так, чтобы во время **каждой** смены был хотя бы один обход. Функция `min_checks(shifts)` жадно выбирает моменты обходов и возвращает их список. В ней две ошибки — найдите и исправьте их.

## Пример

```python
min_checks([(1, 4), (2, 6), (5, 8), (7, 9)])   # [4, 8] — 2 обхода
min_checks([(1, 3), (3, 5)])                   # [3] — один обход в момент 3 годится обеим сменам
```
