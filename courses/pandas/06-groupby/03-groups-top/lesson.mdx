Группировка редко бывает последним шагом. Её результат обычно нужно отсортировать, отфильтровать, соединить
с другой таблицей или показать в отчёте. Для этого удобнее обычная таблица — с названиями групп в столбце,
а не в индексе.

## Из индекса — в столбец

Результат группировки — Series: города стали метками индекса.

<Demo id="series" title="Города — в индексе" />

Знакомый `reset_index` без `drop=True` не выбрасывает старый индекс, а делает его обычным столбцом:

<Demo id="reset" title="Города — в столбце" />

Получилась таблица из двух столбцов с обычным индексом 0, 1, 2… Того же добиваются сразу — параметром
`as_index=False` в `groupby` («не делать ключ индексом»):

<Demo id="as-index" title="То же одной командой" />

У результата `size()` нет названия, и столбец с числами получил бы имя `0`. Название задаёт параметр
`name` в `reset_index`:

<Demo id="size-name" title="Число строк по городам — таблицей" />

<Exercise id="table" title="Таблица категорий">
Сохраните в `category_table` таблицу из двух столбцов — `category` и `revenue` (сумма выручки по категории).
Строки — по убыванию выручки, индекс — с нуля подряд.

<Hint>`orders.groupby("category", as_index=False)["revenue"].sum()`.</Hint>
<Hint>Затем `.sort_values("revenue", ascending=False).reset_index(drop=True)` — здесь уже с `drop=True`: старые номера строк не нужны.</Hint>
</Exercise>

<Mistake title="reset_index: с drop и без">
Один метод — два разных действия. `reset_index()` превращает индекс в столбец: полезно, когда в индексе
данные (города после группировки). `reset_index(drop=True)` выбрасывает индекс: полезно, когда в нём
бессмысленные номера (после фильтра или сортировки).
</Mistake>

## Два ключа — плоская таблица

Особенно удобен `as_index=False` при группировке по двум столбцам: вместо индекса из двух уровней получается
простая «длинная» таблица — по строке на каждую пару.

## Лучшие в каждой группе

«Два самых продаваемых товара **в каждой** категории» — частый вопрос. `nlargest(2)` здесь не подходит: он
вернёт два товара на всю таблицу. Решение — в два шага.

Шаг первый: посчитать выручку каждого товара и отсортировать всю таблицу по убыванию.

<Demo id="products" title="Товары по убыванию выручки" />

Шаг второй: сгруппировать по категории и взять `head(2)`. После `groupby` метод `head` берёт первые строки
**каждой группы** — а раз таблица отсортирована, первые и есть лучшие:

<Demo id="top-each" title="По два лучших товара в категории" />

Строки остались в порядке общей сортировки. Чтобы категории шли подряд, результат сортируют ещё раз:

<Demo id="top-each-sorted" title="Категории — по порядку" />

Обратите внимание: `head` после `groupby` не сворачивает группы в одну строку, как `sum`, а возвращает
сами строки таблицы. Парный метод `tail(n)` берёт последние строки каждой группы.

<Exercise id="worst" title="Аутсайдеры">

в каждой категории: пять строк, отсортированных по категории, с индексом с нуля.

<Hint>Худший товар группы — последняя её строка: `products.groupby("category").tail(1)`.</Hint>
<Hint>Затем `.sort_values("category").reset_index(drop=True)`.</Hint>
</Exercise>

<Exercise id="vip" title="Лучшие покупатели городов">
Сохраните в `customers` таблицу со столбцами `city`, `customer_id`, `revenue` — выручку по каждому покупателю
с его городом. В `vip` сохраните двух покупателей с наибольшей выручкой в каждом городе: десять строк,
отсортированных по городу, а внутри города — по убыванию выручки; индекс с нуля.

<Hint>`orders.groupby(["city", "customer_id"], as_index=False)["revenue"].sum()`.</Hint>
<Hint>Сортировка по убыванию выручки, затем `.groupby("city").head(2)`; в конце `.sort_values(["city", "revenue"], ascending=[True, False]).reset_index(drop=True)`.</Hint>
</Exercise>

<Mistake title="head без сортировки">
`groupby("city").head(2)` берёт первые две строки группы в том порядке, в каком они стоят в таблице. Если
таблицу не отсортировать заранее, это будут не лучшие покупатели, а просто первые попавшиеся.
</Mistake>

## Итоги

- `reset_index()` после группировки или `as_index=False` в `groupby` — ключи становятся столбцами.
- С двумя ключами `as_index=False` даёт плоскую таблицу: строка на каждую пару.
- Лучшие в каждой группе: отсортировать всю таблицу, затем `groupby("ключ").head(n)`.
- `head` и `tail` после `groupby` возвращают строки, а не итоги.
