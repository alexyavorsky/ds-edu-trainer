## Коротко

- `np.apply_along_axis(func, axis, a)` вызывает `func` для каждого одномерного среза вдоль `axis`: при `axis=1` — для каждой строки.
- Функция может вернуть число или массив — результаты собираются в новый массив.
- Внутри — обычный цикл Python, поэтому это **не быстрее** цикла. Выигрыш только в краткости.
- Если функция собрана из агрегаций NumPy (`max`, `mean`, `sort`…), вызовите их сразу с `axis` — это в разы быстрее.
- `apply_along_axis` оправдан для функций без параметра `axis`: `bincount`, `interp`, свои функции с ветвлениями.

## Синтаксис

<Syntax code={`np.apply_along_axis(func1d, axis, arr, *args, **kwargs)
np.apply_along_axis(f, 1, a)      # f(строка) для каждой строки
np.apply_along_axis(f, 0, a)      # f(столбец) для каждого столбца`} />
