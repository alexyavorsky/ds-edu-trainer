Настоящие данные не набирают руками — их загружают из файла. В этом уроке — погода в Москве за 2025 год,
по дню в строке: файл `data/moscow_2025.csv` уже лежит рядом с уроком. CSV — это текст, поэтому сначала
посмотрим на его начало как на обычный текст: `open` открывает файл, метод `read` читает его целиком, а `with`
сам закроет файл, когда блок закончится.

<Demo id="peek" title="Начало файла" />

Первая строка — **заголовок**: названия столбцов. Дальше — данные через запятую: номер дня, минимальная и
максимальная температура, осадки в миллиметрах.

## Загрузить таблицу: np.loadtxt

`np.loadtxt` читает текстовый файл с числами в массив. Ему нужно сказать, чем разделены значения —
`delimiter=","`, и сколько строк сверху пропустить — `skiprows=1`, чтобы не читать заголовок:

<Demo id="load" title="Весь файл в двумерный массив" />

Получилась таблица 365 × 4: по строке на день, по столбцу на показатель. Большие массивы NumPy показывает
сокращённо — несколько строк начала, `...` и конец; строки не пропали, просто не напечатаны. Все числа дробные — `loadtxt` по
умолчанию читает всё как `float`.

<Quiz id="load-shape">
Сколько всего чисел в `weather` — чему равен `weather.size`?

- [ ] 365
- [x] 1460
- [ ] 4

<Explain>Форма `(365, 4)`: 365 строк по 4 числа — всего 365 × 4 = 1460. `size` считает все элементы, а не строки: строк — это `len(weather)`.</Explain>
</Quiz>

Без `skiprows=1` `loadtxt` пытается превратить в число слово `day` из заголовка и падает:

<Demo id="no-skip" title="Заголовок прочитан как данные" />

<Mistake title="забыли пропустить заголовок">
«could not convert string 'day' to float» — значит, в числовые данные попал текст. Чаще всего это заголовок:
добавьте `skiprows=1`.
</Mistake>

## Сохранить результат: np.savetxt

`np.savetxt(путь, массив)` записывает массив в текстовый файл, по числу в строке. Параметр `fmt=` задаёт, как
печатать числа: `"%.1f"` — с одним знаком после точки:

## Итоги

- `np.loadtxt(путь, delimiter=",", skiprows=1)` — числа из CSV в массив; строка файла — строка массива.
- `usecols=` — загрузить только нужный столбец (номер с нуля).
- Текст в числах (например, незамеченный заголовок) — ошибка `could not convert string`.
- `np.savetxt(путь, массив, fmt="%.1f")` — записать массив в файл.
