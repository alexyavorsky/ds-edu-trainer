## Коротко

- `np.repeat(a, k)` повторяет **каждый элемент** `k` раз: `[1, 2] → [1, 1, 2, 2]`.
- `np.tile(a, k)` повторяет **весь массив**: `[1, 2] → [1, 2, 1, 2]`.
- `repeat` принимает и список повторов — у каждого элемента своё число.
- У `repeat` без `axis` многомерный массив сначала вытягивается в строку; `tile` с кортежем повторяет по нескольким осям.
- Для арифметики с повторёнными данными обычно хватает [транслирования](/reference/numpy/broadcasting) — оно не копирует данные.

## Синтаксис

<Syntax code={`np.repeat(a, repeats, axis=None)
np.tile(a, reps)          # reps — число или кортеж по осям`} />

## Подводные камни

<Pitfall title="Копирование там, где хватит транслирования">

`tile` и `repeat` создают полноценные копии. Если повтор нужен только для поэлементной операции, транслирование даст тот же результат без лишней памяти.
