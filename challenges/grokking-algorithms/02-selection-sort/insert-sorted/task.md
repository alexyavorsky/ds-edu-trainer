Заказы кафе хранятся в односвязном списке, отсортированном по времени поступления (в минутах). Напишите `insert_sorted(head, time)`: функция вставляет новый заказ так, чтобы порядок сохранился, и возвращает голову списка — она могла измениться. Заказ с таким же временем, как у уже существующих, встаёт **после** них.

## Пример

```python
head = Node(5, Node(12, Node(30)))
head = insert_sorted(head, 20)   # 5 → 12 → 20 → 30
head = insert_sorted(head, 1)    # 1 → 5 → 12 → 20 → 30
insert_sorted(None, 7)           # 7
```

## Ограничения

- Существующие узлы не пересоздаются, новый узел создаётся ровно один.
- Время — O(n), без перевода в обычный список.
