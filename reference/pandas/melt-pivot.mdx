## Коротко

- **Широкий** формат: у каждой сущности одна строка, показатели по периодам — в отдельных столбцах. **Длинный**: одна строка на пару «сущность — период».
- `melt(id_vars=…)` — из широкого в длинный: остальные столбцы превращаются в пары «имя столбца (`var_name`) — значение (`value_name`)».
- `pivot(index, columns, values)` — из длинного в широкий, **без агрегации**: каждому сочетанию должно соответствовать одно значение.
- Если значений на сочетание несколько, нужен [pivot_table](/reference/pandas/pivot-table) с `aggfunc`.
- Длинный формат удобен для `groupby`, фильтров и графиков; широкий — для чтения человеком.
