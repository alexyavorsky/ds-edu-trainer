В главе сортировка слиянием упоминается как соперник быстрой сортировки: у неё O(n log n) даже в худшем случае. Допишите её. Список делится пополам, половины сортируются рекурсивно, а затем **сливаются** в один упорядоченный список за O(n). Пропуски помечены `# TODO`.

## Пример

```python
merge([1, 4, 9], [2, 3, 10])   # [1, 2, 3, 4, 9, 10]
merge_sort([5, 2, 8, 2, 1])    # [1, 2, 2, 5, 8]
```

## Ограничения

- `merge` работает за O(len(left) + len(right)), без `sorted` и `.sort()`.
