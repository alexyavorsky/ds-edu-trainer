## Коротко

- `a.T` — транспонирование: строки становятся столбцами. Для многомерного массива порядок осей переворачивается.
- `np.transpose(a, axes)` задаёт порядок осей явно; `moveaxis` переносит одну ось, `swapaxes` меняет две местами.
- `a[:, np.newaxis]` (или `np.expand_dims`) добавляет ось длины 1: вектор `(3,)` → столбец `(3, 1)`.
- `np.squeeze` убирает все оси длины 1: `(3, 1)` → `(3,)`.
- Всё это — представления: данные не копируются.

## Синтаксис

<Syntax code={`a.T                          # перевернуть порядок осей
np.transpose(a, (0, 2, 1))   # явный порядок
np.moveaxis(a, source, destination)
np.swapaxes(a, 0, 1)
a[:, np.newaxis]             # добавить ось; np.newaxis — это None
np.expand_dims(a, axis=0)
np.squeeze(a, axis=None)     # убрать оси длины 1`} />
