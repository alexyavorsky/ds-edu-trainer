## Коротко

- `agg(["sum", "mean"])` — несколько функций для выбранного столбца.
- `agg({"col": "sum", "other": ["mean", "max"]})` — свои функции для каждого столбца; столбцы результата становятся MultiIndex.
- **Именованная агрегация** `agg(имя=("столбец", "функция"))` сразу даёт плоские и понятные имена — самый удобный вариант.
- Функция может быть строкой (`"sum"`, `"nunique"`, `"first"`) или своей функцией от Series. Строки работают быстрее.
- `as_index=False` — ключи группировки обычными столбцами.

## Синтаксис

<Syntax code={`df.groupby(key)["col"].agg(["sum", "mean"])
df.groupby(key).agg({"a": "sum", "b": ["min", "max"]})
df.groupby(key).agg(new_name=("col", "func"), other=("col2", my_func))`} />

| Функция | Что считает |
| --- | --- |
| `"sum"`, `"mean"`, `"median"` | сумма, среднее, медиана (без NaN) |
| `"min"`, `"max"`, `"std"` | минимум, максимум, выборочное отклонение |
| `"count"` / `"size"` | непустые значения / все строки |
| `"nunique"` | число различных значений |
| `"first"`, `"last"` | первое / последнее непустое значение |
